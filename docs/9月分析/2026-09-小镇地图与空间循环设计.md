## 1. 地图目标

扩容后的首发地图要同时满足六个目标：

1. 玩家 5～10 分钟内走熟中央商业与公共核心，而不是走完全图；
2. 玩家能通过住宅、工作地点、娱乐场所和户外活动找到居民；
3. 商业、娱乐、社区休闲、运动和景区都有可辨识的子地点，而不是只有一个区域标签；
4. 玩家 8～15 分钟可以完成娱乐社交环，10～18 分钟可以完成滨水景区环，15～25 分钟可以完成全镇长环；
5. 每个主要地点都能触发行动、关系、公共项目、地点记忆或路线结果；
6. 连续返回三次后，玩家能观察到“人、事、地”至少两类变化。

地图是 54 人社会与有限游客流的空间容器，不是 54 个独立房屋的展示列表。当前采用 32 个主要空间锚点、80～100 个可辨识子地点、18 个居民居住组团、一个大型低层公寓、一个旅店和四条可重复环线。旧车站与档案馆相邻但独立；中央广场保持开放通行，不放主要运动场地。

### 2.2 坐标系统

- 原点 `(0,0)` 位于规划范围西南角；`x` 轴向东，`y` 轴向北；
- 总规划范围为 `0 <= x <= 264m`、`0 <= y <= 216m`；
- 主节点坐标表示节点或建筑包络的中心点；
- 建筑记录首层投影占地，楼层数另列；户外节点记录最低场地包络；
- 白盒建议使用 `12m` 网格；主路宽 `6～8m`，居民支路宽 `3～5m`，林间步道宽 `2～3m`；
- 建筑之间至少保留 `4～8m` 的公共通行、庭院或后勤间隔；
- 坐标用于制作和提示词，不要求玩家最终看到坐标网格。

## 5. 商业、娱乐与社区设施

### 5.1 中央商业区

中央商业区不是城市购物中心，而是有主街、后巷、店铺前廊、后院和露天座的旅游小镇街区。主要子地点包括杂货铺、面包房、地图与旅途用品店、本地手作店、摄影与纪念品店、共享仓、游客问询台和临时摊位。商业街每隔约 20～30m 应出现店面、公共入口、巷口、座椅或小广场。

### 5.2 垂直娱乐复合楼

08 号复合楼按以下垂直关系制作：

```text
一层：咖啡馆、临街窗口、露天座、早餐桌、玻璃门廊
二层：茶馆、半私密茶室、靠窗座位、二层阳台
三层：台球厅、2～4 张台球桌、观赛座、约局公告牌
侧翼/后院：酒吧、吧台、小舞台、夜间庭院、户外座位
屋顶：可预约露台、灯串和观景座
```

咖啡馆偏开放和游客化，茶馆偏熟人和关系协商，台球厅偏低压力轻竞技，酒吧偏傍晚聚会、演出和公共传闻。共享后勤不等于共享访问边界。

### 5.3 社区休闲中心与运动带

16 号社区休闲中心位于工作坊南侧、居民区与运动带交界处，包含社区接待大厅、多功能活动室、公共桌游馆、社区厨房、室内运动室、居民议事室、储物和面向户外的长廊。19～22 号节点形成南部露天公共带。

运动场地不放在中央广场。中央广场负责集合、公告、偶遇和节庆通行；南部运动带负责篮球、羽毛球、排球、综合草地、慢跑、拉伸、看台、器材储藏、露天电影和社区赛事。

## 6. 四条空间环线

1. **中心商业短环**：中央广场 -> 公告栏 -> 杂货铺 -> 中央商业侧街 -> 咖啡馆 -> 工作坊 -> 河岸公园 -> 中央广场，目标 5～10 分钟。
2. **娱乐社交环**：咖啡馆 -> 茶馆 -> 台球厅 -> 酒吧后院 -> 社区休闲中心 -> 桌游馆 -> 活动草坪 -> 河岸步道，目标 8～15 分钟。
3. **滨水景区环**：河岸公园 -> 河边茶亭 -> 河湾码头 -> 木栈道 -> 观景桥 -> 西侧林缘 -> 个人外缘，目标 10～18 分钟。
4. **全镇长环**：旧车站 -> 北部森林观景环线 -> 东侧住宿坡 -> 东南山地环线 -> 南侧溪谷 -> 个人外缘 -> 河湾码头 -> 旧车站，目标 15～25 分钟。

外围路线必须有到达理由：居民住所、可预约活动、景观点、公共项目、来访请求或下一阶段扩展入口。单纯增加树木、山坡和道路不计入可玩面积。

## 7. 居民与地图状态

居民路线采用“住所 -> 工作锚点 -> 公共节点/关系会面 -> 住所或受邀活动”。路线变化必须由工作请求、体验预约、家庭关系、玩家邀约、公开事件、剧本访客、桌游排期或角色当前目标解释。客户端随机数不能独立改变居民位置。

商业、娱乐、运动和景区状态均通过同一地点/活动 authority 结算。Godot 只消费投影，不能因为本地动画、门灯、库存或 NPC 位置自行确认世界真相。

## 8. 一日与一周循环

### 上午

杂货铺、咖啡馆、工作坊、旧车站、档案馆和社区休闲中心开放；居民从住所去工作锚点；玩家处理采购、预约、公开请求、手作体验、短住登记或地方记忆查阅。

### 下午

中央商业区、河岸景区、社区活动室和运动带出现可解释活动；玩家可以拜访住宅、参加桌游教学、台球约局、运动活动或景区路线；角色可以接受、拒绝、改约或主动提出替代活动。

### 傍晚

茶馆、台球厅、酒吧后院、桌游馆、活动草坪和河岸露台形成夜间路线；朋友可以来到个人区域完成私域桌游、共建或纪念活动；活动结果回写地点投影、关系、共同记忆和下一次邀约条件。

一周同时推进居民请求线、公共设施线、社交活动线和路线记忆线。未完成内容进入下一轮生活简报，不静默重置。

## 10. 范围边界

首发明确不做 54 人同时运行近场完整 agent、54 栋完全独立住宅、全天候逐人逐帧模拟、农场、矿洞、重生产、港口、交通系统、开放世界外部区域、自由市场、价格投机、城市级供应链、酒水数值系统、体育游戏独立玩法 authority 或桌游独立 event store。
