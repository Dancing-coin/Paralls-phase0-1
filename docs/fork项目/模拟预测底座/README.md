# 模拟预测底座 fork 设计入口

状态：`analysis / design-draft / non-authorizing`

本目录探索把 Paralls 的世界、角色、司命、群体与领域 owner 基础拓展为通用模拟预测底座。金融是首个专业应用，工业和商业用于检验跨行业表达及机制组合。这里的内容是设计分析，新增能力尚无实现或运行验收结论。

## 阅读顺序

先读[模拟预测底座总纲与设计地图](00-模拟预测底座总纲与设计地图.md)：统一说明底座目标、分层、数据与社会结构骨架、显版/隐版、金融纵切、行业适配、文档依赖、实施路线和验收不变量。总纲不替代具体合同，也不代表计划能力已经实现。

再读[通用模拟底座与行业场景适配整体设计方案](04-通用模拟底座与行业场景适配整体设计方案.md)：审查并整合设计01、02、03，保留通用底座与行业适配理念及完整金融数据目录，补齐执行计划、运行模式、实时同化和组织群体交接；原三份保持不动。整体稿含审查裁决和独立三图，新增能力仍属设计草案。

1. [类型化数据底座、制度与领域语义、可插拔演化机制设计](02-类型化数据底座、制度与领域语义、可插拔演化机制设计.md)：本次新增主设计，明确三部分的类型、接口、图谱、时间和运行协作。

3. [通用底座与场景专属扩展设计](01-通用底座与场景专属扩展设计.md)：上一轮总方案，已迁移到此处；补充扩展包、场景装配、金融纵切和技术选型。

## 设计状态

- `现有可复用`：身份、角色、事件、权限边界、Heavenly Graph、领域 owner、记忆和回放等主线设施；具体接口仍需单独验证。
- `计划新增`：类型化模拟合同、FDE 适配、动态社会结构、金融数据接入、传播/撮合/多 tick、显版与隐版工作台。
- `后置验收`：真实参与者还原、跨平台身份去重、规模性能、样本外预测、因果识别和因果世界模型训练。

工业适配实例见[露天铜矿生产调度与事故应对场景适配推演](05-露天铜矿生产调度与事故应对场景适配推演.md)：五类扩展包、工业数据口径、角色与组织、图谱传播、多时钟、物理显版及假设数量算例；尚未执行工业或物理模拟。

通用空间扩展见[通用时空与适用域合同设计](06-通用时空与适用域合同设计.md)：将物理几何、拓扑网络、动态轨迹、空间场、观测覆盖、法域、组织服务域、市场域、语义域和计算域提升为跨行业一级能力。

金融行情案例见[光模块概念行情兴起与腰斩资金撤离场景推演](07-光模块概念行情兴起与腰斩资金撤离场景推演.md)：以虚构A股情景展开产业预期、角色与组织、拥挤持仓、融资及申赎、动态边、交易承接、多时钟与滚动分支；明确资金撤离和市值变化的不同口径，尚未运行金融模拟。

异质交易者审查见[交易者异质信息与决策机制及金融模拟覆盖审查](08-交易者异质信息与决策机制及金融模拟覆盖审查.md)：对照资金博弈、具体平台传播、多主体与不同决策模型的需求，补充独立信息快照、消费过程、分阶段模型与岗位程序合同；区分可表达、可执行、校准和预测有效，附独立三图与区域G概念图。

群体模拟全流程见[全流程群体模拟运行设计](10-全流程群体模拟运行设计.md)：定义 B0/B1 大规模群体覆盖、动态群体化和 B2/B3 角色与组织的精度交接；群体按时间窗和行为维度临时合并，允许乌合、分裂、脱离和再聚合，不把群体压成永久平均人；文档还描述从方案装配、点时输入、群体生成、派生图谱、信息消费、异质决策、owner 接纳、反馈同化、滚动分支到回放评估的完整运行链；当前仍是设计草案，未声称运行时已完成。
