# 模拟预测底座文档约定

本目录保存模拟 fork 的分析与设计，不属于游戏主线执行规格。遵循仓库根 AGENTS.md，本文件只补充目录规则。

- 文档使用 `NN-中文主题.md` 命名，入口由本目录 README.md 维护。跨文档引用使用相对路径。
- 分别标识现有设施、计划新增能力和后置能力；引用已有规格不等于新增机制已实现。
- 架构文档必须包含架构图、主交互时序图和数据流图；图中注明实施状态与状态写入边界。
- 类型、接口和伪代码必须标为设计示意。金融、制度、工业等扩展不能被描述为已通过验收。
- 设计分析不得隐式授权代码变更，不在本目录制造新的自动批准或执行流程。
- 保留角色私有信息、派生图谱、owner结算及revision/receipt/replay边界；扩展接纳不授予任意事实写权限。
- 更新本目录内容不自动修改游戏主线规格或既有用户文档。
