一、社会交换与互惠规则
1. 互惠记账
• 描述：角色间每一次非等价交换（赠予、帮助、人情）都会在关系中产生一笔“人情债”记录，到期未还则产生情绪和社会后果。
• 触发：任何一方发起的资源/劳务转移，且转移价值超过当前关系允许的“即时等价交换”阈值。
• 计算：
◦ 人情债额度 = 转移价值 × 关系距离系数（陌生人欠更多）
◦ 到期时间 = 基准周期 × (1 + 关系信任度) （越信任越宽松）
• 影响：
◦ 欠债方：到期未还 → 触发“违约”情绪元类型（羞愧/焦虑），关系信任下降。
◦ 债权方：到期未收回 → 触发“损失”情绪（愤怒/失望）。
• 司命介入：当人情债被某种“豪爽”方式勾销或恶意拖欠时，生成关键记忆：“老李从未还清那份恩情。”
2. 公平分配
• 描述：当多个角色共享一项收益或共同承担一项损失时，自动根据贡献度、地位、需求进行分配，并对不公产生情绪反应。
• 触发：合作生产完成、公共收益分配、战利品分割、税收分摊等。
• 计算：
◦ 应得份额 = (贡献度权重×贡献量 + 需求权重×需求强度 + 地位权重×地位值) / 总权重
◦ 实际所得与应得份额偏差超过容忍阈值 → 触发“不公”情绪。
• 参数：三种权重可由文明树、文化规范设定（如部落文明需求权重高，商业社会贡献权重高）。

◦ 模仿概率 = 观察到的行为比例 × 社会认同度（地位加权） × 角色自身从众倾向（性格参数）。

◦ 服从概率 = 权威合法性评分 × (1 - 角色叛逆特质) × 情境压力系数。

6. 损失厌恶
• 描述：等量损失带来的负效用大于等量收益带来的正效用（约2倍，可配置）。
• 触发：任何涉及风险选择的价值评估。
• 计算：决策效用 = 收益 × 1.0 + 损失 × loss_aversion_coefficient (默认2.0)。
• 应用：在交易、投资、保险购买等所有经济决策中自动生效。
7. 锚定效应
• 描述：初始接触到的数字（如最初报价、去年价格）会对后续判断产生偏向。

• 计算：估计值 = 锚定值 × 锚定权重 + 理性计算值 × (1-锚定权重)。锚定权重由认知需求（智力相关）和情境压力决定。
• 应用：议价、合同签订、资源预测。

• 计算：
◦ 采信概率：若信息符合信念，+30%修正；若不符，-30%修正。
◦ 记忆强化：符合信念的事件更容易被写入关键记忆。
• 司命介入：在顽固信念导致重大错误或人际关系破裂时，可能触发“醒悟”叙事，改写人格。

• 触发：风险评估、频率估计。
• 计算：风险估计 = 客观风险 × (1 - recency_weight) + 近期类似事件强度 × recency_weight。

一、为什么不能让智能体全程执行建造
如果让智能体一步步操作“拿起树枝→绑绳子→插进土里…”，面临三个问题：
1. 时间尺度割裂：玩家与智能体对话只需几分钟，但搭棚需要三天。让智能体在“对话时间”里完成三天劳作，世界的时间感会崩溃。
2. 资源浪费：精细的物理操作不需要语言模型参与——那不是思考，是动作序列。
3. 批量效率：可能有几十个角色同时在建造。若都用智能体，系统不堪重负。
因此，建造的执行必须留在群体模拟的程序引擎中。

1. 语义一致性规则

2. 数值平衡规则
司命赋予的新属性数值范围，由元规则根据材料、技艺、文明阶段自动限定。例如，用树枝和草席搭建的棚子，其“抗风等级”不可能超过0.3；要超过0.5，需要石材或金属框架。这些约束已编码在材料-属性映射表中，司命生成时做软约束，最终由程序夹逼。
3. 因果闭环规则
任何新属性或新资产，一旦被创建，必须反注册到效应系统和认知标签库，使其能参与未来的因果传导。例如“透光度”属性注册后，低温效应计算不仅要看抵抗值，还要联动“日光温室效应”，降低夜间失温。这由效应系统的“属性发现”协议自动处理。

五、涌现的功能：超越预设的组合
真正的塞尔达魔法在于：风扇+船帆=自动帆船。这种功能涌现不是硬编码的。
在我们的系统中，这由效应交互元规则处理：
风帆船涌现的因果链
1. 物体A（风扇）有 active_effect: {type:produce_wind, direction:backward}。
2. 物体B（帆）有 passive_effect: {type:catch_wind, direction:forward}。
3. 它们被连接到同一个刚体（船体）上。
4. 物理引擎激活时，风扇产生一个向后的持续力。帆的 catch_wind 效应检测到这个“风”的力矢量，根据自身朝向产生一个向前的推力，两者叠加作用在船体上。
5. 玩家或智能体不需要知道流体力学方程；引擎自动根据效应标签匹配实现了功能。
元规则作为“物理法则”
• 效应互作用库：系统维护一个动态的效应交互矩阵。produce_wind 对带有 catch_wind 标签的物体会产生推力，且效率由 efficiency 决定。
• 新效应注册：如果司命创造了一种新效应（如 produce_magnetic_field），它同时会在交互矩阵中注册此效应与其他材料/效应类型的互动规则（铁磁材料被吸引，产生电流等）。

这一切由经济引擎读取合约档案后自动执行。商业模式，成了世界运行的活规则。

二、事件的归属：世界之骨 vs 众生之忆
事件，必须同时存在于两个地方。
1. 世界事件档案（司命维护，不可变）
这是事件的客观骨架。记录发生了什么、因果链、受影响的事物与角色。
为什么必须由司命单独记录？
• 因果链的完整性：当反事实推演时，需要从某事件分叉。没有客观记录，历史就是一团主观迷雾。
• 子系统的通知源：新商业模式被注册时，经济子系统需要知道“有一个新合约生效了”，它不能挨个查角色记忆。
• 司命叙事的基础：生成世界新闻、文明演进史，需要一个客观时间线。
事件档案存储于世界数据库的event_log集合，是追加写入、永不修改的日志。
2. 角色记忆中的事件（个体主观，可风化）
这是事件的血肉与回声。每个亲历者根据自己的感知、认知偏误、情感，在自己的记忆库中写入一份个人版本。

3. 事件的双写协议
当事件发生时：
1. 司命生成事件档案（客观记录），写入event_log。
2. 程序将事件推送给所有受影响/亲历的角色。
3. 每个角色的感知过滤器根据其注意力、认知偏误、与事件的利害关系，决定是否生成记忆，以及记忆的内容和情感色彩。
4. 未被注意的事件不出现在角色记忆中，但仍在世界档案中。这意味着某些历史真相可能随着一代人死去而失传——这正是真实历史的质感。
4. 记忆的风化与重构
角色记忆不是永久精确的：
• 衰减：随时间推移，记忆的细节模糊，情感强度降低。
• 重构：每次回忆时，根据当前信念和情绪微调记忆内容（确认偏误）。
• 社会强化：当多人反复讲述同一事件的相似版本，记忆被加固；若社会共识改变，记忆可能被集体改写。
世界档案始终是锚点。 当司命需要生成“百年史书”时，它读的是事件档案，而非某个老人的模糊记忆。

三、两者的统一：抽象创造 + 双重记录
回到商业模式创造这个例子，完整流程是：
1. 智能体内省：掌柜老赵产生“会员制”想法。
2. 司命辅助结构化：将想法转为合约档案的各维度字段。
3. 事件生成：司命写入 Event_8473_015（商业模式诞生），客观记录在案。
4. 角色记忆注入：老赵、老石、老李等各自写入主观记忆版本。
5. 合约执行：经济引擎读取合约档案，自动执行会员折扣、分红。
6. 传播与演化：社会网络传播中，每个听到的角色写入自己的理解，可能有人模仿改良（如“铁匠铺也搞会员制”），产生新的商业模式变体。
7. 历史沉淀：多年后，若“会员制”广泛普及，司命可能将其注册为文明树的“商业制度”节点，并引用最初的事件档案作为起源故事。
