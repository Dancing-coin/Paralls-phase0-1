确保货币有基础价值根源——例如可以用它向政府缴纳资产税，否则纯投机易退化为零和赌场。

4. 成本真实化
库存有仓储成本，贷款有利息，雇佣有社保义务，机器有折旧，拒绝“空手套白狼”的永动机。
5. 玩家失败不致命
破产后可通过打工、清算重组、继承遗产等途径东山再起，保留社会关系与知识，鼓励冒险。

• 可耕种土地面积、森林覆盖率、关键矿产储量、碳排放浓度、生物多样性指数
人口与社会轴
• 总人口、劳动参与率、中位年龄、基尼系数、社会流动性指数、阶层怨恨度
政治与军事轴
• 政权合法性评分、官僚效率、腐败指数、军力投送能力、邻国敌意指数
经济轴
• GDP增速、通胀率、失业率、信贷/GDP比率、基尼系数（与经济轴共享节点，但读写角度不同）
文化与信仰轴
• 主流宗教虔诚度、教育普及率、社会信任指数、文化自信度、意识形态分裂度
知识与科技轴
• 研发投入/GDP、专利产出、关键技术就绪度（1-9级）、科学家人口占比
每个变量都是一个数值节点，有当前值、历史轨迹、以及与其他节点的因果连线。
￼
二、图谱的连线：四种基本关系类型
节点之间的关系不止“正相关/负相关”，需要定义四种基本连线类型，让图谱具备可计算性：
1. 物质流（实线，带方向）
资源的物理流动。例如：
• 矿产储量 → 工业产出（开采消耗）
• 工业产出 → 碳排放（生产排放）
• 粮食产量 → 人口容量（生存依赖）
2. 信息流（虚线，带方向）
感知与预期的传递。例如：
• 通胀率 → 消费者信心（经济信息影响心理）
• 邻国军力 → 本国威胁感知（情报影响决策）
• 科技突破新闻 → 投资者情绪（叙事影响市场）
3. 规则约束（方括号连线）
制度与法律的刚性限制。例如：
• 政权类型 → [限制] → 央行独立性（民主政体可能赋予央行更多独立）
• 科技等级 → [解锁] → 可用的金融工具（文明树的机制在此体现）
• 宗教教义 → [禁止] → 某些经济行为（如禁收利息）
4. 触发阈值（闪电符号连线）
非线性突变条件。当A超过某个临界值，触发B的质变。例如：
• 阶层怨恨度 > 阈值 → 触发革命事件（政治轴突变）
• 碳排放 > 阈值 → 触发气候灾难（生态轴突变）
• 信贷/GDP > 阈值 → 触发明斯基时刻（经济轴突变）
这四类连线，让图谱从“画着看的图”变成了可执行的因果网络。
￼
三、图谱的动态运转：基于事件的因果传导链
图谱不是静态的，它在事件驱动下运转。司命是这一过程的调度者：
1. 事件发生器
事件来源有三个：
• 智能体行为：某个AI角色或玩家的重大决策（宣战、发明、改革）
• 轴内自发：阈值触发（人口自然增长触及资源上限）
• 外部注入：接入的真实世界数据，或设计师预设的“天道事件”
2. 传导算法（涟漪扩散）
当一个节点数值变化超过预设的“敏感性阈值”，司命执行传导：
1. 定位：在图谱中定位该节点所有出向连线。
2. 计算：根据连线类型计算影响：
◦ 物质流/信息流：用弹性系数（如“矿产减少10% → 工业产出减少3%”）
◦ 规则约束：直接生效（“科技5级 → 解锁期货市场模块”）
◦ 触发阈值：检测条件，决定是否引爆
3. 传播：更新目标节点值，如果目标节点变化也超过阈值，递归传导。
4. 衰减：每次传导引入衰减系数（0.7-0.95可配置），防止无限震荡。传播超过3-5跳后，影响通常已微乎其微。
3. 一个具体例子：玩家推动“蒸汽机发明”
1. 初始事件：科技轴“蒸汽机技术”状态从“未解锁”变为“已应用”。
2. 第一波传导（信息流 + 规则约束）：
◦ 蒸汽机 → [解锁] → 工厂制度（经济文明树节点激活）
◦ 蒸汽机 → [解锁] → 铁路运输（物流效率节点激活）
3. 第二波传导（物质流）：
◦ 铁路运输效率↑ → 粮食运输成本↓ → 城市粮食供给↑ → 城市人口容量↑
◦ 工厂制度激活 → 工厂生产效率↑ → 工业产出↑ → 煤炭需求↑
4. 第三波传导（信息流 + 阈值检测）：
◦ 工业产出↑ → 经济增长预期↑ → 投资者情绪↑（可能触发投机泡沫阈值）
◦ 煤炭需求↑ → 煤矿工人需求↑ → 农村人口向城市迁移 → 城市化率↑ → 传统乡村社会结构动摇（社会轴）
5. 第四波传导（规则约束 + 触发）：
◦ 城市化率↑ + 传统社会结构动摇 → 阶层怨恨度↑（检测是否触发劳工运动）
◦ 工厂制度 → 童工问题 → 触发“社会改革法案”政治事件
一次科技突破，经过图谱的传导，最终可能引爆一场社会革命。这就是六轴联动的威力。

四、司命的角色：图谱的调度者与调谐者
在这个动态图谱中，司命有四重职责：
1. 图谱的维护者
• 保存图谱的完整拓扑结构（所有节点和连线）
• 记录每条连线的弹性系数、衰减系数、传导延迟

2. 传导的调度者
• 维护一个“事件队列”，按优先级处理因果传导
• 防止循环传导死锁（如通胀→加息→经济减速→降息→通胀），设定“一个事件链中同一节点只能被触发两次”的保护机制

3. 涌现的观察者
• 监控图谱的全局模式，识别新涌现的“正反馈环”（如“工资-物价螺旋”）
• 记录大型事件链的完整传导路径，形成“历史档案”
• 在推演模式下，这提供了完整的因果审计线索
4. 参数的进化者
• 允许某些连线系数通过“经济自然选择”缓慢调整
• 例如：经历多次金融危机的文明，其“信贷扩张→泡沫破裂”的敏感性系数会逐渐降低（社会学会了监管），这模拟制度学习

• 核心特征：可数值化、有明确因果关系、可并发安全更新。
• 包含模块：
◦ 基础生理与状态：年龄、健康、精力、饥渴、疲劳等。

◦ 技能与职业：技能等级、当前职业、职位、工资率。
◦ 宏观身份标签：纳税人等级、选民资格、法律状态（是否在逃、被通缉）。
◦ 心智表层数值：短期需求数值（饥饿、安全、社交等）、情绪维度分值（焦虑、希望、愤怒等，但不包括其生成理由）。

二、程序化更新的设计：批量写入引擎
所有结构化域的更新，都通过一个角色状态更新器完成，该更新器在群体模拟的每一层被调用。
