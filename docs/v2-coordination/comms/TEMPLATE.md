# 交流记录模板

> **已于 2026-11-22（协议版本 2）取消：不再要求交流记录。保留模板仅供历史。**

复制为 `comms/YYYY-MM-DD-thread-a.md` 或 `comms/YYYY-MM-DD-thread-b.md`。每位负责人只写自己参与的沟通；同一场对话两边各记一份。

规则（PROTOCOL.md 第三节）：聊天没有约束力；涉及独占文件、共享机制、基线失败节点合同的结论必须落成请求、回应或 claim；当天合并前补记；**禁止写入令牌、密钥、凭证、私人信息**，出现时只写"已省略"；对方的话记为"对方称……"。

## 条目格式

```
## HH:MM | 对方：<姓名或角色> | 渠道：<通讯软件>
- 议题：
- 结论或待办：
- 关联编号：R-B-xxx / C-A-xxx / C-B-xxx（没有则写"无"）
- 决定性原话（逐字，仅涉及决定时）：
```
