## 分层原则

- `整体架构.md`：仓库级总纲，覆盖运行时、非运行时支撑面和验证体系。
- `运行时/运行时总览.md`：运行时级总纲，只讨论运行时内的结构、时序和数据流。
- `运行时/图表/`：只放跨域可渲染图。
- `运行时/模块/`：按 owner 或运行时模块拆分的局部文档。
