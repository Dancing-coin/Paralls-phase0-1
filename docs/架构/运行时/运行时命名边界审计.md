# 运行时命名边界审计

日期：2026-07-01

状态：当前运行时架构文档

本文记录当前仓库中 `Runtime` 命名的边界，避免把服务、子系统、registry、
projection、router、provider、contract 或 verifier 误命名为运行时主机。

## 命名规则

只有同时拥有 tick/cadence、生命周期或会话连续性、以及多个子服务编排职责的模块，
才可以命名为 `Runtime`。

`RuntimeState` 只允许用于状态对象。普通服务、子系统、注册表、投影、路由、provider、
契约和验证器不应被命名成 runtime host。

## 审计表

| 当前或历史名称 | 职责 | 是否应为 runtime | 规范名称 | 当前是否已改 | 迁移风险 |
| --- | --- | --- | --- | --- | --- |
| `CharacterAgentRuntime` | 角色 loop、cadence、continuity 和服务编排 | 是 | 保留 | 否 | 低 |
| `SimingRuntime` | Siming 高层 loop、候选处理和 read-model 编排 | 是 | 保留 | 否 | 低 |
| Godot runtime / `*RuntimeProbe.gd` | Godot 场景执行和运行时验证 | 场景/probe 语境下是 | 保留 | 否 | 低 |
| `SessionRuntime` | 结构化玩家输入路由和小型位置 cache | 否 | `SessionInputRouter` | 是，保留兼容别名 | 低 |
| `RuntimeSpatialOccupancyField` | 动态 L1 occupancy state model | 否 | `SpatialOccupancyField` | 是，保留兼容别名 | 低 |
| `RuntimeSpatialOccupancyService` | L1 occupancy update service | 否 | `SpatialOccupancyService` | 是，保留兼容别名 | 低 |
| `CharacterRuntimeState` | Godot 角色状态对象 | 仅状态对象 | 保留，但限定为 state-only 边界 | 否 | 低 |
| `CharacterGameRuntimeState` | 版本化 Gameplay state-group 读取 facade | 仅状态对象 / facade | 保留，但不可表述为 runtime host、aggregate root 或写入口 | 否 | 低 |
| `GameplayEventStore` / `GameplayOutboxDispatcher` | 玩法领域的 committed-event/replay source 与 commit 后投递 | 否 | 保留现名；它们是 authority substrate，不是新的 runtime | 否 | 低 |
| `CharacterEmbodimentAssetRuntime` | 资产 registry、preload 和 realization planning API | 否 | `CharacterEmbodimentAssetRegistry` | 是 | 中；旧 GDScript 路径已移除 |
| `l1-world-fact-runtime` | Harness 验证 profile | 不是产品级 runtime | 仅作为兼容 profile 名称 | 已在文档澄清 | 低 |
| `L1 runtime` 计划措辞 | L1 world fact services/subsystem integration | 否 | `System L1 world fact subsystem` / runtime-facing L1 services | 是 | 低 |
| `ESMService` | Authority settlement service | 否 | 保留 `ESMService` | 否 | 低 |

## 硬边界

- 不新增 L1 main loop。
- 不新增 L1 event bus。
- 不新增 L1 scheduler。
- 不新增 L1 authority。
- 不绕过 `raw_fact_event -> candidate percept -> CharacterPerceivedEvent`。
- 不把 ESM 变成 runtime host。
- 不把 `CharacterGameRuntimeState`、Gameplay event store 或 outbox 改称独立 Gameplay runtime。
