## 文档完成定义

一个运行时 feature 只有同时记录下面内容，才算文档完整：

1. 当前运行时 owner
2. 明确的 non-owner / forbidden authority
3. source input shape
4. 后端 data object 或 Pydantic model
5. 适用时的 Godot message 或 signal
6. downstream consumer
7. compatibility path status
8. verification profile
9. report artifact path
10. 已知 degraded / unverified state
