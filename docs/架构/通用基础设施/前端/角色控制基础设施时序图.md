# 角色控制基础设施时序图

## 当前静态追加人物

```mermaid
sequenceDiagram
    participant Scene as 场景装配 current
    participant Old as 原有人物 current
    participant New as 新 CharacterActor current
    participant Adapter as 包表现适配器 current
    participant Registry as 资源 Registry current
    participant Control as 控制基础设施 current
    Note over Scene,Old: 原三人身份和资源包保持不变
    Scene->>New: 追加独立人物和 GLB 设置独立 actor_id
    New->>Adapter: 子节点 ready
    Adapter->>Adapter: 读取包朝向或显式校准 绝对设置视觉偏移 current
    Note over New,Adapter: 非法校准停止表现初始化 控制名单接纳门禁仍 planned
    Adapter->>Registry: register_project_presentation_package
    Registry->>Registry: 检查模型摘要和资格报告
    Registry->>Registry: 登记真实骨架映射和原生动作库
    Registry-->>Adapter: accepted 或 reason
    alt 检查通过
        Adapter->>Adapter: 挂载动作库和初始化表现
    else 检查失败
        Adapter->>Adapter: 当前只报错 仍继续初始化
        Note over New,Adapter: 阻止接纳并释放候选实例 planned
    end
    Scene->>Control: bind(root)
    Control->>Control: 扫描 root 内组成员 并选择索引 0
    Note over Control: 后加入人物的增量发现 planned
```

## 计划的接纳流程

```mermaid
sequenceDiagram
    participant Project as 项目装配 planned
    participant Registry as Registry current API / planned 配置注入
    participant Scene as 目标场景
    participant Control as 控制名单 planned 增量接口
    Project->>Scene: 检查独立 actor_id 和出生配置
    alt 身份冲突
        Scene-->>Project: 拒绝 不覆盖原人物
    else 身份独立
        Project->>Project: 在控制名单外准备候选人物
        Project->>Registry: 检查或复用骨架和动作库接纳
        Registry-->>Project: 资源接纳结果与能力范围
        alt 资源接纳失败
            Project->>Project: 释放候选 返回 reason
        else 资源接纳成功
            Project->>Scene: 追加独立人物
            Project->>Control: 加入人物 保留已有选择
            Control-->>Project: 新增成功
        end
    end
    Note over Project,Scene: 无显式替换请求 不修改已有实例
```

自动批量异骨架重定向为 deferred，不在场景启动时隐式执行。

## 控制执行

```mermaid
sequenceDiagram
    participant Source as Control Source
    participant Foundation as CharacterControlFoundation
    participant Port as CharacterControllerPort
    participant Actor as CharacterActor
    participant Motor as CharacterMotor
    participant Presentation as Presentation Runtime
    participant Authority as Backend Authority

    Source->>Foundation: sample or goal adapter output
    Foundation->>Port: normalize intent
    Port->>Actor: submit control intent
    Actor->>Actor: arbitrate action and update runtime state
    Actor->>Motor: apply movement and root contribution
    Motor-->>Actor: motion state / collision result
    Actor->>Presentation: semantic action and state
    Presentation-->>Actor: marker / root contribution
    Note over Actor,Presentation: current 包适配器转 Actor 本地 delta Actor 再转世界 视觉校准只应用一次
    Actor->>Authority: structured world-changing request (when needed)
    Authority-->>Actor: authority result or rejection
    Actor->>Presentation: hit / recovery / confirmed result
```
