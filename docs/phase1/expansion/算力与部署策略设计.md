# 创造算力与部署策略设计

## 状态

- 状态：expansion 子文档（新建）
- 覆盖轮次：`431-437`

## 1. 目标

冻结创造系统在 Phase 1 的算力分配、硬件覆盖与成本边界。

## 2. 计算分配策略

- 不采用绝对本地优先
- 启动先评估 GPU/CPU/内存/NPU/网络
- 按任务等级分配本地/云端/混合执行

## 3. 覆盖与兜底

- 主流硬件最低准入线
- 低于准入线设备走云游戏兜底

## 4. 成本边界

- 常规经营算力：谁经营谁承担
- 云游戏基础设施：平台统一供给与运维

## 5. 优化节奏

- Phase 1 做必要基础优化
- 深度硬件优化后置
- 关键扩展接口前置冻结（模型切换/画质分级/物理精度）

## 6. 架构一致性

云地切换只改变部署路径，不改消息语义与职责边界。
