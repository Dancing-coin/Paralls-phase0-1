# 世界创建与地图映射系统设计

## 状态

- 状态：expansion 子文档（新建）
- 覆盖轮次：`408`、`416`、`419`

## 1. 分层定义

- 场景级：局部空间创建、落地执行、场景蓝图化
- 世界级：多场景编排、全局规则、地图组织

## 2. 映射对象

- 场景状态映射
- 世界地图映射
- 资产实例映射

## 3. 冲突治理

冲突优先级：

1. 世界级规则
2. 授权约束
3. 场景级本地改动
4. 运行时临时状态

自动合并失败：

- 必须进入审核工单，不允许静默覆盖。

## 4. 回写边界

- 允许：实例状态回写实例层。
- 禁止：运行时直接篡改模板层。

## 5. 目标阈值

- 自动合并成功率 `>=90%`（同层且无权限冲突）
- `P1/P2` 工单闭环 `P95 <= 30 分钟`
