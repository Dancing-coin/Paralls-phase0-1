# 创造系统总纲

## 状态

- 状态：core 体系拆分版（总纲）
- 覆盖轮次：`406-450`（当前已产出 `406-437`，按相邻规则已核 `401-405`）
- 说明：本总纲只做能力分层与边界冻结，详细协议与实现映射下沉到子文档

## 1. 总体定位

“创造系统”是《开本》里所有“可创建、可配置、可实例化、可演化”的系统集合。

世界创建只是创造系统中的一个子域，不再与“创造系统”并列混写。

## 3. 跨文档统一规则

- 后轮覆盖前轮：同议题以后期轮次为准。
- 创作者层与玩家层权限必须隔离。
- 云地调度变化不能改写消息语义边界。
- 协议字段以 `08-V1联调映射表-创造系统` 为实现对接主口径。

## 4. 与其他 core 的接口

- `技术架构总纲`：读取创造系统边界与运行时职责。
- `核心玩法机制设计`：读取玩家可做/不可做与任务链约束。
- `商业与生态设计`：读取蓝图授权、导入服务与成本拆账边界。
- `Phase 1 项目计划书`：读取可交付闭环与验收指标。

## 5. 当前冻结结论

- `406-450` 目录下当前已产出的创造能力（`406-437`）已拆分为多核心文档承载，不再由单文档吞并。
- `D104-D108` 仍是创造系统的首要骨架；`D109-D119` 作为创造表现与部署扩展并入同一系统族。
