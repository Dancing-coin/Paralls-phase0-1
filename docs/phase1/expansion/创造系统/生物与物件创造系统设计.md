# 生物与物件创造系统设计

## 状态

- 状态：expansion 子文档（新建）
- 覆盖轮次：`409`、`417-418`

## 1. 目标

冻结生物与物件创造的三层链路，并明确创作者层与玩家层权限隔离。

## 2. 三层创造链路

- 形态层：外观、部件、骨架、过渡素材
- 参数层：属性模板、材料参数、交互标签
- 行为层：生长、繁殖、组装、安装规则

## 3. 权限边界

- 创作者/大玩家：可定义与编辑底层模板
- 玩家：仅可在授权边界内使用、培育、组合
- 玩家不可越权改写底层模板与全局规则

## 4. 与 ESM 边界

- ESM 负责行为层执行与状态结算
- 本文档负责行为规则如何映射为 ESM 可执行输入
- Phase 1 不前置完整生长/繁殖生态

## 5. 与 L3 边界

- 有中间态变化数据：可接入点云过渡
- 无中间态变化数据：交由视觉障眼法做表现过桥
