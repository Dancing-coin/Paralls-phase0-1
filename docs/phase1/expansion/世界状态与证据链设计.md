# 世界状态与证据链设计

## 状态

- 当前状态：第一轮可执行整理稿
- 主要用途：统一 ESM、物体状态、痕迹、证据闭环与 Phase 边界
- 事实口径：以 `filtered_conversation_split` 为唯一主源；同议题以后期轮次为准

## 当前冻结结论

- ESM 是 L1 的独立确定性环境状态管理器，不属于司命，也不依赖 LLM
- 证据链不能并入单一系统，当前应拆为 ESM、物品流转追踪器、接触痕迹管理器、生物痕迹管理器、司命事实核心
- 事件总线负责分发，不负责证据真值判定
- 销毁证据不是信息黑洞，销毁行为本身必须继续产生新的可推理后果
- 当前 Phase 1 重点是“证据链完整闭环”，不是“完整环境物理世界”

## 1. 文档目标

本文档用于把《开本》中与“世界状态变化”和“证据形成、传播、破坏、推理”直接相关的系统统一整理为一个可开发边界。它回答五个问题：

1. 世界中的物理变化由谁负责。
2. 可见物证、不可见痕迹、叙事矛盾分别由谁负责。
3. 玩家行为如何从 L1 事件变成可推理证据。
4. 证据如何共享、展示、销毁与再生产。
5. Phase 1 到底做到什么程度，哪些要后移。

## 3. 核心修订点

### 3.1 从“谁都能记一点”改为“职责硬拆分”

前期讨论里，ESM、事件总线、司命都曾短暂承担过“记录证据”的含混职责。到 `307` 后，边界已经比较稳定：

- ESM 负责物理状态变化与环境确定性演化
- 物品流转追踪器负责物体的归属、位置和转移历史
- 接触痕迹管理器负责指纹、纤维、唾液、汗液等接触遗留
- 生物痕迹管理器负责血迹、毛发、皮屑等生物遗留
- 司命事实核心负责时间线矛盾、说法冲突、知识状态和叙事逻辑一致性

### 3.2 从“证据被销毁就没了”改为“销毁本身也会留下链条”

后期稳定结论是：销毁、焚烧、浸泡、擦拭、移走，都不能成为信息黑洞。它们本身会制造：

- 新的物理残余
- 新的时间线空洞
- 新的目击可能
- 新的知识不对称
- 新的行为成本与嫌疑指向

### 3.3 从“完整环境模拟必须 Phase 1 实现”改为“证据闭环优先，完整物理后移”

`400` 明确收束后，Phase 1 当前必须冻结的是：

- 证据链完整闭环
- 与侦探玩法相关的环境状态最小必要能力

而不是：

- 完整天气系统
- 完整材质库
- 生物成长系统
- 点云过渡驱动的全环境连续变化

这些属于更完整的 ESM 扩展，整体后移到 Phase 2/3。

## 4. 系统边界总览

### 4.1 ESM

职责：

- 管理场景中对象的确定性状态
- 处理材质、容器、可燃、可破坏、可浸泡、可开闭等规则
- 在毫秒级尺度演算状态切换
- 向事件总线上抛精确状态变化事件

不负责：

- 推理谁更可疑
- 判定某个说法在叙事上是否矛盾
- 直接维护玩家知识图谱
- 直接生成高层叙事结论

### 4.2 物品流转追踪器

职责：

- 记录物品从哪里来、被谁拿过、何时转移、当前在何处
- 为“谁接触过这件物品”提供基础时间线
- 支撑物品展示、移交、藏匿、抛弃等行为的可追踪性

不负责：

- 判定接触时留下了什么痕迹
- 判定物理变化是否可见

### 4.3 接触痕迹管理器

职责：

- 记录角色与物体/场景发生接触后可能留下的接触性遗留
- 支撑指纹、纤维、手套残留、唾液、汗液等可检验痕迹
- 处理“是否覆盖前痕迹、是否被擦拭削弱”的规则

### 4.4 生物痕迹管理器

职责：

- 记录血迹、毛发、皮屑、体液等生物来源证据
- 支撑受伤、拖拽、搏斗、暗杀、急救后的证据残留

### 4.5 司命事实核心

职责：

- 统一存储本局事实真相和高层矛盾
- 比对证词、行动记录、可见证据与逻辑闭环
- 判断某条证据暴露后，对知识状态与剧情张力的影响

## 5. 证据形成链路

单条证据通常按以下顺序形成：

1. 玩家或 AI 角色在 L1 发起动作。
2. ESM 先处理确定性状态变化。
3. 事件总线广播精确事件给对应子系统。
4. 流转追踪器、接触痕迹管理器、生物痕迹管理器各自更新。
5. 司命事实核心接收结构化变化，刷新知识图谱与矛盾图。
6. 玩家与角色只能通过各自感知和共享方式逐步接近这些证据，而不是直接读取系统真值。

## 6. 证据类型分层

### 6.1 物理状态证据

例子：

- 门被撬开
- 棉花被焚烧后再浸湿
- 烛台表面有熔蜡与碰撞痕迹

主要责任系统：ESM

### 6.2 流转证据

例子：

- 打火机原本在谁的背包里
- 凶器何时离开了陈列柜
- 留影石经过了哪些人之手

主要责任系统：物品流转追踪器

### 6.3 接触证据

例子：

- 某人摸过门把手
- 某人搬运过箱子
- 某人戴手套使用过物件

主要责任系统：接触痕迹管理器

### 6.4 生物证据

例子：

- 地面血滴
- 衣袖上的皮屑
- 打斗后留下的毛发

主要责任系统：生物痕迹管理器

### 6.5 叙事矛盾证据

例子：

- 角色声称没去过某房间，但流转与接触链说明其去过
- 角色声称案发时独处，但被目击逻辑推翻
- 被销毁的证据导致新的时间线空窗

主要责任系统：司命事实核心

## 7. 信息共享与证据传播

证据并不天然变成公共事实，它必须通过当前冻结的信息共享执行系统传播。当前统一口径：

- 公开对话
- 耳语 / 私密对话
- 展示物品
- 带人查看
- 留影石 / 相机拍摄

对应知识状态：

- 公共知识
- 共有知识
- 高阶知识

这意味着“发现证据”和“让别人知道证据”是两步，不能混写。

## 8. 留影石 / 相机的定位

留影石 / 相机不是证据系统本体，而是证据记录与传播工具。它的职责是：

- 把某一时刻的可见证据冻结成可转移的记录媒介
- 扩展展示、移交、私下分享的方式
- 增加“拍摄是否被看到、记录是否被偷走、照片是否被销毁”的二次博弈

当前不应把它写成所有证据都依赖的前提条件。

## 9. 销毁、破坏与伪造原则

### 9.1 销毁

任何销毁行为都必须继续留下至少一类后果：

- 物理残余
- 时间线空洞
- 目击风险
- 行为痕迹
- 失败痕迹

### 9.2 破坏

破坏不是“删除信息”，而是把原始证据转化为另一种证据状态。

### 9.3 伪造

Phase 1 可保留基础伪造空间，但不应要求完整伪装物理系统。当前更现实的范围是：

- 对外说法伪造
- 公开档案伪装
- 局部物品摆放与展示误导

更完整的道具级伪装与复杂压力系统后移。

## 10. Phase 1 边界

### 10.1 Phase 1 必做

- 关键物体的确定性状态变化
- 物品流转可追踪
- 接触与生物痕迹最小闭环
- 证据可发现、可展示、可转移、可销毁
- 销毁产生新后果
- 司命可基于证据链发现叙事矛盾

### 10.2 Phase 1 不必完整实现

- 全环境连续点云过渡
- 大规模天气联动
- 生物成长生态
- 高复杂度材料化学链
- 全场景普适取证精度
