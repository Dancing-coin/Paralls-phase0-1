# 证据与痕迹系统设计

## 状态

- 状态：第一版收敛稿；当前保留在 `expansion`，作为侦探玩法绑定系统的专题设计文档
- 主来源轮次：`304-307`、`309-310`、`351-357`、`400`
- 补充来源轮次：`303`、`398`
- 采信约束：仅以 `filtered_conversation_split` 为源；整理时必须核对目标轮次前后相邻文档，若相邻轮次仍在连续讨论同一议题，则继续向外扩展，直到议题边界清晰；同议题以后轮次覆盖前轮次

## 当前冻结结论

- 证据系统不能由单一系统吞并，必须拆为五层职责
- `ESM` 只负责物理状态变化，不负责物证解释
- 物品流转、接触痕迹、生物痕迹都需要独立持久化子系统
- 司命事实核心负责把状态变化、流转记录和角色声称对比为事实链与矛盾链
- 角色智能体 `L2` 负责把自己感知到的证据解释成推论
- 销毁证据不是信息黑洞，销毁行为本身必须生成新的可推理后果
- 证据可视化只处理视觉可见证据，且必须由玩家主动触发

## 2. 时间线覆盖说明

### 2.1 职责纠偏阶段

- `304`：明确 `ESM` 不“生成物证”，只忠实记录和上报物理状态变化
- `305`：进一步收束“指纹等微观痕迹不属于 `ESM`”，并区分宏观物理变化与微观痕迹
- `306`：明确接触痕迹不能只依赖事件总线，必须建立独立接触痕迹管理器
- `307`：首次系统化整理证据类型与负责系统，形成五层职责骨架

### 2.2 视觉化与玩法分层阶段

- `309`：建立“视觉可见证据才可图片化，且必须由玩家主动触发”的证据可视化边界
- `310`：把物品流转、接触痕迹、生物痕迹、时间线矛盾明确归入侦探玩法绑定系统，同时保留 `ESM` 作为全玩法通用底座

### 2.3 销毁证据闭环验证阶段

- `351`：用“棉花燃烧后入水”展示状态变化链可被完整记录
- `354-355`：在剧本推演中验证“销毁证据本身形成新的证据链”
- `356-357`：修正“只能通过煅烧销毁血迹”等不合理推理，强化“销毁行为本身留下残骸、氧化、目击、气味和时间线后果”的闭环

### 2.4 当前采用规则

- 五层职责骨架，以 `304-307` 为准
- 可视化边界，以 `309-310` 为准
- 销毁后果闭环，以 `351-357` 和 `400` 为准

## 3. 核心原则

### 3.1 证据不是单一对象，而是分层链条

证据至少分为：

- 物理状态变化
- 流转历史
- 接触痕迹
- 生物痕迹
- 时间线矛盾
- 人证与知识状态

### 3.2 解释与记录分离

当前必须严格区分：

- 物理记录
- 痕迹记录
- 事实比对
- 角色推理

不能把记录层和解释层混写。

### 3.3 销毁也是证据

这是当前必须冻结的上位原则。

任何销毁行为都不能成为信息黑洞。

烧毁、砸碎、清洗、隐藏、伪造，都必须留下：

- 残骸
- 残留
- 目击
- 气味
- 时间线矛盾
- 归属与流转历史
- 行为痕迹

### 3.4 证据图片不是自动全发

只有视觉可见证据，且在玩家主动操作时，才允许进入可视化链路。

## 4. 五层职责拆分

### 4.1 ESM

负责：

- 宏观物理状态变化
- 状态机执行
- 烧毁 / 破碎 / 潮湿 / 结冰 / 弯曲等状态历史

不负责：

- 指纹
- 血迹解释
- 物品归属
- 时间线矛盾判断

### 4.2 物品流转追踪器

负责：

- 谁拾取 / 移交 / 丢弃 / 放回了什么
- 物品从哪里到哪里
- 每次转移的时间与位置

定位：

- 独立持久化查询系统
- 不应只作为事件总线里的瞬时消息存在

### 4.3 接触痕迹管理器

负责：

- 指纹
- 唾液
- 汗渍
- 衣物纤维
- 皮肤细胞等接触痕迹

必须支持：

- 持久化
- 结构化查询
- 可见性判定
- 生命周期管理

### 4.4 生物痕迹管理器

负责：

- 血迹
- 毛发
- 皮屑
- 其他生物残留

与接触痕迹不同点：

- 产生机制不同
- 状态变化受环境影响更强
- 与伤害 / 死亡 / 环境变化更强耦合

### 4.5 司命事实核心

负责：

- 将 `ESM` 状态变化写入事实链
- 将流转记录写入时间线
- 将角色声称与物理事实对比
- 标记矛盾、疑点和待解释事实

### 4.6 角色智能体 L2

负责：

- 感知自己可知范围内的证据
- 解释其意义
- 更新怀疑、信任、推论与记忆

## 5. 各类证据的负责系统

| 证据类型 | 负责系统 | 当前说明 |
| :--- | :--- | :--- |
| 物体烧毁 / 破碎 / 潮湿 / 结冰 | `ESM` | 宏观物理状态变化 |
| 物品位置变化 / 归属转移 | 物品流转追踪器 | 持久化流转历史 |
| 指纹 / 唾液 / 汗渍 / 纤维 | 接触痕迹管理器 | 接触行为副产品 |
| 血迹 / 毛发 / 皮屑 | 生物痕迹管理器 | 生物残留副产品 |
| 不在场证明矛盾 | 司命事实核心 | 声称 vs 事实对比 |
| 人证 | 角色记忆系统 | 来自角色自身感知与记忆 |
| 证据图片 | `L3` 证据可视化 | 仅处理视觉可见证据 |

## 6. 数据流转

### 6.1 宏观链路

```text
L1 / 玩家 / AI 行为
  -> 事件总线
  -> ESM / 物品流转 / 接触痕迹 / 生物痕迹各自记录
  -> 司命事实核心整合并比对矛盾
  -> Per-Character 感知过滤器分发给角色
  -> 角色 L2 形成推论
```

### 6.2 例子：上校点燃窗帘

- `ESM`：窗帘从默认态到燃烧态再到烧毁态
- 物品流转追踪器：打火机从背包到手中再返回
- 接触痕迹管理器：打火机留下接触记录
- 司命事实核心：将上校声称的位置与实际使用打火机位置对比成矛盾
- 角色 `L2`：基于自己感知到的火灾与行为推理纵火嫌疑

## 7. 接触痕迹管理器

### 7.1 为什么不能只靠事件总线

事件总线只适合：

- 实时通知
- 路由
- 重放入口

不适合：

- 长期查询“谁碰过这个物体”
- 业务级可见性判定
- 生命周期管理

### 7.2 接触痕迹管理器的职责

- 持久化存储
- 结构化查询
- 痕迹分类
- 可见性判定
- 生命周期管理

### 7.3 典型生成规则

- 手持物品：生成指纹，除非戴手套
- 口唇接触：生成唾液
- 搏斗推搡：生成皮肤细胞与纤维
- 受伤接触：可叠加血迹
- 长时间持有：可生成汗渍或磨损特征

## 8. 生物痕迹管理器

### 8.1 管理对象

- 血迹
- 毛发
- 皮屑
- 其他生物残留

### 8.2 与 ESM 的边界

例如：

- `ESM` 记录“刀被加热”“窗帘被烧毁”“水缸温度上升”
- 生物痕迹管理器记录“血迹是否仍可检测、是否被高温破坏、是否被水冲淡”

### 8.3 与环境联动

生物痕迹状态会被：

- 高温
- 水
- 风
- 时间
- 物体表面材质

影响。

但“影响规则的执行”与“痕迹记录”仍应拆分：

- `ESM` 负责环境状态变化
- 生物痕迹管理器负责痕迹状态更新

## 9. 物品流转追踪器

### 9.1 记录内容

- 原位置
- 新位置
- 持有者
- 转移方式
- 时间戳
- 目击与否

### 9.2 用途

- 查询凶器曾被谁拿过
- 查询证据是否被转移、调包、隐藏
- 为销毁证据后的间接推理提供归属历史

## 10. 司命事实核心在证据链中的职责

### 10.1 不是直接产证据

司命不产生物理证据。

它做的是：

- 汇总
- 写入
- 对比
- 标记矛盾

### 10.2 典型输出

- 某人声称在包厢，但其打火机在餐车被使用
- 某封信已被烧毁，但烧毁前曾被某角色发现并持有
- 某把刀已经被高温处理，直接血迹消失，但残骸颜色异常且流转历史异常

## 11. 销毁证据闭环

### 11.1 当前采用原则

销毁不是“删除信息”，而是“把信息从一种形态转成另一种形态”。

### 11.2 销毁后的可推理后果

至少包括：

- 残骸
- 灰烬
- 氧化
- 断裂
- 目击者
- 气味
- 烟雾 / 热感
- 时间线矛盾
- 流转历史

### 11.3 剧本推演验证结果

`354-357` 已经把这条原则验证得很明确：

- 血迹和指纹可以被高温破坏
- 但凶器氧化变色、销毁动作被感知、流转历史仍存在
- 最终仍会形成间接证据链

### 11.4 当前不得采用的旧理解

后续文档不得再写成：

- 证据烧掉就彻底没了
- 证据砸碎就无法追查
- 证据销毁只要成功就不会留下任何后果

## 12. 证据可视化边界

### 12.1 什么能图片化

适合图片化：

- 烧毁物体
- 破碎物体
- 宏观血迹
- 毛发
- 物品外观细节
- 满足条件时的微观痕迹

不适合图片化：

- 时间线矛盾
- 人证陈述
- 动机判断
- 逻辑结论

### 12.2 触发条件

必须由玩家主动触发，例如：

- 观察
- 凝神深度观察
- 拍摄
- 公开展示
- 私下分享

### 12.3 信息边界

- 公开展示：在场者获得图片
- 私下分享：只有接收方获得图片
- 私密观察：只有观察者自己获得图片

## 13. Phase 1 边界

### 13.1 当前必须进入 Phase 1 的

- 五层职责拆分
- 基础流转历史
- 基础接触痕迹
- 基础生物痕迹
- 司命事实对比与矛盾标记
- 销毁证据闭环

### 13.2 当前不必全量展开的

- 复杂取证小游戏
- 完整法医分析链
- 超高精度微观图像体系
- 更复杂的跨局证据继承

## 14. 当前统一口径

后续所有文档提到证据与痕迹系统时，应统一采用以下口径：

- 证据系统不能被单一系统吞并
- `ESM` 只负责宏观物理状态变化
- 物品流转、接触痕迹、生物痕迹必须分层独立持久化
- 司命事实核心负责把各类记录整合成事实链与矛盾链
- 角色智能体 `L2` 负责解释自己感知到的证据意义
- 销毁行为本身必须生成新的可推理后果
- 证据可视化只处理视觉可见证据，且必须由玩家主动触发

## 15. 延后项

当前不在本版冻结范围内：

- 证据系统的外部编辑器
- 更复杂的法医检验玩法
- 跨剧本证据继承
- 更高精度的痕迹图像化与自动归档体系
