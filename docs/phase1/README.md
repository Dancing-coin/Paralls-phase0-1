- `core`（Phase 1 必做）

    - 产品白皮书
    - 技术架构总纲
    - Godot源码底层基础设施与运行时约束
  - `01-运行时核心`
    - 司命设计文档
    - 角色智能体设计文档
    - 角色智能体/00-角色智能体总索引
    - 事件总线与感知链路设计
    - 视觉事实系统/00-视觉事实系统总索引
    - 信息共享与知识状态设计
    - ESM设计文档
  - `03-玩法与内容`
    - 核心玩法机制设计
    - 目标与任务系统设计
    - 剧本创作模板
    - AI陪伴与小世界设计
  - `04-商业与阶段`
    - 商业与生态设计
    - Phase 1 项目计划书

- `expansion`（Phase 1 扩展 / Phase 2+ 预留）
  - `02-创造系统`
    - 创造系统总纲
    - 建筑建造与蓝图系统设计
    - 世界创建与地图映射系统设计
    - 生物与物件创造系统设计
    - 创造运行时与规则封装设计
    - 创造表现层（L3）设计
    - 创造算力与部署策略设计
  - 世界状态与证据链设计
  - 证据与痕迹系统设计

## 规则

- `core` = Phase 1 必做。
- `expansion` = Phase 1 可选扩展或 Phase 2+ 预留，不作为 Phase 1 验收硬门槛。
- `phase0` = 进入 Phase 1 完整闭环前的预验证 demo 轨。
- 新文档先判定是否为 Phase 1 必做，若不是，默认放 `expansion`。
- 所有目录调整后，必须同步 `docs/consolidation/04-Phase映射表.md`。
