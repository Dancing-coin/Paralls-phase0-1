# 目标与任务系统设计

## 状态

- 当前状态：第一轮可执行整理稿
- 主要用途：统一目标中立、任务结构、共同目标 / 个人目标关系、阵营形成逻辑与特殊人群定位
- 事实口径：以 `379-400` 这一阶段的后期收束为当前冻结版

## 当前冻结结论

- 核心系统必须目标中立，不能只服务追凶
- 个人目标是角色设计的必需项，共同目标只对部分角色成立
- 阵营不是必须先验写死的唯一结构，可以由共享目标和利益结构涌现
- 11 种特殊人群是角色设计语法，不是压过产品主线的单独总纲
- 旧的“侦探 / 罪犯 / 特工”命名不再作为最终正式体系

## 1. 文档目标

本文档用于回答四个问题：

1. 《开本》的目标 / 任务系统为什么不能只围绕追凶写。
2. 个人目标、共同目标和任务结构之间是什么关系。
3. 阵营应如何生成，而不是如何被粗暴预设。
4. 特殊人群体系在当前文档体系中应放在哪里。

## 2. 时间线覆盖说明

- 主证据轮次：`363-379`、`400`
- 关键补证：`385-397`
- 关键修订：`392`、`394`、`396`
- 明显过时口径：所有角色统一追凶；或直接把特殊人群命名冻结为“侦探 / 罪犯 / 特工”

## 3. 核心修订点

### 3.1 从“所有人都在追凶”改为“目标中立底座”

后期已经明确，《开本》的很多底层机制虽然在 Phase 1 首个剧本中服务侦探推理，但它们的抽象职责应是：

- 获取信息
- 管理风险
- 推进个人计划
- 处理合作与背叛
- 制造或规避后果

因此，搜证、暗杀、藏匿、展示、偷听、投票，都不能被写成“只为找真凶而存在”。

### 3.2 从“统一公共目标”改为“个人目标必需，共同目标可选”

`374-379` 之后稳定下来的口径是：

- 个人目标是角色扮演成立的前提
- 共同目标可以存在，但不是所有角色都有
- 多个角色可以共享某个阶段性目标，但仍保留自己的隐藏诉求

### 3.3 从“阵营先验写死”改为“阵营可由利益结构涌现”

阵营可以存在，但更准确的说法是：

- 有的剧本中阵营是明确预设
- 有的剧本中阵营是局中逐步形成
- 有的角色会跨阵营摇摆

这使系统能同时支持推理本、恐怖生存本、复仇本和更复杂的社会博弈结构。

### 3.4 从“职业命名集合”改为“抽象人群语法”

`392-396` 后的稳定版本，不再把“侦探 / 罪犯 / 特工”视为最终命名，而是收束到更统一的人群原型与正交分类语法中。

## 4. 目标系统的层级

### 4.1 个人目标

个人目标是最底层、也是最不可省略的一层。它定义：

- 角色真正想达成什么
- 角色愿意承受什么代价
- 角色为何参与冲突

个人目标示例：

- 保护某人
- 藏住某个秘密
- 证明自己清白
- 让某个仇人付出代价
- 从现场活着离开

### 4.2 共同目标

共同目标是多个角色局部共享的阶段性目标，不要求全员一致。

示例：

- 找出导致封锁发生的原因
- 在某个时间点前逃离现场
- 不让某个秘密公开
- 暂时合作压制更大威胁

### 4.3 阵营目标

阵营目标是共享目标进一步稳定化后的组织表达。它可以：

- 来自预设阵营
- 来自中途结盟
- 来自共同敌人
- 来自共享资源依赖

## 5. 阵营生成逻辑

当前更适合采用“关系涌现 + 局部预设”的混合方式。

### 5.1 可预设部分

- 某两人天然同盟
- 某三人共享秘密
- 某角色必须阻止另一组人成功

### 5.2 可涌现部分

- 局中因证据共享而结盟
- 因共同恐惧而暂时合作
- 因利益分裂而内部分化
- 因公开指控而迅速重组站队

## 6. 目标中立系统与侦探绑定系统

### 6.1 目标中立底座

- 角色智能体
- 司命
- 事件总线
- 可感知信息编译层
- 信息共享执行系统
- 房间与状态管理
- 基础场景交互
- 小世界与关系沉淀机制

### 6.2 当前更偏侦探绑定的机制

- 案件框架随机生成
- 真相锁定与嫌疑推理
- 证据链可视化
- 投票定罪结局

这一区分很重要，因为它决定后续扩展时哪些系统可直接复用，哪些需要替换玩法壳。

## 7. 特殊人群的定位

### 7.1 当前地位

特殊人群当前不是产品总纲中心，而是：

- 目标系统的角色原型语法
- 阵营设计的补充工具
- 剧本创作中的角色构造辅助层

### 7.2 当前采用方式

整理时应这样使用它：

- 在目标系统文档中作为核心组成写入
- 在剧本模板中作为可选角色原型字段引用
- 在玩法说明中说明其如何影响冲突类型与行动倾向

### 7.3 当前不建议做法

- 先把特殊人群独立抬成最高优先级总纲
- 用旧职业命名直接覆盖统一抽象命名
- 让特殊人群体系反向决定整个平台定义

## 8. 特殊人群命名与分类学原则

后期修订后的原则是：

- 命名尽量统一抽象层级
- 优先使用行为原型而不是具体职业
- 允许与职业映射，但职业不是最终分类层
- 允许复合人群，而不是强制单标签

## 9. Phase 1 落地方式

### 9.1 当前必须具备

- 个人目标系统
- 局部共同目标结构
- 可产生阵营合作 / 对抗的关系设计
- 目标中立的底层规则表达
- 特殊人群语法对角色原型的支撑

### 9.2 当前不必完整展开

- 全量剧本类型模板
- 大规模复合人群库
- 所有人群的完整数值化设计工具
- 阵营经营和跨局政治结构

## 10. 对首个剧本的影响

《血字的研究·变奏》虽然以推理为壳，但当前写法必须避免：

- 所有角色唯一目标都是找真凶
- 所有线索只服务定罪
- 所有结盟都只围绕公共正义展开

更准确的写法应是：

- 有人想查明真相
- 有人想隐藏真相的一部分
- 有人想自保
- 有人想借案件推进自己的私人议程
