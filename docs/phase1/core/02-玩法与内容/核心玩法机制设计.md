# 核心玩法机制设计

## 状态

- 状态：第一版初稿
- 主来源轮次：`310`、`379`、`400`
- 补充来源轮次：`031`、`085-101`、`232-248`、`299-301`、`363-378`、`398`、`406-450`（当前已产出 `406-437`）

## 当前冻结结论

- 核心玩法系统必须目标中立，而不是只服务追凶
- 共同目标只对部分角色成立，所有角色仍保留个人目标
- 事实锁定与信息博弈是玩法闭环的共同底层
- 侦探玩法只是 Phase 1 首个完整闭环，不是全部系统边界

## 1. 文档目标

本文档用于冻结《开本》当前的核心玩法机制框架，明确：

- 玩法循环如何成立
- 目标、任务、阵营如何组织
- 推理、线索、证据、暗杀、投票如何形成闭环
- 哪些机制是侦探玩法绑定，哪些是平台通用底座

本文档不负责完整展开：

- 特殊人群分类学全表
- 剧本案例推演
- 商业化和付费设计

## 2. 时间线覆盖说明

玩法与目标系统经历了明显修正，不能把不同阶段的说法直接拼接。

- `310`：第一次系统区分“侦探玩法绑定机制”与“全玩法通用底座”
- `372`：明确指出“追凶”不适合作为所有角色的第一目标
- `373`：提出过一个更激进的中间版本，即完全抛弃公共目标
- `374`：修正为更稳定的版本，即允许“部分角色共享共同目标”，但不要求所有人必须有公共目标
- `375-377`：在《无人生还》这一特定案例中继续修正，说明某些剧本甚至不需要通用公共目标，只需共享处境
- `378-379`：把以上修正提升为脱离具体剧本后的总体玩法框架
- `398/400`：把目标中立化、角色选择权平衡、证据链闭环等正式纳入 Phase 1 更新版计划
- `431-437`：补充硬件准入与云端兜底策略，这些结论主要影响玩法可达性与交付节奏，不改变玩法规则本体

当前采用规则：

- 玩法分层与“侦探绑定 / 通用底座”划分，以 `310` 为基础
- 目标系统以 `374/379/400` 为准
- `373` 只视为中间修正，不作为全局规则
- 某些具体剧本可以像 `375-377` 那样不设置显式共同目标，但平台总规则仍保留“部分角色共享共同目标”的能力

## 3. 核心修订点

### 3.1 从“追凶中心”到“目标中立”

早期设计容易让所有系统默认围绕“追凶”展开。

当前不采用这一口径。

当前采用：

- 追凶是重要玩法类型
- 但搜证、对话、证据、暗杀、环境博弈都不应只为追凶服务
- 同一底座必须也能服务逃脱、生存、复仇、守护、嫁祸等目标

### 3.2 从“统一公共目标”到“共同目标可选”

`372` 之后已明确：

- 不能强行给所有角色一个统一的第一目标

但 `373` 的“完全抛弃共同目标”也不是最终全局版本。

最终采用 `374/379/400`：

- 平台允许没有公共目标的剧本
- 也允许只让部分角色共享共同目标
- 阵营由共同目标自然形成，不要求所有人都进阵营

### 3.3 从“销毁证据=断链”到“销毁也是证据”

玩法闭环中，销毁不再是黑洞。

采用：

- 销毁证据本身会产生新的线索、残留、目击、时间矛盾或流转记录

### 3.4 从“侦探玩法专属系统堆叠”到“平台底座 + 类型模块”

`310` 已经给出稳定方向：

- 案件、线索、投票等更偏侦探绑定
- 智能体、司命、ESM、空间音频、事件总线、环境和关系系统属于平台底座

### 3.5 建造玩法当前收束为“建筑蓝图闭环”

建造线不再按“完整体素生存沙盒”作为当前玩法范围。

当前采用：

- 建筑建造
- 蓝图交易
- 蓝图导入生成

当前不采用：

- 完整体素沙盒生存循环
- 世界级地形与规则全开放

### 3.6 创作者设计层与玩家体验层分权

玩法机制上必须区分：

- 创作者 / 大玩家负责定义模板、规则、参数边界
- 玩家在边界内进行建造、培育、组合与博弈

这条分层会直接影响建造、生物、物件与市场玩法的可用范围。

运行时执行口径（V1）：

- 玩家可做：在世界授权范围内使用蓝图、组合物件、进行培育与博弈
- 玩家不可做：直接编辑底层模板、修改世界级规则、绕过授权导入资产
- 创作者/大玩家可做：配置模板边界、授权策略和世界编排参数

## 4. 核心玩法循环

《开本》的最小玩法循环不是“找线索”，而是：

```text
进入世界
  -> 扮演角色
  -> 感知环境与他人
  -> 获取信息 / 制造信息 / 隐藏信息
  -> 基于目标做决策
  -> 观察系统与他人反馈
  -> 调整策略
  -> 推进个人或共同目标
  -> 进入结局或阶段性收束
```

对 Phase 1 的侦探闭环而言，这条循环具体体现为：

```text
入场
  -> 搜证 / 对话 / 观察 / 偷听
  -> 秘密目标与公共局势碰撞
  -> 结盟 / 欺骗 / 嫁祸 / 自保 / 守护
  -> 证据展示或销毁
  -> 冲突升级 / 暗杀涌现 / 时间线矛盾暴露
  -> 投票 / 指认 / 坦白 / 反杀
  -> 结局
```

## 5. 目标系统

### 5.1 目标层级

当前采用三层口径：

- 个人目标
- 共同目标
- 动态注入目标

### 5.2 个人目标

个人目标是强制存在的，是角色人格与处境的延伸。

当前冻结为 8 种核心目标：

- 追凶
- 逃脱（凶手）
- 生存
- 守护
- 复仇
- 嫁祸
- 逃脱（空间）
- 坦白

除这 8 种外，其余常见表述统一视为：

- 核心目标的叙事包装
- 核心目标的阶段性任务
- 多个核心目标的组合玩法

例如“偷盗并全身而退”应优先拆解为资源获取 + 嫁祸 / 逃脱（空间）的组合，而不是再新增一个同级核心目标。

### 5.3 共同目标

共同目标不是人人都有，而是**部分角色因共同利益共享的目标**。

其作用是：

- 形成阵营
- 创造稳定合作动机
- 在个人目标之外提供额外冲突层

共同目标的形态可以是：

- 明面或暗面
- 固定或动态
- 稳定或阶段性

当前更适合做共同目标的，主要是：

- 追凶
- 生存
- 守护
- 复仇
- 逃脱（空间）

当前不宜作为稳定共同目标默认项的，主要是：

- 逃脱（凶手）
- 嫁祸
- 坦白

### 5.4 动态注入目标

当局势变化或旧目标失效时，司命可注入新目标，例如：

- 觉醒
- 反水
- 灭口
- 继承

这使得角色不是从开局到结束只做一套静态任务。

### 5.5 目标分配原则

目标分配必须遵守：

- 人格驱动
- 负荷均衡
- 冲突可玩
- 不强行统一所有人方向

### 5.6 阵营与派系

阵营来自共同目标，不是先有阵营标签再硬塞目标。

阵营内部还可以继续按合作状态形成派系。

因此，一个剧本中可以同时存在：

- 无阵营角色
- 明面阵营
- 暗面阵营
- 动态形成的临时合作派系

## 6. 任务系统

目标是“想达成什么”，任务是“具体怎么做”。

当前任务类型至少包括：

- 信息获取
- 物品操作
- 社交互动
- 策略行动
- 推理分析
- 移动探索
- 投票与表态

### 6.1 信息获取

典型方式：

- 搜查场景
- 检查物品
- 套话
- 偷听
- 跟踪
- 观察微表情与异常动作

### 6.2 物品操作

典型方式：

- 拾取
- 藏匿
- 展示
- 移交
- 破坏
- 伪造
- 使用环境工具

### 6.3 社交互动

典型方式：

- 公开对话
- 耳语
- 威胁
- 安抚
- 共谋
- 背叛
- 邀请同行

### 6.4 策略行动

典型方式：

- 暗杀
- 环境致死
- 制造噪音
- 设陷阱
- 引导目击
- 转移嫌疑

### 6.5 建造与改造任务

在当前阶段，建造相关任务优先采用建筑蓝图任务链：

- 设计或获取蓝图
- 准备建造条件
- 执行导入校验（权限、依赖、世界约束、资源）
- 导入生成建筑
- 记录实例化回写结果（实例状态与审计记录）
- 围绕建筑结果展开后续信息和社交博弈

并发冲突处理口径：

- 同一场景位点冲突时，优先采纳世界规则与授权结果
- 无法自动合并时，不把冲突直接吞掉，必须进入人工审核或延迟执行队列

不把完整体素资源采集 / 合成 / 沙盒生存链写入当前必做任务结构。

## 7. 推理、线索与证据闭环

### 7.1 事实锁定

玩法必须建立在 `T0-T3` 锁定机制之上：

- 事实会在时间线上逐步冻结
- 路径、说法、冲突和次生事件仍可变化

### 7.2 线索类型

当前稳定口径：

- 物证
- 人证
- 环境痕迹
- 时间线矛盾
- 关系与动机线索

### 7.3 线索状态

线索不应只有“发现 / 未发现”。

还应包括：

- 被展示
- 被私下分享
- 被藏匿
- 被伪造
- 被销毁

### 7.4 证据闭环

证据链不是单个模块，而是多系统协作结果：

- ESM 记录物理变化
- 物品流转记录归属和位置变化
- 接触痕迹记录微观接触
- 生物痕迹记录血迹、毛发等
- 司命事实核心对比说法与时间线

### 7.5 销毁原则

采用当前冻结规则：

- 销毁证据本身必须成为新的推理对象

因此：

- 烧毁会留下残骸与气味
- 冲洗会留下湿痕和时间差
- 丢弃会留下流转路径
- 处理者本身可能成为目击对象

## 8. 伪装、知情人与信息博弈

### 8.1 伪装

伪装是角色对外信息管理系统，而不是简单说谎。

关键机制包括：

- 公开档案
- 真实档案
- 不在场证明
- 伪装深度
- 伪装破绽

### 8.2 知情人

知情人不是侦探玩法独有，但在侦探玩法中高度重要。

类型包括：

- 固定 NPC 知情人
- 动态 NPC 知情人
- AI 角色知情人
- 玩家知情人

### 8.3 高阶知识

信息博弈的核心不只是“谁知道什么”，还包括：

- 谁知道别人知道什么
- 谁怀疑别人知道什么
- 谁误以为自己藏住了秘密

因此系统必须显式支持：

- 公共知识
- 共有知识
- 高阶知识

### 8.4 空间音频与偷听

空间音频是玩法机制，不只是表现层。

它支撑：

- 公共发言
- 私密耳语
- 偷听
- 噪音掩护
- 误导与埋伏

## 9. 暗杀与阴谋

### 9.1 暗杀触发

当前采用五重条件：

- 致命动机
- 信息空窗期
- 独处窗口
- 能力匹配
- 代价评估

### 9.2 阶段化感知

暗杀不是结果事件，而是阶段事件：

- 意图阶段
- 执行阶段
- 完成阶段

这保证目标和旁观者有机会做出反应。

### 9.3 本能反应

对 `P0` 致命威胁，角色走本能反应规则，而不是慢速完整推理。

### 9.4 阴谋系统

阴谋不只包括“直接杀人”，还包括：

- 蓄意破坏
- 伪造现场
- 借环境杀人
- 引导他人犯错
- 共谋与背叛

### 9.5 司命的作用

司命只负责：

- 检测机会
- 评估可玩性
- 排列条件

不负责：

- 替角色执行暗杀
- 消除后果
- 绕过人格与世界规则

## 10. 投票与结局

### 10.1 投票

投票是侦探闭环中的重要收束形式，但不是所有玩法都必须有。

在侦探玩法中，投票至少承担：

- 公共判断
- 阵营博弈
- 证据展示后的最终表态

### 10.2 结局

结局不应只存在“找对真凶 / 找错真凶”。

当前稳定口径包括：

- 正义伸张
- 真凶逃脱
- 冤案
- 全灭
- 隐藏结局

并且结局应当由：

- 投票
- 角色存活状态
- 证据公开程度
- 个人目标完成情况

共同决定。

## 11. 通用底座 vs 侦探绑定机制

### 11.1 偏侦探绑定的机制

这些机制更强绑定于“找出真相”的闭环：

- 案件生成规则
- 线索池
- 不在场证明
- 投票与指认
- 证据链高强度使用
- 留影石 / 相机证据记录

### 11.2 全玩法通用底座

这些机制不应只服务侦探玩法：

- 角色智能体
- 司命
- ESM
- 空间音频
- 事件总线
- 可感知信息编译层
- 对话系统
- 动态状态系统
- 环境交互
- 关系与信任系统

### 11.3 参数化存在的中间层

还有一些机制是“全玩法存在，但配置不同”的：

- 司命干预强度
- 环境交互复杂度
- 天气系统作用强度
- 资源紧缺程度
- 暗杀与阴谋开关

## 12. 当前采用规则

后续所有文档提到玩法机制时，应统一采用以下口径：

- 核心玩法不是“追凶唯一中心”，而是“多目标博弈”
- 核心目标冻结为 8 种，其余玩法目标优先拆回核心目标组合
- 共同目标只对部分角色成立，不强制所有人共享公共目标
- 阵营来自共同目标，派系来自合作关系
- 事实锁定与高阶知识是玩法底层
- 证据销毁不会让信息归零，只会转化为新的信息形态
- 侦探玩法是 Phase 1 首个闭环，不是全部系统边界

## 13. 延后项

本版不展开：

- 完整特殊人群分类学
- 各题材剧本的目标映射模板
- 恋爱本 / 无限流 / 种田 / SLG 的专属子机制细节
- 大玩家规则编辑器中的玩法参数化面板
