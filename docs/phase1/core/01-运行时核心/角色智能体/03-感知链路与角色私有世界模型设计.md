# 03-感知链路与角色私有世界模型设计

## 1. 文档目标

本文档冻结角色如何从世界事实中获得“自己能感知到的那个世界”。

## 2. 核心原则

### 2.1 角色不读取世界真相

角色不能直接知道：

- 全局原始事件流
- 司命事实核心
- 他人私有状态
- 未被自己感知到的世界变化

### 2.2 感知必须同源

统一链路固定为：

`原始世界事件 -> 可感知信息编译层 -> Per-Character 感知过滤器 -> 角色感知事件`

### 2.3 角色拿到的是“角色版世界”

同一事实，对不同角色来说：

- 可见性不同
- 清晰度不同
- 时间进入点不同
- 解释前提不同

## 3. 感知系统四层

1. `Raw Fact Producers`
2. `Perceptible Compilation Layer`
3. `Per-Character Perception Filter`
4. `Private World Snapshot`

## 4. Raw Fact Producers

来自 `L1/ESM/交互系统` 的原始事实上抛器，包括：

- 行为事实上抛器
- 空间音频事实上抛器
- 环境状态回写器
- 物体状态变化回写器
- 接触、碰撞、温度、光照、遮挡事实上抛器

## 5. Perceptible Compilation Layer

职责：把原始事实编译成可能被感知的候选事件，而不是直接判断某个角色听没听见。输出对象为 `Perceptible Candidate Event`。

## 6. Per-Character Perception Filter

职责：根据角色私有条件裁剪候选事件。至少考虑：

- distance
- orientation
- line_of_sight
- occlusion
- lighting
- ambient_noise
- attention_focus
- sensory baseline
- current body state
- conversation personality parameters

输出对象为 `Character Perceived Event`。

## 7. Private World Snapshot

这是角色当前短时感知世界图，不是长期记忆库。它至少包括：

- `visible_entities`
- `audible_entities`
- `unresolved_signals`
- `active_anomalies`
- `current_attention_targets`
- `short_horizon_social_presence`
- `local_spatial_confidence_map`

## 8. 感知质量模型

`Phase 1` 最少冻结两个分数：

- `clarity_score`
- `certainty_score`

并允许：

- `partial_observation`
- `distorted_details`
- `missed_details`

## 9. 感官模态

`Phase 1` 冻结：

- Vision
- Audition
- Smell
- Heat / Atmosphere
- Touch / Proximity（弱模态）

## 10. 注意力模型

角色不是对所有输入一视同仁。需要单独维护：

- `primary_targets`
- `vigilance_level`
- `distraction_level`
- `bias_tags`

注意力会改变 event salience、clarity 与是否捕捉到候选事件。

## 11. 司命与角色输入边界

- 司命接收更广的原始/结构化世界事件
- 角色只接收经过私有裁剪后的角色感知事件

不能把司命知道但角色没感知到的事，直接塞进角色脑中。

## 12. Phase 1 范围

Phase 1 必须支持：

- 结构化事实输入
- 候选感知编译
- 私有过滤
- 双分数质量模型
- 私有世界快照
- 视觉/听觉主模态
- 嗅觉与热感关键场景
- 注意力焦点影响
- 漏感知/模糊感知/错感知

## 13. 一句话收束

角色感知系统的目标不是把世界完整复制给角色，而是在同源事实链上，为每个角色构建一个受空间、状态、注意力和个体差异约束的私有世界入口。
