# 02-人格形成链与静态档案设计

## 1. 文档目标

本文档冻结角色智能体的静态核心档案，也就是所有运行时判断的长期上游来源。

## 2. 核心原则

### 2.1 人格不是手填标签包

当前采用：

`基因种子 -> 人生记忆 -> 品格层 -> 五维人格 -> 运行时偏置`

五维人格是映射结果，不是源头。

### 2.2 静态档案只放长期稳定项

静态档案只放：

- 长期人格
- 形成原因
- 长期能力
- 长期偏好
- 长期禁忌
- 长期语言风格
- 长期会话倾向

不放：

- 当前情绪
- 当前怀疑值
- 当前会话运行态
- 当前伤势结果

## 3. 八层结构

静态档案固定拆成：

1. `Identity Core`
2. `Origin Seed`
3. `Life Memory Backbone`
4. `Virtue & Value Layer`
5. `Trait Vector Layer`
6. `Capability & Constraint Layer`
7. `Style & Expression Bias Layer`
8. `Conversation Personality Layer`

## 4. Identity Core

定义角色的基础身份信息：

- `character_id`
- `world_id`
- `canonical_name`
- `aliases`
- `gender_presentation`
- `age_range`
- `species_or_race`
- `era_context`
- `social_class`
- `occupation_role`
- `public_identity_summary`
- `private_identity_summary`

## 5. Origin Seed

定义人格形成链的上游起点：

- 出生区域与家庭结构
- 经济与教育出身
- 信仰来源
- 早年安全感
- 依恋模式
- 先天气质底色
- 身体底子
- 先天才能与局限

## 6. Life Memory Backbone

记录真正塑造角色的经历骨架：

- `formative_events`
- `stable_relationship_imprints`
- `core_losses`
- `core_shames`
- `core_prides`
- `core_secrets`
- `survival_adaptations`
- `identity_turning_points`

这不是运行时记忆池，而是开局前已经形成的关键人生骨架。

## 7. Virtue & Value Layer

定义角色认为什么是对的、值得的、不能做的：

- 诚实、忠诚、正义、仁慈、责任感
- 价值优先级
- 道德红线
- 自我形象与理想自我
- 世界观偏置
- 责任来源与执念

## 8. Trait Vector Layer

当前五维人格固定为：

- `courage`
- `scheming`
- `empathy`
- `rationality`
- `sociability`

它是行为倾向向量，不是人格源头。

## 9. Capability & Constraint Layer

定义角色能做什么、不能做什么：

- `skills`
- `trained_capabilities`
- `knowledge_domains`
- `physical_constraints`
- `psychological_constraints`
- `social_constraints`
- `role_permissions`
- `forbidden_behaviors`

这里记录长期身体条件，不记录当前身体状态。

## 10. Style & Expression Bias Layer

定义角色通常如何表达自己：

- 说话风格（冗长/直接/礼貌/隐喻/情绪泄露）
- 沉默模式
- 手势偏置
- 姿态偏置
- `facs_bias_tags`
- `sacs_bias_tags`

它不等于执行层本身，但会长期影响执行层输出。

## 11. Conversation Personality Layer

这是会话相关长期参数层，至少包括：

- `base_hearing_sensitivity`
- `speech_discrimination_under_noise`
- `whisper_capture_ability`
- `social_openness`
- `privacy_sensitivity`
- `stranger_join_tolerance`
- `talk_initiative`
- `public_speaking_comfort`
- `deception_control`
- `anti_eavesdrop_habit`
- `pressure_escape_bias`
- `trust_threshold_for_private_talk`

它们只表示长期倾向，不直接决定会话真值。

## 12. 总 Schema

```yaml
character_profile:
  identity_core: {}
  origin_seed: {}
  life_memory_backbone: {}
  virtue_value_layer: {}
  trait_vector_layer: {}
  capability_constraint_layer: {}
  style_expression_bias_layer: {}
  conversation_personality_layer: {}
```

## 13. Phase 1 范围

Phase 1 必须冻结上述八层，并保持静态档案与运行态严格分离。

## 14. 一句话收束

静态档案不是角色设定说明书，而是角色智能体运行时的长期人格约束底座；它通过身份、起源、人生骨架、价值品格、行为向量、能力限制、表达偏置、会话人格八层结构，为后续感知、理解、规划和具身表达提供稳定上游。
