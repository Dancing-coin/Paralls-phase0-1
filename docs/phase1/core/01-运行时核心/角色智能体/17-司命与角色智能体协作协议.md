# 17-司命与角色智能体协作协议

## 1. 文档目标

本文档冻结司命与角色智能体之间的高层协作协议：司命能发什么、角色如何承接、哪些地方必须经过角色自己的 `L2/L3`。

## 2. 核心定义

司命是全局叙事催化者，角色智能体是世界内角色本体。司命催化，角色承接，角色自己决定。

## 3. 允许的消息类型

`Phase 1` 建议固定：

- `impulse`
- `opportunity`
- `fact_reveal`
- 预留：`public_event_hint`
- 预留：`pressure_shift_hint`

## 4. 承接路径

司命消息先进入角色输入层，本质上仍然是输入材料：

1. `L2` 先解释
2. 再由 `L3` 判断是否转成行为意图

## 5. 司命不能做什么

- 不能直接下发低层动作命令
- 不能替角色生成最终结论
- 不能跳过世界约束
- 不能让行动已完成后再补写动机

## 6. 玩家角色是否遵循同一协议

是。玩家角色收到的仍是高层消息，但在 `L3` 侧主要转成：

- 冲动提示
- 风险提示
- 候选建议
- 角色主观倾向

玩家自己决定是否跟随。

## 7. 审计要求

每条司命消息都必须能回放：

`SimingMessage -> L2 Interpretation -> Belief/Affect Delta -> L3 Candidate Shift -> Intent Selected/Rejected`

## 8. Phase 1 范围

Phase 1 必须成立：

- 司命只发高层消息
- 角色先经 `L2`
- 再经 `L3`
- 再进 `L4`
- 再由 `L1/ESM` 结算
- 最终回流给司命与角色

## 9. 一句话收束

司命与角色智能体之间的正确关系，不是“导演让演员照做”，而是“导演只制造动机、窗口和压力，演员仍然按自己的心智和人格去决定是否接住这场戏”。
