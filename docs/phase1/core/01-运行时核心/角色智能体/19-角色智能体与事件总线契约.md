# 19-角色智能体与事件总线契约

## 1. 文档目标

本文档冻结角色智能体通过事件总线收什么、发什么、消息信封怎么分层，以及哪些字段必须可重放。

## 2. 核心定义

角色智能体在总线中的正确身份是：受限订阅者 + 结构化回写者。

它不能直接订阅所有世界原始事实，也不能随意广播内部心理状态。

## 3. 三层消息

建议把角色相关消息分成：

1. `公共事实层`
2. `角色私有感知层`
3. `角色行为回写层`

角色默认不直接消费公共事实层；它正式消费的是私有感知层。

## 4. 公共信封字段

统一信封建议包括：

- `event_id`
- `event_type`
- `producer_ts`
- `room_id`
- `scene_id`
- `zone_id`
- `source`
- `routing`
- `causation_id`
- `correlation_id`
- `priority`
- `durability`
- `payload`

当前 canonical 口径采用：

- `source.layer`
- `source.system`
- `source.actor_id`
- `source.object_id`（如有）
- `routing.audience_mode`
- `routing.routing_mode`
- `routing.dialog_group_id`（如有）
- `routing.target_ids`（如有）

不再采用平铺的：

- `producer`
- `source_actor_id`
- `target_actor_ids`

也不再采用：

- `world_ts`

统一改为：

- `producer_ts`

## 5. 角色接收的消息类型

- `CharacterPerceivedEvent`
- `SelfBodyPerceivedEvent`
- `SimingHighLevelMessage`
- `ConversationStateUpdate`
- `ConstraintStateUpdate`

## 6. 角色发出的消息类型

- `IntentCommitted`
- `SpeechActPublished`
- `ActionRequestIssued`
- `SocialSignalPublished`
- `InformationShareIssued`
- `AutonomyModeChanged`
- `ExpressionStatePublished`（可选）
- `DecisionTraceCheckpoint`（调试用）

## 7. 角色不能直接获得什么

角色不能直接拿到：

- 全局原始事实流
- 司命事实核心真值
- 他人私有记忆
- 他人主观信念
- 高阶知识图谱全量真值
- `ESM` 内部数值状态原始字段
- 其他角色未公开意图

## 8. 角色不能直接广播什么

角色不能向业务总线直接广播：

- 私有心理真值
- 内部怀疑值
- 原始 FACS/SACS 权重
- 未过滤 chain-of-thought

## 9. 回放要求

最小可重放链：

`CharacterPerceivedEvent -> BeliefUpdateDelta -> IntentCommitted -> ActionRequestIssued / SpeechActPublished -> ESM Result / Social Consequence`

## 10. 一句话收束

角色智能体与事件总线的正确关系，不是“角色随便订阅、随便广播”，而是“角色只接收自己有资格接收的世界版本，只回写对世界有意义且可重放的结构化行为结果”。
