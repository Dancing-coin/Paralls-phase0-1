# 01-角色智能体总纲

## 1. 文档目标

本文档定义《开本》角色智能体的统一身份、系统边界、内部主结构与后续专项文档的共同约束。

## 2. 核心定义

角色智能体是每一个剧中角色的统一运行时决策核心。它不是对话模型壳、不是普通 NPC 行为树、也不是玩家的纯手动角色壳。它持续回答：

- 这个角色感知到了什么
- 这个角色如何理解这些信息
- 这个角色当前想做什么
- 这个角色最终会如何说、如何动、如何暴露自己

一句话：角色智能体是“剧中角色在世界内的连续存在体”。

## 3. 系统边界

### 3.1 上游输入

角色智能体只正式接收三类输入：

1. 角色私有感知事件
2. 司命高层催化消息
3. 状态变化与约束结果回写

统一链路必须保持为：

`原始世界事件 -> 可感知信息编译层 -> Per-Character 感知过滤器 -> 角色感知事件`

角色默认不直接消费全局原始事实流。

### 3.2 下游输出

角色智能体输出：

- 行为意图
- 对话行为
- 社交与空间行为
- 具身表达计划
- 关键状态变化回写

但它不直接决定世界物理结果。动作是否成立、身体是否真的受伤、物体是否真的被移动，必须由 `L1/ESM` 结算。

### 3.3 与司命的关系

司命是全局叙事催化者，角色智能体是世界内角色本体。司命只能催化、唤醒、揭示和制造窗口，不能越权替角色决定最终行为。角色是否接住这场戏，必须经过自己的 `L2/L3`。

### 3.4 与 ESM 的关系

`ESM` 决定“身体发生了什么、环境在物理上发生了什么”。角色智能体决定“这些结果对角色意味着什么、会引发什么主观状态和后续倾向”。

## 4. 统一底层原则

所有剧中角色共享统一底层：

- AI 角色
- 玩家投影角色
- 被带回小世界后的角色

差异不在“底层脑”，而在于谁握着高层主动规划权、当前可用算力和具身表达预算。

## 5. 六大组成块

角色智能体固定由六块组成：

1. 人格档案系统
2. 四层心智系统（L1 感知 / L2 理解 / L3 规划 / L4 执行）
3. 记忆与知识系统
4. 动态状态系统
5. 伪装与接管系统
6. 具身表达系统

## 6. 玩家角色的正确模型

玩家角色既不是纯手动壳，也不是完全自动角色。当前采用“双回路模型”：

- 玩家真实认知回路：发生在系统外的人脑中
- 剧中角色补全回路：由角色智能体维持人格连续性、自动微表现、挂机承接和主观补全

玩家主要接管 `L3` 主动规划与 `L4` 主动执行；系统持续保留 `L1/L2` 的角色补全职责和自动生理/微表现层。

## 7. 具身表达总口径

执行层不得退化为动画播放器。统一链路为：

`心理/意图状态 -> FACS/SACS -> Embodiment Binder -> Canonical Rig -> Asset Adapter -> Runtime Mixer`

其中：

- `FACS` 负责面部动作编码
- `SACS` 负责身体动作编码
- 上层永远不直接写具体骨骼名或 blendshape 名

## 8. Phase 1 范围

Phase 1 冻结：

- 完整人格档案形成链
- 四层心智系统
- 五池记忆
- 动态状态系统
- 玩家接管模式
- 挂机保守接管
- `FACS/SACS + Binder` 最小闭环
- 轻量角色快照承接

## 9. 一句话收束

角色智能体是《开本》中每个剧中角色的统一运行时本体；它以人格档案为长期核心，以四层心智模型为决策主链，以记忆/知识/动态状态为持续上下文，以 `FACS/SACS + Embodiment Binder` 为具身出口，在司命催化和 `ESM` 物理约束之间维持角色作为“活体存在”的连续性。
