# 08-高价值视觉事实特征字典

## 1. 文档目标

本文档冻结首批高价值视觉事实所依赖的 canonical features 字典，用于支撑后续模板规则表与实现优先级判断。

## 2. 特征类型

每个事实固定使用三类特征：

- `required`
- `supporting`
- `negative`

## 3. 12 个高价值视觉事实的特征字典

### fixed_gaze_on_target
- `required`：`target_actor_id_present`、`head_target_alignment`、`eye_target_alignment`、`fixation_hold_duration_ms`、`fixation_stability`
- `supporting`：`torso_follow_amount`、`mutual_attention_score`、`head_motion_quietness`
- `negative`：`high_scan_variability`、`frequent_target_switch`、`navigation_scan_mode`

### defensive_recoil
- `required`：`torso_guarded_hunch_amount`、`head_or_neck_retract_amount`、`center_of_mass_backward_shift`
- `supporting`：`micro_step_back_present`、`shoulder_inward_defense_amount`、`arm_self_protect_amount`、`gaze_lock_or_avoidance`
- `negative`：`casual_turning_motion`、`normal_walk_transition`、`friendly_approach_posture`

### suppressed_tension_face
- `required`：`AU4_intensity`、`AU7_intensity`、`AU23_or_AU24_intensity`、`face_readability`
- `supporting`：`jaw_tension`、`speech_suppression_coupling`、`neck_tension_presence`
- `negative`：`open_smile_profile`、`relaxed_lid_profile`、`high_speech_deformation_masking`

### visible_instability
- `required`：`balance_instability_score`、`gait_irregularity_score`
- `supporting`：`pelvis_drift_score`、`step_asymmetry`、`head_recovery_lag`、`pain_guarding_presence`、`breath_disruption_visibility`
- `negative`：`intentional_dance_or_stylized_motion`、`known_uneven_surface_compensation_only`

### object_removed_from_surface
- `required`：`previously_surface_supported`、`support_relation_changed`、`visible_fraction_drop`
- `supporting`：`hand_object_coupling`、`recent_actor_interaction_nearby`、`surface_emptying_salience`
- `negative`：`camera_occlusion_only`、`surface_visibility_lost_without_object_motion`

### object_hide_close
- `required`：`object_close_to_body_score`、`visible_fraction_drop`、`hand_object_coupling`
- `supporting`：`torso_closure_score`、`arm_shielding_score`、`body_side_occlusion_score`、`concealment_motion_score`
- `negative`：`casual_hold_profile`、`normal_pickup_without_visibility_drop`、`display_gesture_profile`

### door_opened_partial
- `required`：`open_ratio_in_partial_band`、`state_transition_closed_to_partial`
- `supporting`：`line_of_sight_change_score`、`visibility_gap_created`、`handle_interaction_recent`
- `negative`：`minor_physics_jitter`、`already_open_and_static`

### light_level_drop
- `required`：`local_lux_drop`、`visibility_reduction_score`
- `supporting`：`shadow_heaviness_increase`、`light_source_state_change`、`scene_contrast_shift`
- `negative`：`camera_auto_exposure_only`、`short_flash_transition`

### smoke_visible
- `required`：`smoke_visibility_score`、`particle_persistence_duration_ms`
- `supporting`：`source_region_consistency`、`density_growth_rate`、`contrast_against_background`
- `negative`：`brief_steam_like_burst`、`low_density_transient_particle_noise`

### bloodstain_visible
- `required`：`trace_visibility_score`、`surface_attachment_stability`、`contrast_above_trace_min`
- `supporting`：`abnormal_color_signature`、`shape_irregularity`、`nearby_injury_context_hint`
- `negative`：`known_scene_red_decor`、`specular_reflection_false_positive`、`brief_shadow_artifact`

### private_proximity_cluster
- `required`：`intra_group_distance_low`、`extra_group_distance_high`、`orientation_convergence`、`cluster_hold_duration_ms`
- `supporting`：`mutual_attention_score`、`voice_privacy_alignment`、`shared_object_focus`
- `negative`：`crowded_space_forced_proximity`、`queue_or_corridor_passby_pattern`

### intentional_occlusion
- `required`：`line_of_sight_block_score`、`occluder_position_relevance`、`occlusion_hold_duration_ms`
- `supporting`：`body_orientation_shielding`、`object_target_alignment`、`door_or_anchor_blocking_score`
- `negative`：`incidental_passby_occlusion`、`camera_angle_only_occlusion`、`crowd_noise_occlusion_without_stability`

## 4. 一句话收束

这份特征字典先把“我们到底在从姿态、物体、环境和空间关系里提取什么”说死；只有 feature 层定住，后面的规则模板、视觉事实上抛器和感知链才不会一路漂。
