# 09-高价值视觉事实模板规则表

## 1. 文档目标

本文档给出首批高价值视觉事实的 `required / supporting / negative / initial_thresholds` 模板规则表，作为 Phase 1 起始阈值集。

## 2. 12 个事实模板

### fixed_gaze_on_target
- `required`：`target_actor_id_present`、`head_target_alignment > 0.58`、`eye_target_alignment > 0.65`、`fixation_hold_duration_ms > 180`、`fixation_stability > 0.60`
- `supporting`：`torso_follow_amount > 0.20`、`mutual_attention_score > 0.30`、`head_motion_quietness > 0.55`
- `negative`：`high_scan_variability > 0.45`、`frequent_target_switch == true`、`navigation_scan_mode == true`

### defensive_recoil
- `required`：`torso_guarded_hunch_amount > 0.45`、`head_or_neck_retract_amount > 0.28`、`center_of_mass_backward_shift > 0.22`
- `supporting`：`micro_step_back_present`、`shoulder_inward_defense_amount > 0.25`、`arm_self_protect_amount > 0.25`、`gaze_lock_or_avoidance > 0.30`
- `negative`：`casual_turning_motion`、`normal_walk_transition`、`friendly_approach_posture > 0.40`

### suppressed_tension_face
- `required`：`AU4_intensity > 0.22`、`AU7_intensity > 0.18`、`AU23_or_AU24_intensity > 0.25`、`face_readability > 0.35`
- `supporting`：`jaw_tension > 0.20`、`speech_suppression_coupling > 0.20`、`neck_tension_presence > 0.18`
- `negative`：`open_smile_profile > 0.35`、`relaxed_lid_profile > 0.35`、`high_speech_deformation_masking == true`

### visible_instability
- `required`：`balance_instability_score > 0.32`、`gait_irregularity_score > 0.28`
- `supporting`：`pelvis_drift_score > 0.20`、`step_asymmetry > 0.20`、`head_recovery_lag > 0.18`、`pain_guarding_presence > 0.18`、`breath_disruption_visibility > 0.15`
- `negative`：`intentional_dance_or_stylized_motion == true`、`known_uneven_surface_compensation_only == true`

### object_removed_from_surface
- `required`：`previously_surface_supported == true`、`support_relation_changed == true`、`visible_fraction_drop > 0.50`
- `supporting`：`hand_object_coupling > 0.45`、`recent_actor_interaction_nearby == true`、`surface_emptying_salience > 0.40`
- `negative`：`camera_occlusion_only == true`、`surface_visibility_lost_without_object_motion == true`

### object_hide_close
- `required`：`object_close_to_body_score > 0.75`、`visible_fraction_drop > 0.45`、`hand_object_coupling > 0.70`
- `supporting`：`torso_closure_score > 0.25`、`arm_shielding_score > 0.25`、`body_side_occlusion_score > 0.30`、`concealment_motion_score > 0.45`
- `negative`：`casual_hold_profile > 0.45`、`normal_pickup_without_visibility_drop == true`、`display_gesture_profile > 0.40`

### door_opened_partial
- `required`：`open_ratio_in_partial_band == true`、`state_transition_closed_to_partial == true`
- `supporting`：`line_of_sight_change_score > 0.20`、`visibility_gap_created > 0.20`、`handle_interaction_recent == true`
- `negative`：`minor_physics_jitter == true`、`already_open_and_static == true`

### light_level_drop
- `required`：`local_lux_drop > 0.25`、`visibility_reduction_score > 0.20`
- `supporting`：`shadow_heaviness_increase > 0.15`、`light_source_state_change == true`、`scene_contrast_shift > 0.18`
- `negative`：`camera_auto_exposure_only == true`、`short_flash_transition == true`

### smoke_visible
- `required`：`smoke_visibility_score > 0.38`、`particle_persistence_duration_ms > 150`
- `supporting`：`source_region_consistency > 0.40`、`density_growth_rate > 0.18`、`contrast_against_background > 0.22`
- `negative`：`brief_steam_like_burst == true`、`low_density_transient_particle_noise == true`

### bloodstain_visible
- `required`：`trace_visibility_score > 0.45`、`surface_attachment_stability > 0.50`、`contrast_above_trace_min == true`
- `supporting`：`abnormal_color_signature > 0.40`、`shape_irregularity > 0.20`、`nearby_injury_context_hint > 0.20`
- `negative`：`known_scene_red_decor == true`、`specular_reflection_false_positive == true`、`brief_shadow_artifact == true`

### private_proximity_cluster
- `required`：`intra_group_distance_low == true`、`extra_group_distance_high == true`、`orientation_convergence > 0.50`、`cluster_hold_duration_ms > 250`
- `supporting`：`mutual_attention_score > 0.35`、`voice_privacy_alignment > 0.30`、`shared_object_focus > 0.25`
- `negative`：`crowded_space_forced_proximity == true`、`queue_or_corridor_passby_pattern == true`

### intentional_occlusion
- `required`：`line_of_sight_block_score > 0.55`、`occluder_position_relevance > 0.45`、`occlusion_hold_duration_ms > 180`
- `supporting`：`body_orientation_shielding > 0.25`、`object_target_alignment > 0.25`、`door_or_anchor_blocking_score > 0.25`
- `negative`：`incidental_passby_occlusion == true`、`camera_angle_only_occlusion == true`、`crowd_noise_occlusion_without_stability == true`

## 3. 派生证据投影模板

### tamper_candidate
- 组合要求：至少两个源事件，且包含 `object_removed_from_surface / door_opened_partial / bloodstain_visible / object_partially_exposed` 任一

### concealment_candidate
- 组合要求：包含 `object_hide_close` 或 `intentional_occlusion`，且 `concealment_strength > 0.50`

### injury_visibility_candidate
- 组合要求：包含 `visible_instability` 或 `bloodstain_visible`，且 `body_distress_score > 0.45`

### private_exchange_candidate
- 组合要求：`private_proximity_cluster == true` 且 `shared_object_focus > 0.25`

## 4. 一句话收束

这份模板规则表是 Phase 1 视觉事实系统的第一套可执行判定基线，后续阈值要通过 replay 样板库和误报/漏报统计持续校准。
