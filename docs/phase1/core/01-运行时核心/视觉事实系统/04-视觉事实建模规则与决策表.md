# 04-视觉事实建模规则与决策表

## 1. 文档目标

本文档定义《开本》视觉事实该如何建模：哪些适合 `Fact + Bias`，哪些适合 `Fact Family`。

## 2. 总规则

如果“变化的世界事实本体”相同，只是动机、语气、社交含义、危险程度不同，采用：

- `Fact + Bias`

如果“变化的世界事实本体”已经不同，直接拆成：

- `Fact Family`

## 3. 判定问题

每个新视觉事实先问：

1. 去掉解释后，本体是不是同一个？
2. 差别来自解释层还是世界事实层？
3. 这个差别会不会改变下游链路？
4. replay 时是否必须被看作不同事实？

## 4. 推荐归类

### 更适合 `Fact + Bias`
- `fixed_gaze_on_target`
- `defensive_recoil`
- `suppressed_tension_face`
- `object_hide_close`
- `private_proximity_cluster`
- `visible_instability`

### 更适合 `Fact Family`
- `door_opened_partial / door_opened_full / door_forced_open`
- `object_removed_from_surface / object_dropped / object_partially_exposed / object_broken_visible`
- `light_level_drop / light_source_extinguished / visibility_restored`
- `smoke_visible / fire_visible / fire_spread_visible`
- `bloodstain_visible / footprint_visible / water_trace_visible / disturbance_mark_visible`
- `tamper_candidate / concealment_candidate / injury_visibility_candidate / private_exchange_candidate`

## 5. 一句话收束

角色表达类事实更适合 `Fact + Bias`，因为差别主要来自解释层；物体、环境、证据结果类事实更适合 `Fact Family`，因为差别已经属于世界事实本体差异。
