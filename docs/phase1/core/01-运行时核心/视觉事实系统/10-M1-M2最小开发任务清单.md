# 10-M1-M2最小开发任务清单

## 1. 文档目标

本文档按“先打通闭环，再上复杂语义”的原则，给出 Phase 1 视觉事实系统第一批开发任务清单。

## 2. M1 范围

M1 只覆盖：

1. `door_opened_partial`
2. `object_removed_from_surface`
3. `light_level_drop`

### M1-1 公共结构
- `VisualFactEvent`
- `PerceptibleCandidateEvent`
- `SampleFrameBase`
- `SemanticFrameBase`
- `VisualFactEmitterBase`

### M1-2 `ObjectSampler`
- 输出 `ObjectStateSampleFrame`

### M1-3 `ObjectSemanticExtractor`
- 提取 `removed_from_surface` / `opened_partial`

### M1-4 `ObjectVisualFactEmitter`
- 发 `object_removed_from_surface` / `door_opened_partial`

### M1-5 `EnvironmentSampler`
- 输出 `EnvironmentStateSampleFrame`

### M1-6 `EnvironmentSemanticExtractor`
- 提取 `light_drop`

### M1-7 `EnvironmentVisualFactEmitter`
- 发 `light_level_drop`

## 3. M2 范围

M2 只覆盖：

4. `fixed_gaze_on_target`

### M2-1 `CharacterSampler` 最小版
- 只支撑 gaze 样板，不先做全角色语义

### M2-2 `GazeController`
- 输入 `target_actor_id / mode / weight / duration_ms / revision_seq`
- 输出本地 `GazeRuntimeState`

### M2-3 `GazeModifier3D`
- 头 / 颈 / 可选眼球局部精修

### M2-4 `CharacterSemanticExtractor` 最小 gaze 版
- 提取 `fixed_gaze` / `checking_gaze` / `gaze_stability`

### M2-5 `CharacterVisualFactEmitter` 最小版
- 发 `fixed_gaze_on_target`

## 4. 工作台最小支持

M1-M2 阶段至少要能看见：

- sample 输出
- semantic 输出
- visual fact 输出
- candidate 输出
- 简易时间线

## 5. 顺序建议

### 必须先做
1. 公共结构
2. 工作台最小链路
3. `ObjectSampler`
4. `EnvironmentSampler`

### 然后做
5. `ObjectSemanticExtractor`
6. `EnvironmentSemanticExtractor`
7. `ObjectVisualFactEmitter`
8. `EnvironmentVisualFactEmitter`

### 再进入角色域
9. `GazeController`
10. `GazeModifier3D`
11. `CharacterSampler`
12. `CharacterSemanticExtractor`
13. `CharacterVisualFactEmitter`

## 6. 阶段验收标准

### M1
- `door_opened_partial` 跑通
- `object_removed_from_surface` 跑通
- `light_level_drop` 跑通
- replay 和工作台可见

### M2
- `fixed_gaze_on_target` 跑通
- 普通扫视不误报
- 近中远三层可读性成立
- 玩家主动镜头移动不被硬抢

## 7. 一句话收束

M1-M2 的任务不是“让视觉事实系统看起来完整”，而是先把 object/environment 的低风险事实和 character/gaze 的第一条高价值角色事实跑成可调、可看、可回放的闭环。
