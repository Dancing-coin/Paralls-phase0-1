# 03-视觉事实系统总纲

## 1. 文档目标

本文档定义《开本》视觉事实上抛器系统的总体职责、分层、一级源域、派生层以及与角色感知链、司命和证据链的关系。

## 2. 核心定义

视觉事实上抛器系统的职责不是“广播骨骼和表情”，而是：

> 把世界中一切已经在 Godot 里可见成立、且值得进入推理/叙事/感知链的视觉变化，提炼成结构化视觉事实事件。

## 3. 总体结构

系统固定分两层：

### 一级源域

1. `character`
2. `object`
3. `environment`
4. `spatial_relation`

### 派生层

5. `evidence_projection`

## 4. 为什么 `evidence` 不做一级源域

`evidence` 不是世界源域，而是从：

- `character`
- `object`
- `environment`
- `spatial_relation`

四类视觉事实中投影出来的搜证/推理价值。

## 5. 总体数据流

`Godot 本地可见状态层`
-> `本地采样层`
-> `本地语义层`
-> `4 个一级源域抛器`
-> `evidence_projection`
-> `事件总线`
-> `可感知信息编译层`
-> `Per-Character 感知过滤器`

## 6. 四个一级源域抛器

### CharacterVisualFactEmitter
- 角色姿态、表情、视线、步态、可见异常状态

### ObjectVisualFactEmitter
- 物体位置、可见性、开合、完整性、贴身遮掩等状态变化

### EnvironmentVisualFactEmitter
- 光照、火焰、烟雾、门窗、痕迹、天气可见化变化

### SpatialRelationVisualFactEmitter
- 角色与角色、角色与物体、角色与空间关键点形成的视觉关系

## 7. EvidenceProjectionEmitter

不直接采样世界，只消费前 4 个一级视觉事实，再判断：

- 哪些变化具备搜证价值
- 哪些变化具备推理价值

输出：

- `visual_evidence_projection`

## 8. 系统定位

- 上游：Godot 本地执行与采样系统
- 横向：角色智能体、司命、`ESM`、证据链
- 下游：事件总线、可感知信息编译层、调试/回放系统

## 9. 一句话收束

视觉事实系统不是角色表演附属功能，而是“世界可见真相的结构化入口”：谁动了、东西变了、环境变了、空间关系变了、哪些变化因此有证据价值，都从这里进入运行时链路。
