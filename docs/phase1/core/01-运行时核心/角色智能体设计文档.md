## 2. 统一定义

角色智能体是《开本》中每一个剧中角色的统一运行时决策核心。

它不是：

- 普通 NPC 行为树
- 单次 LLM 调用壳
- 纯对话器
- 玩家的纯手动角色壳
- 司命的下属执行脚本

它持续回答：

- 这个角色感知到了什么
- 这个角色如何理解这些信息
- 这个角色当前想做什么
- 这个角色最终会如何说、如何动、如何露出自己

一句话：

> 角色智能体是“剧中角色在世界内的连续存在体”。

## 3. 四条总边界

### 3.1 与玩家 / 旅人的边界

当前统一口径：

- 玩家：现实操作者
- 旅人：玩家在 Paralls 中的 Meta 身份
- 剧中角色：世界内角色实例
- 角色智能体：剧中角色的统一运行时本体

统一关系为：

`玩家 -> 旅人 -> 剧中角色 -> 角色智能体`

### 3.2 与司命的边界

司命是全局叙事催化者，角色智能体是世界内角色本体。

- 司命只能催化、唤醒、揭示、制造窗口
- 角色仍需经 `L2/L3` 自己承接与决定
- 司命不能越权直控角色动作

### 3.3 与 ESM 的边界

- `ESM` 负责身体和环境事实是否成立
- 角色智能体负责这些事实对角色意味着什么，以及它将如何应对

### 3.4 与事件总线的边界

角色智能体不是全量订阅者。

- 默认不直接消费全局原始事实流
- 正式消费的是经过可感知信息编译层和 Per-Character 过滤后的角色私有感知事件
- 只回写对世界和其他系统有意义且可重放的结构化行为结果

## 7. 当前采用规则

后续任何文档提到角色智能体时，应统一采用以下口径：

- 角色智能体是完整自主角色驱动核心，不是普通 NPC 或对话树
- AI 角色与玩家投影角色共享同一套底层心智结构，只是驾驶模式不同
- 玩家真实认知发生在人脑中；系统内 `L1/L2` 负责角色连续性与主观补全，不替代玩家思考
- 角色默认不直接消费全局原始事件流，而是消费经过编译和 Per-Character 过滤后的感知事件
- 所有关键行为都受三重过滤器约束
- 司命回写角色的只能是高层消息，不能直接控制低层动作
- `ESM` 决定身体事实，角色层决定主观意义与行为后果
- 带走后的小世界角色仍是同一角色底层的压缩续接，不是新建陪伴壳体
