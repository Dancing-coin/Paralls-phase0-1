# 信息共享与知识状态设计

## 状态

- 当前状态：第一轮可执行整理稿
- 主要用途：冻结信息默认私有原则、共享动作、知识形态、偷听机制与证据传播边界
- 事实口径：以 `037`、`038`、`217`、`233`、`309`、`398`、`400` 的后期收束为当前冻结版

## 当前冻结结论

- 信息默认私有，共享必须是主动行为
- 信息共享执行系统按“五种共享方式 + 三种知识形态 + 偷听检测”冻结
- 公共知识、共有知识、高阶知识必须严格区分
- 留影石 / 相机属于“信息共享执行系统 + 证据可视化链路”的交叉工具，不是独立主线系统
- 证据图片 / 特写只服务视觉可见证据，且必须由玩家主动触发

## 1. 文档目标

本文档用于冻结《开本》信息传播层的：

- 默认私有原则
- 主动共享动作
- 公共知识 / 共有知识 / 高阶知识的判定边界
- 偷听与旁听检测
- 留影石 / 相机的系统位置
- 与角色记忆、事件总线、证据链和笔记系统的接口关系

本文档不展开：

- 事件总线字段级协议
- 角色心智模型内部实现
- 证据链五层职责细节
- 客户端完整 UI 设计

## 3. 根规则

### 3.1 信息默认私有

当前稳定规则是：

- 玩家和智能体发现的线索、秘密、判断默认只归自己掌握
- 系统不会因为某条信息“重要”，就自动广播给相关角色
- 信息一旦共享，就同时暴露“谁在共享、共享给谁、共享发生在何处”

### 3.2 共享必须可验证

共享行为不能只存在于抽象状态里，必须通过游戏内动作落地。

最少包括五种共享方式：

- 公开对话
- 耳语 / 私密对话
- 展示物品
- 带人查看
- 留影石 / 相机拍摄

## 4. 五种共享方式

### 4.1 公开对话

- 传播范围最广
- 最容易形成公共知识
- 同时风险最高，最容易暴露身份、态度和立场

### 4.2 耳语 / 私密对话

- 只在局部小范围同步信息
- 默认形成共有知识，而不是公共知识
- 必须接受被偷听、被误听、被截断的风险

### 4.3 展示物品

- 适用于视觉证据和实物证据
- 谁在场、谁能看见、看清到什么程度都要受空间与感知约束
- 不等于自动同步全部背景解释

### 4.4 带人查看

- 保留空间行动与场景证据的价值
- 适合展示“现场本身”而不是单一物品
- 会留下谁曾到过现场、谁知道现场状态的知识链

### 4.5 留影石 / 相机拍摄

- 是证据记录与传播工具
- 属于“信息共享执行系统 + 证据可视化链路”的交叉位置
- 可以被拍摄、持有、转交、公开展示、私下分享

但它不是：

- 所有证据的自动复制器
- 独立凌驾于证据链本体之上的核心系统

## 5. 三种知识形态

### 5.1 公共知识

公共知识指某信息已在公开场景被展示或宣告，在场相关角色不仅都知道该信息，也知道彼此都知道。

### 5.2 共有知识

共有知识指某个局部群体通过私下共享完成同步，但外部角色并不知道这次同步已经发生。

### 5.3 高阶知识

高阶知识是“关于别人知道什么”的知识结构，例如：

- 我知道你知道
- 我知道你不知道
- 我怀疑你知道，但不确定你知道多少

这类结构是以下行为成立的底层：

- 试探
- 撒谎
- 装傻
- 反伪装
- 沉默施压

## 6. 偷听与旁听

### 6.1 偷听不是 UI 开关

偷听首先是空间、距离、遮挡、声音强度和感官能力共同决定的结果。

### 6.2 偷听产出不是二元真值

偷听结果不应只分“听到 / 没听到”，而应允许：

- 听全
- 听到片段
- 听错
- 只知道有人在密谈，但不知道内容

## 7. 与其他系统的接口

### 7.1 与事件总线

- 事件总线承载共享动作与相关世界事件
- 但“是否形成公共知识 / 共有知识 / 高阶知识”不是事件总线自身的业务判断

### 7.2 与角色智能体

- 角色记忆必须保存信息来源、传播方式和知识层级
- 角色 `L2` 不只要知道“我知道什么”，还要知道“别人可能知道多少”

### 7.3 与司命

- 司命的高阶知识图谱需要订阅共享动作结果
- 司命可以利用知识不对称催化冲突
- 但司命不能绕过共享动作，直接替角色构造不该存在的知识同步

### 7.4 与证据链

- 证据能否传播，不只取决于是否存在，还取决于是否被观察、拍摄、展示、转交
- 证据图片传播范围必须遵守知识状态规则，不能脱离信息系统单独扩散

### 7.5 与笔记系统

- 笔记面板应支持线索、证据、时间线、关系网和嫌疑判断
- 但笔记是“角色已掌握信息”的整理器，不是全知数据库

## 8. Phase 1 边界

### 8.1 Phase 1 必须冻结

- 信息默认私有原则
- 五种共享方式
- 三种知识形态
- 偷听检测基础版
- 留影石 / 相机的基础定位
- 证据图片的主动触发与受限传播

### 8.2 Phase 1 不要求

- 更复杂的群体信息传播模拟
- 超细粒度的谣言扩散模型
- 自动化知识图谱可视编辑器
- 更复杂的跨局知识继承

## 9. 当前采用规则

后续所有文档提到信息传播、知识状态、偷听、证据展示时，应统一采用以下口径：

- 信息默认私有，共享必须主动发生
- 共享动作必须可验证
- 公共知识、共有知识、高阶知识必须分层
- 留影石 / 相机是证据记录与共享工具，不是独立主线系统
- 证据图片只服务视觉可见证据，且必须由玩家主动触发
