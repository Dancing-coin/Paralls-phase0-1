# 16-角色智能体调试工作台设计

## 1. 文档目标

本文档冻结工程师、策划、QA 如何实际观察、解释、定位、回放角色智能体的运行过程。

## 2. 核心定位

工作台不是日志页，而是“角色主观链路的可视化解释台”。它必须能回答：

- 角色刚才看见了什么
- 它没看见什么
- 它记住了什么
- 它为什么怀疑/相信
- 它为什么选了这个行为
- 它脸和身体为什么这样表现

## 3. 用户角色

至少服务：

- 工程师
- 策划 / 叙事设计师
- QA / 验收人员

并提供不同视图。

## 4. 八个主面板

1. 角色概览面板
2. 感知与私有世界面板
3. 记忆与知识面板
4. 理解与信念变化面板
5. 规划与三重过滤器面板
6. 执行与具身表达面板
7. 玩家接管 / 挂机接管面板
8. 回放与对比面板

## 5. 三种视图模式

- `Engineering View`
- `Design View`
- `Narrative View`

## 6. 必须能追踪的链路

`PerceivedEvent -> Interpretation -> Belief -> CandidateAction -> Filter -> Intent -> Expression -> Execution`

## 7. 关键能力

- 全局时间轴
- 单角色回放
- 双角色对照
- 越权与 OOC 高亮
- 当前 autonomy mode 可视化
- `FACS/SACS` 与执行结果联动查看

## 8. Phase 1 范围

Phase 1 至少交付：

- 角色概览
- 感知/私有世界
- 记忆/知识
- 规划与过滤器
- 执行与表达
- 玩家/挂机接管
- 单周期回放
- 人类可读解释摘要

## 9. 一句话收束

角色智能体调试工作台不是把日志展示出来，而是把角色主观链路、边界约束、决策理由和具身表达统一翻译成可被工程、策划和 QA 共同使用的解释界面。
