# 04-记忆系统与知识状态设计

## 1. 文档目标

本文档冻结角色如何把感知结果沉淀为可持续使用的内部认知结构。

## 2. 核心原则

### 2.1 记忆不是一坨聊天历史

角色智能体不能把所有经历塞成一条长上下文文本；否则会失去可追踪性、知识层级、来源区分和误判保真。

### 2.2 记忆不等于知识

角色可以记得自己看见了什么，但不一定知道那意味着什么；也可以知道一件事为真，却不记得最初是哪一次观察带来的。

## 3. 五池结构

记忆系统固定拆成：

1. `Event Memory`
2. `Observation Memory`
3. `Knowledge Memory`
4. `Social Memory`
5. `Higher-Order Memory`

## 4. Event Memory

记录“发生过什么”，与角色是否解释它无关。至少包含：

- `source_event_id`
- `world_ts`
- `event_type`
- `participation_mode`
- `source_channel`
- `summary`
- `clarity_score`
- `certainty_score`

## 5. Observation Memory

记录“我实际看见/听见/闻到/注意到了什么细节”。允许：

- partial
- distorted
- ambiguity

它是角色主观观察版本，而不是世界事实真值。

## 6. Knowledge Memory

记录角色当前认为自己知道的命题化内容，例如：

- 谁在撒谎
- 某把刀原本不在桌上
- 某人可能在保护别人

至少维护：

- proposition
- acquisition_mode
- confidence_level
- knowledge_state
- contradiction_refs
- currently_believed

## 7. Social Memory

记录角色对他人的长期关系性认知，包括：

- trust_baseline
- suspicion_baseline
- emotional_valence
- dependency_level
- intimacy_level
- unresolved_tensions
- shared_secret_refs

## 8. Higher-Order Memory

记录角色对“谁知道什么、谁知道别人知道什么”的主观高阶认知，而不是司命全局高阶知识图谱真值。

## 9. 私有世界快照与记忆的边界

- `Private World Snapshot` 是当前短时感知场
- 记忆是已经沉淀下来的可持续内部记录

二者不能混。

## 10. 知识状态模型

最小状态集：

- `noticed`
- `suspected`
- `tentatively_believed`
- `believed`
- `high_confidence_believed`
- `disputed`
- `abandoned`

## 11. 会话结果不另建第六池

对话结果应拆入五池：

- 听见一句话 -> Observation
- 相信某句话 -> Knowledge
- 因此更信任某人 -> Social
- 推断“他知道我知道” -> Higher-Order

## 12. Phase 1 范围

Phase 1 必须支持：

- 五池结构
- 感知到记忆的沉淀链
- 命题化知识对象
- 关系性记忆对象
- 高阶知识对象
- 知识来源标签
- 冲突引用
- 会话结果拆入五池

## 13. 一句话收束

角色记忆系统不是给模型塞上下文，而是为角色构建一个分层的、带来源与置信度的内部认知结构，使角色能在不完整、可冲突、可误判的信息条件下持续保持人格与博弈一致性。
