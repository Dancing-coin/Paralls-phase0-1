# 10 主动感知与记忆边界设计

状态：`planned architecture; non-authorizing`

## 1. 主题结论

记忆只能说明角色过去知道什么，不能保证世界现在仍然如此。信息缺失、过期或冲突时，角色不必自动走回原地，可以比较观察收益、时间、风险和资源后选择信息获取策略。

- `[current]`：L1 私有感知、主动感知触发和记忆写回边界已有运行时基础。
- `[planned]`：typed information request、信息新鲜度、冲突处理和主动感知策略选择。
- `[deferred]`：自动回到原地点重新观察；把长期记忆当作全知世界模型。

## 2. 策略类型

```text
RecallStrategy              先检查记忆和当前上下文
LocalReobserveStrategy      原地重新观察
RepositionAndObserve       移动到更好位置再观察
AskOtherActor               询问队友或 NPC
ProbeAction                 用低风险行动试探
DeferStrategy               暂缓获取，先保持安全
AbandonStrategy             信息价值低于成本时放弃
```

## 3. 架构图

```mermaid
flowchart LR
  M[Memory evidence] --> Q[Information gap/conflict]
  L1[L1 current percept] --> Q
  Q --> D[Mind/L3 value-risk comparison]
  D --> S[Recall/reobserve/reposition/ask/probe/defer]
  S --> A[Information action intent]
  A --> W[Authority/actor result]
  W --> L1
```

## 4. 时序图

```mermaid
sequenceDiagram
  participant M as Memory
  participant L1 as L1
  participant L3 as L3
  participant X as Actor
  participant W as World authority
  M-->>L3: stale or conflicting evidence
  L1-->>L3: current partial percept
  L3->>L3: compare information value and risk
  L3->>X: reobserve/ask/probe/defer intent
  X->>W: perform information action
  W-->>L1: actual observed result
  L1->>M: write revised evidence
```

## 5. 数据流图与记忆字段

```mermaid
flowchart TD
  E[Past evidence] --> R[Recall with freshness check]
  C[Current percept] --> R
  R --> U[Unknown/conflict assessment]
  U --> I[Typed information request]
  I --> O[Observation/action result]
  O --> N[New percept]
  N --> E
```

每条记忆至少带有：

```text
source
captured_at
freshness
confidence
attention
conflict
revision
```

记忆是证据，不是当前世界真相；重新感知结果必须重新经过 L1。
