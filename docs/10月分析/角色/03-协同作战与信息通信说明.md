# 03 协同作战与信息通信说明

本说明对应 [03 设计](03-协同作战与信息通信设计.md)。

## 接口建议

```text
TeamSignal
  source_actor
  signal_type
  observation_ref
  confidence
  target_actor / target_group
  issued_at / expires_at

CoordinationContract
  contract_id
  purpose
  participant_roles
  local_obligations
  abort_conditions
  context_version
```

## 信息可信度

队友信息必须保留来源、时间、置信度和有效期。接收方可以接受、暂缓、拒绝或报告冲突；通信不是 authority 事实，也不能跳过本地 L1。

## 当前实现对照

现有主动感知和 L1 provider 链可以承接协同信号的输入侧；团队契约、语音传播和多角色局部信息隔离仍属于规划能力。不要把“后端能传一条消息”描述成“协同战已经完成”。

## 验证重点

- 过期信号是否不再改变动作。
- 角色局部看不到的信息是否不会凭空出现在心智状态。
- 一个角色退出契约后，其他角色是否能恢复自己的快循环。
- 队友错误判断是否能被本地观察纠正。


## 本批规格与计划回写（2026-10-10）

本说明与角色03设计共同作为协同输入来源。收敛计划保持发送者局部观察、接收方独立 L1、local_intent 和可退出短契约；C 使用独立验收场景，不能复用 `StreetCombatDemo` 的语义。说明中的消息字段只是来源语义，不创建通信 authority 或共享脑。
