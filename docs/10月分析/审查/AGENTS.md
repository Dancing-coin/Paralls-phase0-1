# 十月分析规格与计划审查规则

本目录只存来源覆盖、命名/链接审查和静态证据，不定义新的领域对象或实现权限。

- 每个结论必须能回到十月分析四个原始域目录或角色动作工作流原文的具体文件/章节。
- current只能表示仓库代码、测试或既有设计入口可直接证明的边界；planned表示有原文依据但尚未实现；deferred仅表示原文允许暂缓。永久禁止项必须单独标记，不得放进deferred。
- 审查通过是文档静态覆盖，不是运行时完成。没有真实owner、协议或验证证据的项必须列为待决/阻断。
- 不在本目录新建第二套clock、scheduler、event store、tag registry、authority或角色心智对象。
