# 角色协同、表达与精神边界实施计划

状态：`analysis/planned/non-authorizing`。本轮交付规格与计划文档，任务复选框表示未来实施，不是已执行记录。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有角色心智链和 L4 五通道边界上规划协同信号、短期协同契约、表达调节、理智投影和语音租约接入。灵魂规则只消费未来由通用领域 owner 提供的私有投影，不在本计划虚构 `SoulAccessGate` 或新的通信 authority。

**Architecture:** 以迁入的 08 号规格为主设计；新增对象是派生投影和 proposal，不是第二套心智或灵魂 authority。表达计划最终进入 `CharacterExecutionContract`/CharacterActor，世界后果仍由 owner 结算。

**Tech Stack:** 现有 CharacterAgent profile/dynamic state/voice/dialogue/actor bridge、Pydantic、pytest、Godot evidence。

**Spec:** [08-角色协同表达与精神边界规格](../规格/08-角色协同表达与精神边界规格.md)

## Global Constraints

- `MentalRegulationProjection` 是派生输入，不是新 authority。
- 没有注册精神资源的世界不生成隐形精神条。
- 原角色15提出的 `spiritual_rule`/`SoulAccessGate` 当前无 runtime owner；本计划只规定未来 owner 结果进入 L1 的隐私过滤位置。
- 表达五通道不能直接修改生命、资源、关系或灵魂事实。
- 协同信号沿空间声音/可见信号进入接收方 L1；短期契约包含目标、参与者、责任、有效期、失败条件和退出方式。每个角色保留自己的 `local_intent`。

## Review Focus

- 表达失控被误当成世界事实：必须只产生 episode/intent/evidence。
- 协同消息泄露发送者私有 memory：必须由 disclosure scope 和 recipient projection 阻断。
- 理智/精神字段与生命资源双写：必须有唯一 owner 和 projection direction。
- soul gate 结果泄露不可见规则：必须只提供角色有权知道的摘要。
- Godot 表现无反馈：必须进入 episode missing-feedback，而不是成功。

## Dependency order

角色阶段执行Task1–4、Task5的已有resource owner私有消费/无soul owner拒绝和Task6适用表现检查。若 `capacity/locked` 映射未准入，Task1/5沿当前 `minimum/maximum/current/reserved/available` 投影，不扩展资源事实；未定阈值不得由实现者猜成正式规则。计划04准入resource/life/spiritual-rule owner及版本映射后，回到Task5/6验收新投影。这个回验不作为计划04开工前置；独立列出缺owner和Godot未验证项。

[D02/D06/D11](../审查/03-实施待决收敛与验证闸门.md)规定：角色基础先行，缺Life/Presence/Soul owner时沿现有readiness/diagnostic表示不可用并私有过滤，不伪造成功gate；资源在计划04集中迁移后回验。Task3/4的独立通信/租约合同与已有owner消费可先做；真实连续双角色协同C由Task6A在单角色Boss B通过后验收，不作为计划04的开工前置。角色基础门、B/C场景门、未来Soul回验和Godot表现证据分别记录。
