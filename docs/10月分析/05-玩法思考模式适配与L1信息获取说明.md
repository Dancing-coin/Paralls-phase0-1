# 05 玩法思考模式适配与 L1 信息获取说明

本说明对应 [05 设计](05-玩法思考模式适配与L1信息获取设计.md)。

## 现有实现映射

- L1 私有快照和 PQF/provider 感知链：`backend/app/character_agent/reasoning/l1_perception.py`。
- 主动感知触发：`backend/app/character_agent/reasoning/active_perception.py`。
- L2/L3 模型入口：`backend/app/character_agent/reasoning/l2_reasoner.py`、`backend/app/character_agent/planning/l3_planner.py`。
- 玩法状态与 authority 结算：以当前 mainline 文档和对应领域 Owner 为准，不能由模型直接写入。

## 当前真实链路

### 事实抛出器主链

Godot 的 `scripts/l1/facts/RawFactEmitter.gd` 和各类 emitter 通过 `BackendBridge` 发送 `raw_fact_event`。后端在 `backend/app/main.py` 中执行：

```text
RawFactEvent
  -> L1 foundation / occupancy 更新（必要时生成空间派生事实）
  -> compile_candidate_percepts
  -> filter_candidate_for_actor
  -> CharacterPerceivedEvent
  -> CharacterAgentL1Service.apply_character_perceived_event
```

这条链是当前角色每轮最直接的感知入口。

### PQF/provider 多模态链

同一 `raw_fact_event` 处理过程中，后端还会收集 payload 中的 `l1_provider_refs`；没有显式 refs 时会生成运行时 ref。`L1RuntimePerceptionBridge` 为每个角色和 Siming 建立隔离的 `PerceptionInputFrame`、PQF 和 `CanonicalPerceptBundle`，再调用角色 runtime 的 `ingest_canonical_percept_bundle`。provider ref 是采样引用和质量/新鲜度元数据，不等于模型已经理解出的事实。

### VLA 当前接入深度

`VLAAdvisorySlowPath` 可以把 PQF 路由为 `VLAProviderRequest`，经 scheduler、cache 和 provider adapter 得到 `VLAProviderResult`；`merge_vla_advisory_into_bundle` 将结果放到 `world_hypotheses` 和 `uncertainty.vla_advisory`，`ActorSceneKnowledgeStore` 以 `source_kind="vla_advisory"`、`advisory=true` 保存，不覆盖 `l1_projected_fact`。

当前主应用入口没有自动编排这条 slow path；VLA 链路主要由显式调用和验证脚本覆盖。因此当前应描述为：`事实主链 + PQF/provider 增强链 + 可调用的 VLA advisory 支路`，而不是“每次 L1 都由 VLA 感知”。

默认配置还保持 `VLA_PROVIDER_MODE=blocked`、Deep advisory 关闭；真实 provider 运行需要单独的凭证、artifact 和 live proof。

## 推荐适配器契约

```text
ThoughtModeDescriptor
  mode_id
  domain
  input_projection
  allowed_intents
  information_request_types
  activation / suspension rules

InformationRequest
  requested_observation
  reason
  urgency
  target_scope
  expires_at

PerceptionResult
  observed_facts
  uncertainty
  source
  context_revision
```

## 验证重点

1. 角色没有被直接注入玩法完整事实。
2. 信息需求必须转成 L1 可执行的观察、调查、询问或试探行为。
3. 战斗和经济模式可以同时存在，但最终 intent 只有一个，其他目标有明确保留/暂缓状态。
4. authority 结算结果经过 L1 回到心智模型。
5. 模式切换、信息缺口和主动感知都有可回放的来源和版本。
