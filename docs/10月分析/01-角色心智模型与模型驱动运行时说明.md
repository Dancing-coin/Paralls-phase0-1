# 01 角色心智模型与模型驱动运行时说明

本说明是 [01 设计](01-角色心智模型与模型驱动运行时设计.md) 的代码与验证入口索引。

## 当前代码入口

| 能力 | 当前入口 | 说明 |
|---|---|---|
| 主动感知 | `backend/app/character_agent/reasoning/active_perception.py` | 已有冲突、陈旧、目标消失、可达性失败等触发 |
| L1 感知 | `backend/app/character_agent/reasoning/l1_perception.py` | 私有快照、provider/PQF 感知链 |
| L2 | `backend/app/character_agent/reasoning/l2_reasoner.py` | 现有模型入口和心智状态接入；规划语义仍需继续收口 |
| L3 | `backend/app/character_agent/planning/l3_planner.py` | 现有候选过滤/评分；模型最终选择边界需按目标设计调整 |
| L4 | `backend/app/character_agent/execution/l4_executor.py` | 执行承接和动作契约入口 |
| runtime | `backend/app/character_agent/runtime/runtime_loop.py` | 认知调度和 continuation 入口 |

## 接入顺序

1. 保留 L1 的唯一信息入口。
2. 在心智模型中生成 `ThoughtModeFrame` 和 `GoalPortfolio`。
3. 为 Laya 提供精简、typed、带版本的 Fast L2/L3 输入。
4. Laya 只输出候选 intent；本地代码做权限、能力、时限和执行校验。
5. 失败、过期、连续不确定或长期冲突时，异步请求慢思考；必要时再调用 Deep Model。
6. 结果回写同一心智状态，不能创建第二套隐藏脑状态。

## 验证入口

- 静态：检查 L1、authority、L4 和模型上下文的边界。
- 后端：`python -m pytest -v`。
- 角色智能体相关 profile：以 `.harness/profiles/` 和 `docs/harness.md` 的现行 profile 为准。
- 现阶段不能宣称 Laya 已接入，除非有真实 checkpoint、运行日志和对应 profile 证据。

## 迁移风险

- 现有 L3 本地候选过滤可能继续拥有过多语义决策权。
- 模型不可用时必须进入声明过的 continuity floor，不能静默伪造完整认知。
- 现有 Phase 0 demo 只能作为兼容路径，不能反向定义完整心智模型。
