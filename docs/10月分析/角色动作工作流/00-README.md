# 角色动作工作流

状态：`analysis/planned/non-authorizing`

本目录定义 XSXB Animation Director 的骨架注册、中央动作库、AD 中介骨架、通用骨骼映射工作区、四视角参考、浏览器预览和 Blender MCP 正式烘焙边界。

方案拆成两个大阶段：

1. **骨架与动作库基础、映射和预览**：建立 Profile、RigBinding、动作库登记、映射对照和已有 Action 的预览/迁移基础；
2. **关键帧参考驱动的动作编辑与动作制作**：在第一阶段合同之上，加入四视角关键帧、已有动作非破坏性修改和新动作创建。

主设计文档：[01-AD骨架动作参考与重定向工作流设计](01-AD骨架动作参考与重定向工作流设计.md)

本目录的分析文档不授权实现。正式实现仍需经过仓库的 spec、plan 和验证流程，并与统一动作库阶段 1–3 的正式文档保持一致。
