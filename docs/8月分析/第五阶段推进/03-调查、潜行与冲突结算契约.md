# 调查、潜行与冲突结算契约

状态：`incremental design; P5C formal spec required before implementation`

本阶段优先选择一个受限的调查/潜行 vertical slice，再决定是否扩展为实时战斗。它复用
现有 action/perception、skill/ability、物品、状态和 mirror 路径，不在 Godot 或模型端
建立第二套战斗真相。

## 1. 调查路径

```text
observe/search intent
-> perception/visibility and skill gate
-> physical/logical fact + evidence refs
-> Quest/Knowledge authority evaluation
-> objective progress or structured failure
```

失败可以是视野不足、技能不足、工具缺失、证据过期或权限拒绝；失败本身可形成 trace，
但不自动生成“玩家已经发现”的事实。

## 2. 潜行与冲突路径

```text
approach/hide/intercept intent
-> location, visibility, capability and state projections
-> exposure/damage/retreat proposal
-> Conflict/Action owner validates effect/resistance and evidence
-> committed result -> social/quest/economy consequences
```

伤害、物品损耗、暴露、追捕、赔偿和关系变化分别由对应 owner 写入；任何客户端预测、
模型建议或司命 catalyst 都只能提出 intent/proposal。

## 3. 受限策略

第一版只实现可回放、低规模、离散结算的调查/潜行冲突，不实现全身实时战斗、战争 AI、
大规模敌群或物理破坏。所有 effect/resistance、标签和规则都必须来自注册 revision。
