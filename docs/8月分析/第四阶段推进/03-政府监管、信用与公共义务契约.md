# 政府监管、信用与公共义务契约

状态：`incremental design; P4C formal spec required before implementation`

P4 把现有 permit、inspection、tax assessment、debt、contract 原语组合成有限的制度经济。
Government 不直接控制角色身体或组织资产；Economy 不直接改变政策和许可。

## 1. 监管闭环

```text
policy revision activated
-> organization submits permit/operation evidence
-> government inspection/assessment
-> permit, tax or remediation obligation
-> economy/contract settlement
-> public compliance projection
```

检查失败只能创建 remediation/penalty obligation 或 permit state transition；不得删除历史、
直接扣库存，或把自然语言检查结论当成 canonical fact。

## 2. 有限信用边界

P4 只支持与商业 reference slice 直接相关的有限 credit：授信 proposal、债务 claim、还款、
逾期/default 和恢复。信用判断读取公开/授权的组织 period、已结算 obligations 和政策，
不读取其他角色私有记忆，也不实现宏观金融信用评分。

```text
credit proposal
-> policy + organization evidence
-> Contract/Debt claim
-> account disbursement (if approved)
-> repayment/overdue obligation
-> public compliance/credit band projection
```

任何授信或处罚必须保留 source evidence、policy revision、审计引用和可重放结果。

## 3. 明确后置

法院判决、政治协商、选举、军事指挥、系统性金融风险、货币发行和跨辖区财政转移不属于
P4；它们进入 P7 的文明/公共秩序 spec，并继续复用 Government、Contract、Debt、Economy
和 EventStore owner。
