# 项目定位与当前能力边界

## 1. 本线程形成的产品判断

项目的最终方向是“通用智能体驱动的游戏底座”，但近期落地场景应收窄为：

> 面向剧本杀、调查、社交冒险和轻量 RPG 的角色智能体游戏底座。

底座的价值不在于提前制作某一个固定游戏，而在于把以下链路固化：

```text
角色档案与世界设定
-> 私有感知
-> 角色理解、记忆和目标
-> 结构化行动请求
-> 世界/玩法权威结算
-> 事件与状态回放
-> Godot/其他呈现层表现
```

创作者提供的是内容、资产和受治理规则；底座提供的是角色心智、状态、权威、事件、同步、回放和工具接口。

## 2. 当前已经具备的基础

### 角色智能体

- L1 私有感知入口；
- L2 主观理解与认知更新；
- L3 目标与意图规划；
- L4 结构化执行契约；
- Event、Observation、Knowledge、Social、Higher-Order 五池记忆；
- NeedTension、affect、dynamic state、goal state 和长期 drift；
- 技能目录、技能路径、行动请求和行动可用性评估。

### 世界和玩法权威

- 结构化 interaction intent；
- ESM/Gameplay authority；
- 资源、身体功能、状态标签、属性 modifier；
- 背包、容器、负重、装备、产权和固定交易；
- 原子事件批次、幂等、revision 冲突、失败结果、回放和 outbox；
- 后端状态向 Godot 的 snapshot/delta 镜像。

### 当前参考闭环

`adventure-basic` 已经验证了买剑装备、身体/耐力约束、储物戒、地契与产权、赠与/债务/简单合同等组合场景，并有后端回放与 Godot 镜像证据：

- `.harness/verification/gameplay-foundation-all-report.json`
- `.harness/verification/adventure-basic-report.json`

## 3. 可以支撑的游戏类型

当前比较适合：

- 剧本杀和调查推理；
- 角色社交和关系驱动剧情；
- 对话、秘密、证据和信息传播；
- 探索、检查、开门、拿取、携带、放置；
- 简单交易、赠与、契约、债务和产权剧情；
- 轻量装备、资源限制和能力门槛；
- 智能体驱动的 NPC 行为和角色间自主互动。

## 4. 当前不能直接宣称的能力

### 完整动作 RPG

目前存在挥剑、格挡的输入和动作表现，但还不是完整战斗系统。缺少命中、伤害、防御、硬直、击退、连击、目标锁定、敌人 AI、战斗遭遇和多人战斗同步。

### 完整经济模拟

当前是账户、固定报价、物权、赠与、债务和简单合同原语，不是动态市场、生产链、工资、税收、企业经营和政府监管系统。

### 任意剧本一键生成完整游戏

当前已有内容和规则扩展边界，但还缺少任务系统、剧情目标编译器、资产校验、场景拼装、UI 生成、测试回放和发布流水线。

### 世界模型生成完整游戏世界

当前 VLA/多模态路径主要是感知和 advisory 输入，权威事实仍由世界运行时、ESM、Gameplay 和物理/场景层负责。世界模型尚未成为完整世界真相或世界持久化引擎。

## 5. 一句话定位

当前项目不是“已经做完的通用游戏引擎”，而是：

> 已经完成角色智能体和权威玩法运行时的关键骨架，正在从 RPG/剧本杀垂直底座向可被创作者和 Codex 调用的通用内容运行时演进。
