# 项目定位与当前能力边界

状态：`incremental product-boundary guidance; current capability claims require code and Harness evidence`

## 1. 本线程形成的增量产品定位

“通用智能体驱动的游戏底座”是从当前能力继续扩展的产品方向，不替代仓库当前
`world-character-Siming-authority unified runtime` 主线。近期可验证的落地场景应收窄为：

> 面向剧本杀、调查、社交冒险和轻量 RPG 的角色智能体游戏底座。

底座的价值不在于提前制作某一个固定游戏，而在于把以下链路固化：

```text
角色档案与世界设定
-> 私有感知
-> 角色理解、记忆和目标
-> 结构化行动请求
-> 世界/玩法权威结算
-> 事件与状态回放
-> Godot/其他呈现层表现
```

创作者提供的是内容、资产和受治理规则；底座提供的是角色心智、状态、权威、事件、同步、回放和工具接口。创作者控制面本身仍是后续规格，不应由这句话推断为现有产品能力。

## 2. 当前已经具备的基础

### 角色智能体

- L1 私有感知入口；
- L2 主观理解与认知更新；
- L3 目标与意图规划；
- L4 结构化执行契约；
- Event、Observation、Knowledge、Social、Higher-Order 五池记忆；
- NeedTension、affect、dynamic state、goal state 和长期 drift；
- 技能目录、技能路径、行动请求和行动可用性评估。

### 世界和玩法权威

- 结构化 interaction intent；
- ESM/Gameplay authority；
- 资源、身体功能、状态标签、属性 modifier；
- 背包、容器、负重、装备、产权和固定交易；
- 原子事件批次、幂等、revision 冲突、失败结果、回放和 outbox；
- 后端状态向 Godot 的 snapshot/delta 镜像。

### 当前参考闭环

当前已验证的是一个**有界参考闭环**，不是“这些领域已经通用完成”。对应收口计划见
[Adventure-Basic Reference Closure Plan](../superpowers/plans/world-character-siming-authority-mainline/character-gameplay-foundation/2026-07-29-adventure-basic-reference-closure-plan.md)；
它由 [`.harness/verification/adventure-basic-report.json`](../../.harness/verification/adventure-basic-report.json)、
[`.harness/verification/live-adventure-basic-mirror-report.json`](../../.harness/verification/live-adventure-basic-mirror-report.json)
和聚合 [`.harness/verification/gameplay-foundation-all-report.json`](../../.harness/verification/gameplay-foundation-all-report.json)
共同证明，覆盖：

- 买剑并装备；
- 身体受伤或 stamina 不足时阻断已知剑术动作；
- 储物戒容器/负重约束；
- 地契物品与土地产权分离；
- 赠与、债务、简单合同的受限生命周期。

这些证据证明的是五个受治理 reference scenario 的 authority、replay、filtered mirror
和 real-Godot delivery；它们不等于完整经济域、完整 RPG 域或通用内容域已经闭合。

## 3. 可用于探索的游戏方向

以下是现有角色心智、权威结算与交互基础可支撑的原型方向，不表示其中的任务、
证据、信息传播或完整社交 authority 已经实现。

当前比较适合：

- 剧本杀和调查推理原型；
- 角色社交和关系驱动剧情原型；
- 对话、秘密、证据和信息传播的内容探索；
- 探索、检查、开门、拿取、携带、放置；
- 简单交易、赠与、契约、债务和产权剧情；
- 轻量装备、资源限制和能力门槛；
- 智能体驱动的 NPC 行为和角色间自主互动。

## 4. 当前不能直接宣称的能力

### 完整动作 RPG

目前存在挥剑、格挡的输入和动作表现，但还不是完整战斗系统。缺少命中、伤害、防御、硬直、击退、连击、目标锁定、敌人 AI、战斗遭遇和多人战斗同步。

### 完整经济模拟

当前是账户、固定报价、物权、赠与、债务和简单合同原语，不是动态市场、生产链、工资、税收、企业经营和政府监管系统。

### 任意剧本一键生成完整游戏

当前已有内容和规则扩展边界，但还缺少任务系统、剧情目标编译器、资产校验、场景拼装、UI 生成、测试回放和发布流水线。

### 世界模型生成完整游戏世界

当前 VLA/多模态路径主要是感知和 advisory 输入，权威事实仍由既有世界运行时实现、ESM、Gameplay 和物理/场景层负责。世界模型尚未成为完整世界真相或世界持久化引擎。

## 5. 一句话定位

当前项目不是“已经做完的通用游戏引擎”，而是：

> 已完成角色智能体和权威玩法运行时的关键骨架；当前以 RPG/剧本杀参考闭环为主，后续是否演进为可被创作者和 Codex 调用的通用内容运行时，仍需通过独立 spec、plan 和验证收口。
