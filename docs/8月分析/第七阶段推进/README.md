# 第七阶段推进：文明级世界、推演与世界模型研究

状态：`phase-seven workbench; long-term guidance; research/product lanes, non-authorizing`

第七阶段不是当前商业玩法的必要前置，而是八月分析中面向持久世界、文明演进、反事实
推演、世界模型和机器人沙盒的长期阶段。它必须建立在 P1-P6 的事实、权限、发布和回放
门禁之上，不能用“模型生成”跳过 authority。

```text
P4 institutional economy + P5 RPG/social + P6 governed packages
  -> P7A civilization capability and cross-jurisdiction projection
  -> P7B branch replay, calibration and counterfactual reports
  -> P7C world-model proposal/prediction channel
  -> P7D robotics/embodied safety pilot
```

## 1. 阶段定位

P7 扩展的是世界规模、推演消费模式和跨形态实验，不重建角色、Gameplay 或 Siming runtime。
文明能力、六轴传导、金融/制造解锁、政治军事和公共秩序由相应社会与制度 owner 定义；
世界基础设施只提供 mode profile、调度入口、revision、分支和回放支撑。

## 2. 明确后置

- 全球/跨辖区宏观经济、货币、金融系统和战争；
- 大规模人口优化、反事实分支和统计校准；
- world model 预测、生成内容和行动建议；
- 机器人仿真、sim-to-real、传感器延迟和现实动作安全。

所有这些都必须先有受限 vertical slice 和独立 Harness；不能因为研究模型可输出 JSON 就
允许其直接提交世界事实。
