# 第七阶段范围与文明世界边界

状态：`incremental design; P7A formal spec required before implementation`

## 1. 文明层只组合既有事实

文明能力可以读取人口、组织、经济、技术、政府、关系和环境的 versioned projections，
计算制度采用、产业能力、公共秩序或跨辖区影响，并生成 proposal/报告。它不得复制角色、
组织或经济事实，更不得直接改写这些 owner 的 stream。

```text
domain projections
-> CivilizationCapability / policy proposal
-> policy + dependency + impact evaluation
-> signed revision or explicit authority command
-> existing event store/replay/projection path
```

## 2. 规模化边界

先支持有限辖区、有限角色和固定窗口的 deterministic sample，再逐步提升 batch size、
激活层级和统计投影精度。性能优化只改变批量方式和报告精度，不能改变正式规则或身份连续性。

不在本阶段先实现完整城市、全球市场、战争全局、自然生态无限模拟或自动文明生成。

## 3. owner 约束

| 能力 | owner | 不得越权 |
| --- | --- | --- |
| CivilizationCapability | 社会/制度玩法 authority | 不直接写家庭、组织、账户 |
| Cross-jurisdiction policy | Government/Polity | 不绕过许可、税和公共义务 |
| Technology/manufacturing unlock | 玩法/生产 authority | 不凭模型文本创造设施/配方 |
| Public-order outcome | Government/Conflict/Social owner | 不删除犯罪、战争或关系历史 |
| World mode/scheduler | existing world runtime extension | 不成为经济/文明万能 coordinator |
