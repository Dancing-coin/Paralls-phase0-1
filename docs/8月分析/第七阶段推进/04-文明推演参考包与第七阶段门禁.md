# 文明推演参考包与第七阶段门禁

状态：`incremental design; P7D research Harness required before implementation`

## 1. 参考包

第一版只选择一个有限辖区、少量组织和一条技术/政策变化。例如：面包街税率调整、
供应链中断和新烤炉技术 proposal 对两个经营周期的影响。它必须使用 P4 的商业事实、
P3 的人口 continuity 和 P6 的签名 package，而不是单独生成一套文明状态。

## 2. 必须验证

- production checkpoint 与 branch tail replay 一致；
- 外部 dataset、seed、ruleset、model revision 和 mapping digest 可复现；
- 预测、proposal、已批准 revision 和正式事实在报告中明确分层；
- 模型建议、司命 catalyst、Godot 或机器人客户端不能直接写 authority；
- 跨辖区/文明能力结果能够追溯到 source projections 和 policy decisions；
- 机器人动作具备安全约束、人工接管、失败回退和 sim-to-real 标记。

## 3. 完成声明

通过后只能声称“有限文明推演/世界模型/机器人安全样板已通过隔离与回放门禁”。不能
声称完成全球文明模拟、通用世界模型、自动内容生成或现实机器人生产部署。
