# 世界模型与机器人安全边界

状态：`incremental design; P7C/P7D research spec required before implementation`

## 1. 世界模型通道

world model 可以做状态预测、候选行动、资产生成建议或风险估计，但只能输出带输入 digest、
模型 revision、置信度和 evidence refs 的 provider result/proposal：

```text
committed world snapshot
-> model prediction / action proposal
-> semantic/effect/affordance validation
-> existing authority SettlementPlan
-> append_batch (only after approval)
```

模型不能确认“预测已经发生”，不能直接修改角色状态、物理对象、经济余额或 Siming 的
世界事实。Godot 和机器人客户端同样只能消费 committed result。

## 2. 机器人沙盒

机器人/仿真形态复用实体、动作、事实、证据、回放和安全策略，但不强迫使用完整 RPG
经济/社会规则。高频运动保持本地 embodiment；后端只接收结构化动作、传感器摘要和结果证据。

安全验证至少包括：动作约束、权限/同意、空间边界、资源/能量限制、传感器延迟、失败
回退、人工接管和 sim-to-real 版本标记。

## 3. 研究边界

P7 允许研究 adapter、预测质量和结果复用，但不授权将未验证模型、任意生成代码或外部
现实数据写入生产 world truth。每个研究实验都必须有隔离 world/mode profile、固定 seed、
审计报告和清理/回滚路径。
