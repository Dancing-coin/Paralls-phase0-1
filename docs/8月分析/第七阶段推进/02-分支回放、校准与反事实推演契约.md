# 分支回放、校准与反事实推演契约

状态：`incremental design; P7B formal spec required before implementation`

## 1. 分支模型

推演必须从已提交 checkpoint、固定 tail、world revision、ruleset revision、seed 和输入
数据集创建分支。分支是可审计的推演消费模式，不是生产世界的隐式写入通道。

```text
production checkpoint
-> branch manifest + pinned revisions + fixed seed
-> proposed inputs/parameter mapping
-> deterministic batch settlement
-> branch report + projection digests
-> discard, compare or explicitly promote through approval
```

## 2. 外部数据校准

现实统计、历史资料和创作者数据只能作为版本化 `ReferenceDataset` 与 `CalibrationInput`，
保存来源、许可、schema revision、digest 和映射。它们不能直接覆盖角色、资产、经济或
规则事实。

校准结果必须区分：

- 世界内已提交事件；
- 外部参数假设；
- 模型/统计推断；
- 尚未验证的 proposal。

## 3. 反事实报告门禁

任何“如果提高税率/改变技术/关闭生存系统”的报告都必须说明起点、分支差异、规则版本、
seed、catch-up policy、结果 digest 和未建模因素。报告不能被自动当成生产事实，正式采用
需要 admin/政策 authority 的新 revision 或新命令。
