# 行为分层与信息传播

状态：`proposed; behavior kernel and propagation design; no generic agent action writer`

## 行为分层

群体模拟不应让每个角色都运行完整 LLM。行为按可观察价值和业务风险分层：

| 层 | 典型行为 | 计算方式 | 输出 |
| --- | --- | --- | --- |
| B0 基线 | 休息、通勤、重复工作、简单队列 | 确定性规则/采样 | presentation seed |
| B1 局部反应 | 邻域信息、短期需求、简单协作 | 小模型/有限状态 | seed 或 activation candidate |
| B2 关系协商 | 谈判、冲突、信任变化、复杂任务 | 近场 agent 或短时 agent | owner-bound intent candidate |
| B3 高价值事件 | 创新、重大危机、玩家关键介入 | 完整 agent + Siming context | 只允许已准入 capability |

升级必须有 `activation_reason`、预算、scope、source revision 和回退策略。模型不可用时，B2/B3 只能 no-op/requeue，不能退化为任意事实写入。

## 离散动作合同

每个动作使用 closed action schema：`action_kind + actor_ref + target_ref + source_vector + expected_revisions + policy_revision + privacy_scope + idempotency_key`。动作类型不是 caller-selected event family；owner 负责将其转为自己的 fragment。未知动作、跨域 target、私有 scope 或过期 source 均 zero-write。

## 信息传播

传播分三段：`source observation -> scoped propagation hypothesis -> recipient observation/memory candidate`。

传播假设必须记录 source、recipient cohort、窗口、信道、置信度、policy revision 和 privacy disposition。只有 recipient 实际可见且满足 scope 的内容才能进入角色 Observation/Knowledge/Social 五池；传播概率不能直接改写 belief 或世界事实。

错误信息、冲突信息和来源撤回都要保留 provenance。撤回会生成新的 redacted/retracted derivation，不删除角色已经形成的主观记忆；未来对话可通过新观察进行更正。

## 参考项目翻译

- OASIS 的 23 类离散 action、推荐系统和信息扩散可用于建立 action taxonomy、传播测试集和预算模型；社交平台点赞/转发不直接映射为经济、关系或空间事实。
- Generative Agents 的 schedule、retrieval、reflection 可用于 B1/B2 的上下文构造；不能作为远场常驻 LLM 循环。
- Concordia 的 entity/component 与 intent/outcome 分离可用于组合行为上下文；最终 adjudication 仍由领域 owner 完成。
- Sotopia 的 scenario sampler/evaluation 可用于关系协商质量测试，不作为生产社会事实存储。

## Formalization 前置

先选一个非敏感、只读传播 vertical，定义 closed action schema、recipient scope、传播窗口和五池写入边界；完成前，不实现全局舆情、文明意识或跨区域社会真相。
