# 群体世界本体与状态模型

状态：`proposed; domain-model design; no production owner admission`

对应母规格：[Character Simulation Memory Seed And Continuity Design](../../superpowers/specs/world-character-siming-authority-mainline/2026-08-22-character-simulation-memory-seed-continuity-design.md)，映射范围：canonical ref、source owner、validity 和 no-shadow-truth。

## 为什么补充

现有 SGC 文档已经规定“群体模拟不能成为第二真相”，但还没有定义模拟对象本身。没有稳定本体，cohort、家庭、组织、关系和区域会退化成不可回放的 JSON，最终又会出现一个隐藏的 population truth owner。

## 分层本体

群体模拟只读取和组合以下五类已有或待正式化的引用，不复制领域事实：

| 层 | 最小对象 | 事实归属 | 群体模拟可做的事 |
| --- | --- | --- | --- |
| 身份层 | `CharacterRecordRef`、profile、activation state | Character/Gameplay authority | 选择 cohort、生成行为种子、提出激活提示 |
| 关系层 | household、organization membership、social edge ref | Character/Social/Organization owner | 读取已授权关系摘要，计算传播邻域 |
| 空间层 | world、region、zone、place、route ref | World/Environment owner | 计算局部性、距离、可见范围和批次边界 |
| 资源层 | inventory/production/quote/survival projection ref | 各领域 owner | 计算压力和候选，不写库存、生产或生存事实 |
| 叙事层 | `StorylineThread`、`NarrativeFollowUp`、`ActivationHint` | Siming/Graph derived layer | 排序观察和激活优先级 |

## Canonical 引用规则

每个模拟实体只保存 `entity_ref + source_owner + source_revision + scope + validity`，不保存一个可独立演化的 shadow state。派生聚合（例如“区域缺粮压力”）必须包含 constituent refs、aggregation policy revision、窗口和 digest；它是可重建报告，不是区域事实。

cohort 是一次计算选择，不是永久实体。其 identity 为 `cohort_ref = hash(scope, selector_revision, source_vector, seed, window)`。相同输入必须得到相同成员顺序；成员变化必须由 source revision 或 selector revision 解释。

## 状态生命周期

所有可能改变生产事实的对象使用同一候选生命周期：`observed -> aggregated -> candidate -> admitted/rejected -> owner_receipt -> projected`。

`aggregated` 和 `candidate` 允许丢弃和重算；`admitted` 之后必须等待 owner receipt；`projected` 才能进入下一轮 graph/presentation 输入。没有 receipt 的候选不能成为下一轮事实。

## 参考项目翻译

- AgentSociety 的 workspace-bound stateless agent 启发“身份引用 + workspace/上下文”，但 Paralls 不能让 workspace 取代 CharacterRecord 或 owner 事实。
- OASIS 的用户 profile/action 数据启发 cohort 输入和离散动作 schema，但社交平台对象不能直接成为 3D 世界对象。
- Generative Agents 的 memory stream 启发角色私有记忆，而不是群体本体；记忆仍必须回到五池和 scope 规则。

## Formalization 前置

先从一个已有 Organization/Character/World projection 做 schema fixture，验证 source/ref/revision/scope/validity 和聚合 digest；未完成前，人口、迁移、出生死亡、阶层和文明演进均保持 `unimplemented`，不得用模拟聚合代替 owner。
