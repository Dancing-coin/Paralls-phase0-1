# 线程结论与决策清单

状态：`incremental decision guidance and backlog; non-authorizing analysis aligned to active plans`

本文件区分两类内容：已达成的架构判断，以及需要进入正式 spec/plan 后才可选择的候选
backlog。它不提供当前执行顺序或实现授权；二者仍以 mainline spec/plan tree 为准。文中
的未来 owner、revision 汇总模型和统一 control-plane 均为 `planned`，当前入口仍是既有
`world_runtime` / ESM / Gameplay authority、Patch/runtime 生命周期与受限 `/ws` 读路径。

## 1. 已达成的架构判断

1. 项目当前首先应服务 RPG，近期最适合剧本杀、调查、社交和轻量冒险。
2. 当前最成熟的是角色心智、权威结算、事件回放和具身交互基础，不是内容领域的完整度。
3. 角色智能体已经具备进入 3D 场景行动的基础，但不能把它等同于完成了完整具身智能或动作游戏。
4. VLA 应保持 advisory 和感知/动作建议角色，不能绕过 authority。
5. 世界模型可以接入，但应作为预测、生成和压缩器；物理引擎和世界 authority 仍负责真实结算。
6. AI 游戏和机器人沙盒可以共享 harness 原则，但需要不同的公平性、安全性、时间和物理约束。
7. 2D、3D、VRM、Live2D、VR 和机器人需要多个形态底座，但角色心智核心不应复制多套。
8. 当前产权与经济只是基础原语，未来必须和技能、背包、建造、生存、商业组织、政府组织协作。
9. Codex 可控底座的核心价值是结构化接口、验证、回放和恢复，而不是让模型直接编辑引擎内部文件。
10. 资产商店、生成站、故事结果市场和 IP 共创平台可以形成生态，但当前还没有完成链上确权、贡献归因和收益分账。
11. 单局算力应通过规则、小模型、五池记忆、上下文检索、结果缓存和高光复用降低；不能简单把所有历史喂给大模型。
12. 角色档案、人格投影、记忆写回、目标仲裁和状态 authority 是最值得闭源保护的核心。

- dossier authoring 和完整热加载控制面；
- 任务/证据/剧情目标编译；
- 可交互资产生成与导入流水线；
- 经济跨域循环；
- 结果缓存、算力计费和复用市场；

- 完整战斗；

- 动态市场与政府监管；

- 链上创作权、收益权和分账。

## 3. 候选增量 backlog（尚未成为路线图）

以下顺序只表达对话5—13的依赖判断。任何一项开始前都必须在正式 spec/plan 中明确
owner、兼容性、迁移与 Harness；不同产品目标可以选择不同切片，不能把 P0-P3 当作已经
批准的统一开发排期。

### P0：事实与结算样板（候选）

- 在扩展完整经济、战斗和建造前，先补万物档案、语义标签、效应/抵抗、元规则，以及仅供新增语义/跨域 adapter 使用的 `ActionIntent -> SettlementPlan -> append_batch` 因果结算；
- 先用“霜冻农田”或“火焰橡木门”跑通跨域垂直样板，证明实体、因果、投影与回放一致；
- 定义 `planned` 的 Creator CLI/MCP 命令面；当前入口先复用后端认证 session/scope、Patch/runtime 生命周期和受限 `/ws` 查询/镜像路径；
- 定义世界包、角色包、剧本包、玩法包和资产包格式；
- 定义验证、回放、打包和发布流程；
- 把 dossier、规则和资产接入变成可审计版本；
- 将闭源 core 与创作者内容包分离；
- 以 `reader/editor/admin`、项目 scope 与数据分级统一约束 UI、CLI 和 MCP；其中统一 control-plane 和 `ActiveWorldRevision` 仍是 `planned` 收口目标，不是当前现成模块；

### P1：剧本杀产品闭环（候选）

- 任务/目标/证据系统；
- 关系和信息可见性工具；
- 司命节奏、公平性和故事结果复用；
- 2D/2.5D/3D 的最小呈现适配；
- 作者预览、调试、回放和发布。

### P2：RPG 玩法域（候选）

- 战斗；
- 成长与技能晋升；
- 制作、建造、生存；
- 商业组织与政府监管；
- 动态经济和持久世界。
- 经济玩法按 Econ-1 单辖区闭环推进：单币种、生产/工资、基础需求、组织经营、许可证、销售税和周期报价先于订单簿与跨区贸易；
- 玩法系统按领域拆分为独立文档，经济只作为其中一个跨域结算子系统，不能代表全部玩法建设；

### P3：世界模型和沉浸式/机器人方向（候选）

- world model proposal/validation；
- 可交互生成资产；
- 低延迟 VR/手势/手套；
- 机器人世界预演和安全 authority。

## 4. 尚未冻结的长期产品假设

最值得坚持的产品定义是：

> 一个由闭源角色心智与世界权威驱动、通过 CLI/MCP 被 Codex 和创作者控制、能够加载不同内容包和呈现适配器、并能对运行结果进行回放、复用、计费和分润的智能体游戏运行时平台。
