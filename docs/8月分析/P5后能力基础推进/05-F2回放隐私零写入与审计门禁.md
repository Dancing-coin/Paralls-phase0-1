# F2 回放隐私零写入与审计门禁

状态：`implemented-and-verified; taxonomy gate only`

## 大白话

以后每个 P6/P7 功能都不能只说“接口写出来了”。必须能重放、能证明权限、能证明拒绝没有偷偷写入、能回滚、能查审计。研究提案、预览结果、分支推演和正式世界事实也要分开。

## 必须定义

- focused tests 和 Harness profile/rule IDs；
- full/checkpoint-tail replay、deterministic hash、revision/schema 输入；
- privacy filtering、permission denial、zero-write、stale/duplicate 幂等；
- migration/rollback、audit completeness 和 evidence freshness；
- P7 的 read-only、branch reproducibility、proposal/result separation。

## 停机条件

缺 profile、回放不一致、隐私泄露、过期证据或拒绝请求产生 committed event 时，对应 track 必须保持 `planned/blocked`，不能用总 Harness 绿灯掩盖局部失败。
