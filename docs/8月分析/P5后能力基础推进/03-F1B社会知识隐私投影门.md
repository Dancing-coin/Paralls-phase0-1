# F1B 社会知识隐私投影门

状态：`partial-foundation verified; generic contract remains planned`

## 大白话

关系、声望、家庭、知识、信念、感知和隐私不是“再做一个社会系统”。它们要说明事实从哪里来、谁能看到、角色记住什么、哪些内容只能作为私有证据。

## 必须定义

- source event、actor/subject scope、visibility policy、provenance、revision；
- public projection、actor memory、private evidence 的区别；
- 传播、过期、遗忘、撤销和脱敏行为；
- 同范围通过、跨范围拒绝和失败零写入。

## 验收

focused tests 要覆盖 privacy redaction、cross-scope denial、来源保留、stale/duplicate、full/checkpoint-tail replay 和拒绝零写入。Character Core 与既有 profile 是角色真相来源，不能合成 NPC 或让客户端维护关系真相。
