## 目录级 README 与导航文件

`README.md`、`分析与设计指导/README.md`，以及上述领域目录下的 `README.md` 均为导航文件；它们继承对应行的状态，不另行构成实现证据。`00-增量设计工作台与覆盖矩阵.md` 是全表的导航和约束入口。阶段推进目录及其文件不在本台账范围内，因为它们属于另一套“执行顺序和门禁”体系。

## 新鲜度与复核

表中“已有证据”只有在当前 commit，或记录为兼容的命名 commit 上运行且仍满足对应 contract revision 时才能用作后继开工证据。owner、写入路径、schema/revision、投影/隐私规则、Harness 断言、迁移或回滚任一变化，均使相关行回到 `planned`，必须重新运行 profile。未来日期或仅阶段化的文档只能作为设计输入，绝不是可执行证明。
