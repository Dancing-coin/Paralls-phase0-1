# 算力成本、记忆复用与运行经济

状态：`discussion guidance; billing, cache marketplace, and production cost controls are not implemented runtime features`

## 1. 算力消耗的主要来源

对于 30-60 分钟的剧本杀单局，成本通常不是每一帧画面，而是以下几类推理和状态处理：

- 司命对全局状态、节奏、公平性和剧情分支的判断；
- 角色 L2 主观理解、L3 规划和多轮对话；
- 视觉/VLA 慢路径和不确定感知；
- 记忆检索、总结、冲突消解和知识更新；
- 任务、关系、经济和世界状态的跨域结算；
- 语音、动作和高光表现生成。

角色深度推理本身不一定是最大成本。只要把高频动作交给规则/小模型，把大模型集中在真正改变信念、目标、关系和剧情的节点上，单局成本可以控制在合理范围。

## 2. 五池记忆如何降低成本

正确方向不是把全部历史都塞进上下文，而是：

```text
事件发生
-> 结构化提取
-> 五池记忆写入
-> 摘要、实体、关系和来源索引
-> 当前情境检索少量相关记忆
-> 模型只接收与当前决策相关的上下文
```

可采用：

- working memory：当前几轮对话、目标和注意对象；
- event memory：发生过什么；
- observation memory：角色看见/听见了什么；
- knowledge memory：角色相信什么以及置信度；
- social memory：对其他角色的关系认知；
- higher-order memory：谁知道什么、谁怀疑什么；
- long-term summary：跨场景稳定事实和角色弧线。

知识图谱可以用于索引和关系查询，但不能成为第二个心智真相源。记忆仍需要来源、时间、置信度、隐私和失效规则。

## 3. 可复用的结果

适合复用的不是某个玩家的完整私密思考，而是经过版本化和隐私处理的结构化结果：

- 世界设定和规则解释；
- 已验证的场景方案；
- 任务/剧情分支模板；
- 角色行动方案和高光时刻模板；
- 事件结算结果；
- 资产生成结果和绑定结果；
- 可复用的 NPC 行为策略；
- 已验证的失败处理和恢复路径。

不应直接跨玩家复用：

- 私密记忆原文；
- 玩家未授权的角色秘密；
- 依赖唯一玩家历史的主观信念；
- 未经验证的世界状态；
- 带有个人隐私的对话和行为轨迹。

## 4. 复用必须有版本和键

结果缓存至少应绑定：

```text
IP/世界版本
角色档案版本
玩法 Patch 版本
规则/模型版本
当前事件和证据摘要
可见性与玩家差异参数
```

命中缓存只能提供候选方案，最终仍需经过当前世界 authority、玩家状态和公平性校验。尤其是涉及产权、经济、任务奖励和秘密的信息，不能因为缓存命中就直接确认。

## 5. 玩家为什么愿意承担算力成本

玩家愿意付费的不是“模型 token”，而是：

- 更深的角色记忆和关系延续；
- 更独特的剧情分支；
- 更高质量的语音、动作和高光时刻；
- 更复杂的世界反应；
- 可继承、可分享、可复玩的故事结果；
- 对自己贡献内容的收益或署名权益。

产品上可以把成本包装为：

- 基础体验由缓存、规则和小模型承担；
- 高价值的个性化推理、生成和高光表现使用算力额度；
- 玩家购买的是角色深度、故事服务和世界持续性，而不是一次性 token。

## 6. 当前实现与缺口

当前已经有五池记忆、动态状态、目标状态、事件回放和部分调度/降级基础；但还没有完整的：

- 统一算力计费账本；
- 跨玩家结果缓存市场；
- 记忆/结果隐私授权协议；
- 复用质量评分和公平性审核；
- 模型调用预算、租约、抢占和结算平台。
