状态：`phase roadmap and execution guidance; does not authorize implementation alone`

这套体系只回答四件事：阶段做什么、依赖什么、什么时候能进入下一步、如何验收。

## 阶段总路线

```text
P1 通用 Gameplay contract + 单经营者样板
  -> P2 已有角色的组织协作
  -> P3 Population continuity + 持续世界
  -> P4 动态经济与制度
  -> P5 RPG 任务/社会/调查/冲突
  -> P5 后续能力基础 F0-F2
  -> P6 Creator Control Plane + 玩法包发布
  -> P7 文明/推演/世界模型/机器人研究
```

## P5 后续与 P6/P7 的配合规则

- `F0` 先统一 P1-P5 的真实实现证据和剩余缺口；
- `F1A/F1B/F1C` 在 F0 后可以并行设计，但必须各自绑定已有 owner 和事件路径；
- `F2` 统一回放、隐私、拒绝零写入、审计、迁移和回滚证据；
- P6A/P6B 可在共享语义与社会投影前置完成后准备；P6C/P6D 等待包治理和验证门禁；
- P7 可以并行准备只读研究材料，但正式实施仍等待现有 P6D 硬前置和 P7 自身安全门禁；
- 固定顺序是 `P5 -> P5 后续能力基础 -> P6 -> P7`；决策门只处理阶段内部的并行边界和开工证据，不重新编号。
