# 垂直样板与验收矩阵

状态：`planned validation sequence; existing adventure-basic evidence is a narrower reference closure`

垂直样板用于证明新增玩法确实复用了同一事实、规则和事件脊柱。样板顺序是候选
backlog，不替代正式 plan，也不因本文件存在而获得实现授权。

| 样板 | 要证明的组合 | 不能据此宣称 |
| --- | --- | --- |
| V0：霜冻农田或火焰橡木门 | 实体/组件、材料与状态、effect/resistance、规则、跨域因果、过滤投影与 replay | 通用元素化学、完整生态或完整战斗 |
| V1：Econ-1 面包店 | 技能劳动、库存 lot、设施、食物需求、报价、工资、税费、组织日结和周期调度 | 动态订单簿、跨区贸易、金融市场或完整公司制 |
| V2：有证据的冲突与调查 | 部位/材料/effect、伤势、关系/声望、线索可见性、赔偿/悬赏与任务阶段 | 完整实时战斗或通用潜行 AI |
| V3：受治理创新 | 需求压力、试验、proposal、审核、文明能力门控与传播 | 司命/模型直接发布规则或任意动态 schema |

每个样板至少验证：语义定义和 revision 固定；成功、拒绝、权限不足、revision 冲突和
重复命令零部分提交；因果/evidence/rule refs 可追溯；full replay 与 checkpoint + tail
一致；游戏/模拟/推演 profile 仅改变粒度而不改变结算语义；Godot/UI 只消费 committed
result；reader/editor/admin 的可见性和命令边界正确。

现有 `adventure-basic` 证明的是五个受限场景的参考闭环，证据见
[adventure-basic report](../../../.harness/verification/adventure-basic-report.md) 与
[live mirror report](../../../.harness/verification/live-adventure-basic-mirror-report.md)。
它不能代替 V0-V3，也不能提升经济、建造、生存或社会模拟为已完成。
