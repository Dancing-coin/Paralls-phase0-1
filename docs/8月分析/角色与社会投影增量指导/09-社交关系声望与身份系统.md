# 关系、声望与身份投影指导

状态：`planned social projection extension; current actor-local perception and relationship seed paths are reusable only`

## 1. 目标

该系统把对话、承诺、信任、派系态度、身份凭证和声望变成可回放的玩法事实，
并与角色心智的隐私投影相连。它不把语言模型输出直接当作关系变化。

## 2. 数据模型

```text
SocialEdge(source_ref, target_ref, relation_kind, strength, confidence)
Reputation(subject_ref, faction_ref, score, tier, source_events)
IdentityCredential(holder_ref, issuer_ref, role_ref, scope, valid_until)
SocialCommitment(commitment_id, parties, terms_ref, evidence_kind, status)
ContactMemory(contact_id, visibility, summary_ref, source_event_ids)
```

关系变化必须说明来源事件、参与者和政策 revision。身份凭证可影响门禁、价格、
岗位和任务可见性，但不能越权写入产权或政府许可。

## 3. 与其他系统的边界

对话和角色心智产生 structured social intent；本文件只负责关系、身份、声望和社会
承诺的事实投影。知识 claim、belief、disclosure、rumor 和传播规则归
[知识、信念与信息传播系统](20-知识信念与信息传播系统.md)，不在本文件重复定义。
任务读取承诺和证据；组织读取
成员/声望/授权；经济处理礼物、服务、赔偿和信用；政府读取身份、许可和违法
记录；战斗读取敌对/保护关系。隐私 projection 决定不同角色看到哪一部分。

## 4. 当前与新增

- `implemented`：角色心智、关系种子、隐私投影、事件与目标运行态；
- `reusable`：typed contract、evidence、authority event bus、审计和 replay；
- `planned`：关系图、声望聚合、身份 credential lifecycle、社会承诺、派系政策、
  谈判结果和可见性规则。

创作者可定义关系类型、派系、声望阈值、身份模板和剧情后果；原始记忆、隐藏
关系 workspace、跨项目角色秘密和写回算法保持闭源。
