# 知识、信念与信息传播投影指导

状态：`planned knowledge projection extension; current memory and perception paths are reusable foundations`

## 1. 真相、感知、知识与信念必须分开

世界事实不等于角色看到的事实，角色看到的事实也不等于其相信、记住或传播的
内容。没有这层区分，潜行、调查、谣言、内幕信息、误会、宗教、市场判断和
角色智能体记忆都会错误地共享全知视图。

```text
WorldFact -> PerceptionResult -> KnowledgeClaim -> BeliefState
          -> testimony/rumor -> recipient perception -> revised belief
```

## 2. 核心模型

```text
KnowledgeClaim
  claim_id, subject_ref, proposition_ref, source_event_refs
  confidence, acquired_at, visibility, verification_status

BeliefState
  subject_ref, proposition_ref, credence, stance, explanation_refs, revision

InformationSource
  source_ref, channel, reliability_policy, anonymity, audience_scope

Disclosure
  disclosure_id, sender_ref, recipient_refs, claim_refs, consent_policy

RumorTrace
  root_claim_ref, transmission_refs, distortion_policy, decay_policy
```

`WorldFact` 由实体/领域 authority 拥有；`KnowledgeClaim` 是角色或组织已获得的
证据性信息；`BeliefState` 允许不完整或错误，但不得反向改写事实。命题必须有
类型化 schema 和引用范围，不能以自由文本作为可结算社会事实。

## 3. 传播、验证与玩法协作

感知系统产生带置信度和可见性的观察结果；社交系统处理证词、保密、说服和
传播；任务系统以经验证的 claim/evidence 推进阶段；经济和金融只允许使用政策
授权的信息视图；政府检查、审判和调查将证据转为行政/法律事实。角色心智从
过滤后的 knowledge/belief projection 读取，不直接扫描 event store。

关系、身份、声望和社会承诺的 canonical projection 归
[关系、声望与身份投影指导](09-社交关系声望与身份系统.md)；本文件只负责 claim、
belief、disclosure、rumor 和传播/验证规则。信息传播规则需要 source reliability、渠道噪声、社交距离、保密义务、反证和
时间衰减。谣言可以改变声望或行为，却不能在没有 authority 证据时自动定罪、
转移产权或扣款。

## 4. 隐私与反作弊

claim 的 visibility 与 audience 由 source policy 固定；查询未知资源应返回
不存在与无权访问不可区分的拒绝。调试 view 只能显示脱敏 trace。预览世界可
暴露完整测试资料，正式世界不得用创作者调试接口泄漏玩家秘密、内心、调查线索
或订单信息。
