# 角色与社会投影增量指导

状态：`guidance-only; extends Character Core, actor-local perception and existing social paths; no new runtime is authorized`

本目录不是新的“角色社会运行时”，也不授权创建第二套角色真相、social loop、
knowledge store、household authority 或独立时钟。它只记录如何在现有角色档案、
Character Core、L1-L4、五池记忆、需求/情绪/目标、actor-local perception、privacy
projection、relationship seed、事件 evidence/replay 和既有角色服务上逐步补齐社会
投影与玩法协作。

内容按三类阅读：

- `implemented`：角色心智、感知、事件和投影路径已有代码或 Harness 证据；
- `reusable`：已有协议/投影可作为新玩法输入，但不代表目标社会能力完成；
- `planned`：关系图、知识信念、家庭人口等必须进入正式 spec/plan 后实现。

本目录的“社会”是角色对关系、身份、知识和家庭的受限投影边界，不是一个绕过
Gameplay authority 或 Event Store 的总社会模拟器。
