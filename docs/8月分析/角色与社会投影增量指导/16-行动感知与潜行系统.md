# 行动、感知与潜行系统

状态：`planned action/perception extension; current structured interaction and perception paths are reusable foundations`

## 1. 定位

行动的语义意图、具身执行和 authority 结算边界由
[行动基元与具身交互](../玩法系统/02-行动基元与具身交互.md) 统一说明。本文件只拥有
行动结果进入角色私有认知后的部分：感知决定谁能把事件作为知识或证据，潜行则是
行动、感知、伪装、痕迹和社会后果的组合。潜行的冲突、任务和技能规则是依赖这些
投影的玩法扩展，而不是“在战斗系统里加隐身”或“在任务系统里减一个可见度数字”。

## 2. 核心模型

```text
PerceptionQuery
  observer_ref, source_ref, channel, distance, occlusion, attention

PerceptionResult
  observed_fact_refs, confidence, ambiguity, visibility_policy

StealthProfile
  concealment, noise, disguise_refs, trace_generation, exposure_risk

TraceRecord
  trace_id, source_ref, location_ref, trace_kind, decay_policy, visibility
```

物理适配器或环境逻辑先报告位置、遮挡、声响、接触等 `PhysicalFact`；感知
authority 再按感官、注意力、光照、噪声、伪装和状态形成角色可见的事实视图。
观察到的东西不等于真实全量世界，也不自动成为所有角色共享知识。

## 3. 潜行与调查闭环

```text
潜行动作 -> 物理/逻辑事实 -> 感知对抗与痕迹生成
-> 观察者知识/怀疑更新 -> 调查或任务证据
-> 关系、声望、监管或冲突后果
```

伪装、隐身、魅惑等超自然能力也只能改变已注册的 effect、状态、感知通道或
抵抗，不可直接编辑其他角色的记忆、任务状态或事件历史。调查方必须取得可见
线索、证词或物证，不能以模型叙述替代 evidence。

## 4. 当前与新增

- `implemented`：结构化 input、具身 affordance、grab/carry/place、角色感知链、
  private projection、Godot authority mirror；
- `reusable`：由行动层提供的 structured intent/PhysicalFact、事件 evidence、status、技能 gate 与 replay；
- `planned`：Social/Quest authority、通用 perception query/result、attention/occlusion 模型、
  trace lifecycle、stealth/disguise rules、怀疑/调查投影和角色知识写回协议。`ActionPrimitive`
  registry 不由本域重复定义。

创作者可定义动作、感知通道、痕迹、伪装和任务线索；感知过滤、知识隐私、
身体/空间事实和正式事件写入保持闭源。
