# 缺漏审计与补强路线

状态：`incremental architecture audit; derived from 对话5-13主题重组 and current runtime baseline`

## 1. 审计结论

此前目录已覆盖经济、技能、库存、建造、生存、任务、战斗、社交、组织、政府、
时间和环境，但存在两类容易被忽略的缺口：

1. **共享底座不够形式化**：标签/元规则若没有查询、数值、生命周期、冲突、
   追溯、迁移和权限 contract，领域文件仍会各自实现特殊逻辑；
2. **社会世界不够完整**：家庭人口、知识/信念、金融、政治军事分别决定角色
   的多重身份、信息不对称、长期风险和公共秩序，不能简单吸收到“关系”或
   “政府监管”中。

本目录现已分别由 `00`、`19`、`20`、`21`、`22` 覆盖。它们的存在不表示都应
立刻实现，而是冻结扩展边界，避免未来再另建事实系统。

审计的起点不是从零设计玩法底座。当前已存在的 `backend/app/gameplay/` 已经提供
领域 authority、`GameplayEventStore.append_batch`、replay、outbox、资源/状态、背包/装备、
产权/固定交易、债务/合同、Patch 与受限 Godot mirror；其有界 `adventure-basic` 组合已
有 Harness 证据。详见 [运行时覆盖矩阵](../../架构/运行时/运行时覆盖矩阵.md) 和
[Gameplay Foundation 与领域结算](../../架构/运行时/模块/GameplayFoundation与领域结算.md)。
本审计只追踪该基线尚未闭合的共享语义、长期调度、社会制度和规模化世界能力。

## 2. 与主题重组的覆盖矩阵

| 来源主题 | 对应玩法设计 | 仍需避免的误区 |
| --- | --- | --- |
| 万物档案与因果事件 | 13、00 | 不把物品/农田/事件复制进角色或经济表 |
| 标签、材料、物质、性质、状态 | 00、13、05、08、18 | 不用自由字符串或默认元素级模拟 |
| 效应、抵抗与元规则 | 00、13、06、08、17 | 不让内容包携带任意代码或直接写状态 |
| 统一结算链 | 01、12、13、15 | 不让经济/战斗/任务形成私有结算链 |
| 群体模拟与激活 | 12、14、19、20 | 不为激活角色创建脱离世界的 NPC 副本 |
| 创新与文明演进 | 14、15、17、21、22 | 不让司命/模型自然语言直接激活正式规则 |
| 商业社会与多重身份 | 02、10、11、19、20、21、22 | 不把同一角色拆为消费者/工人/投资者影子 |
| 动作、战斗与潜行 | 08、16、17 | 不让客户端表现或模型输出确认事实 |
| 生态与灾害 | 18、06、02、05 | 不让环境效果跨域无限递归 |

## 3. 实现顺序

### P0：补齐世界共享语义，复用现有结算脊柱

1. 完成 `00` 的最小 registry、selector、Rule IR、effect/state lifecycle、
   fixed-precision evaluation、trace 与 migration contract；
2. 完成 `13` 的 Entity/Thing/Environment/CausalEvent record 与语义快照；
3. 实现 V0 “霜冻农田”或“火焰橡木门”，覆盖成功、拒绝、冲突、重复、回放和
   projection；
4. 在 V0 通过前，不把现有固定交易/简单债务原语扩写成动态经济、完整战斗、炼金或文明树。

### P1：让角色和社会连续运行

1. SimulationClock、mode profile、activation lock、pending-change merge；
2. 生存、家庭、知识/信念、关系、日程和基础环境的日级/长周期结算；
3. 为角色智能体提供最小场景快照，而不是 event-store 全量读取；
4. 固化 preview、simulation、production 的隔离和可解释 replay。

### P2：在已验证玩法原语上完成第一组可玩垂直循环

1. Econ-1：在既有账户、库存、产权、债务与合同原语上增加生产、技能、需求、组织、许可证、税费和周期性报价；
2. V2：行动/潜行/调查或冲突，连接部位材料、effect、知识、关系和任务证据；
3. 每个玩法包都使用 `15` 的 manifest、验收面和发布流程。

### P3：制度与大规模世界

1. 创新 proposal、CivilizationCapability 和有限的六轴因果边；
2. 金融信用、政治军事、跨辖区贸易和公共秩序；
3. 反事实分支、统计投影和高规模群体模拟优化。

## 4. 非目标与风险控制

- 不先实现默认元素/分子化学、股票市场、完整选举、战争全局模拟或万能规则 AI；
- 不将动态字段变成无 schema 的 JSON，也不允许规则包携带任意运行时代码；
- 不把现实平台支付、创作者收益或链上分账混入游戏世界经济账本；
- 不让司命、角色智能体、Godot 或创作者工具成为 authority writer；
- 不把 ESM 或 System L6 扩写成经济、组织、政府或通用 Gameplay 的万能 owner；新增领域必须复用现有 event store/outbox/replay 脊柱；
- 不因“快速路径”牺牲 rule trace、revision pinning 和 replay 等价性。
