# 任务、目标、证据与剧情系统

状态：`bounded quest/evidence slice implemented; generic story packages and reward tooling remain planned`

## 1. 目标

任务系统把角色行动和世界变化组织成可验证的目标链，适合 RPG、调查和剧本
杀。它不直接修改经济或角色秘密，只消费授权投影并提交目标进度提案。

## 2. 数据模型

```text
QuestDefinition(quest_ref, stages, prerequisites, failure_policy)
Objective(objective_ref, type, target_refs, evidence_kind, visibility)
QuestInstance(instance_id, actor_ref, quest_ref, current_stage, status)
Evidence(evidence_id, kind, source_event_refs, holder_ref, confidence, visibility)
StoryBeat(beat_ref, trigger, allowed_catalysts, consequence_policy)
```

证据可以来自交易、战斗、生产、对话、观察、产权或监管，但必须引用已提交
事件；模型声称完成任务不是证据。阶段推进由 Quest Authority 依据证据和
revision 原子结算，并输出过滤后的角色/玩家视图。

## 3. 与其他系统

任务可要求取得物品、完成技能工作、建造设施、满足生存条件、达成交易、赢得
战斗或改变关系。奖励通过经济、技能、物品或状态 capability 发放，不能在任务
脚本里直接改余额和等级。

## 4. 当前与新增

- `implemented`：事件、角色目标/需求运行态、隐私投影、结构化行动和 replay 基础；
- `reusable`：typed contract evidence、Patch/Rule IR、Siming catalyst；
- `implemented bounded`：P5 quest/objective schema、evidence provenance、阶段迁移、线索
  可见性、失败零写入和 replay；
- `planned`：通用奖励 proposal、失败/重试扩展和剧情包发布工具。
