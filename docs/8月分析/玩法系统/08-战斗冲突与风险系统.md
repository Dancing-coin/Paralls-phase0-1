# 战斗、冲突与风险系统

状态：`planned conflict extension; current action/resource/body/equipment gates are reusable foundations`

## 1. 领域边界

冲突系统处理竞争性行动、伤害、控制、逃跑、投降和风险结算。表现层可以播放
动作，VLA 只能提供 advisory；命中、伤害和胜负必须由 Conflict Authority 依据
世界事实、技能、装备、身体和规则 revision 决定。

## 2. 核心模型

```text
ConflictDefinition(mode, rounds, allowed_actions, victory_policy)
Encounter(encounter_id, participants, location_ref, status, revision)
ActionAttempt(actor_ref, action_ref, target_ref, resource_hold, evidence)
Resolution(hit, damage, status_effects, displacement, loot_policy, explanation)
ActionRiskExposure(actor_ref, risk_ref, probability_band, mitigation_refs)
```

所有资源预留、耐久变化、状态施加、物品掉落、产权变化和经济奖励在可验证的
结算批次中提交。失败也必须有结构化原因，不能由客户端先显示“命中”再回滚。

战斗的关键压力测试是将动作基元、物理事实、部位、材料、护甲、效应、抵抗和
状态链连到同一条因果协议。剑命中木门、护甲、血肉或骨骼时，差异由目标组件
的物质/性质、命中部位和抵抗计算产生；冲突域只定义战斗节奏、胜负、士气、
撤退和战术，不拥有另一套伤害世界观。

## 3. 与其他系统

技能提供资格和命中质量；装备提供 modifier 与耐久；生存提供身体资源；背包
承载武器和战利品；任务读取战斗证据；关系系统读取敌对/保护后果；经济处理
治疗、装备、悬赏、赔偿和掉落价值。

## 4. 当前与新增

- `implemented`：action gate、资源/身体约束、status/effective stats、装备激活、
  event spine 和 embodied result；
- `reusable`：atomic settlement、idempotency、replay、presentation-only mirror；
- `planned`：encounter 状态机、命中/伤害解析、回合/实时调度、控制效果、死亡/逃跑、
  loot/赔偿、AI 对手策略和公平性规则。

创作者可编辑武器、技能招式、伤害曲线、冲突模式和失败叙事，但不能开放任意
伤害写入器或跳过身体/资源检查。
