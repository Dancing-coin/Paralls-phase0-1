# 分层玩法系统

状态：`incremental gameplay guidance; gameplay hierarchy is separate from canonical-owner classification`

当前实现映射：见 [../12-实现收口与证据映射.md](../12-实现收口与证据映射.md#玩法系统)。P1-P5 已形成多个可回放的限定玩法切片，不代表所有 L1-L5 玩法域都已产品化。

本目录按**玩家决策的作用尺度与反馈周期**组织，而不是按哪个 authority 拥有事实来
排除系统。经济、组织、政府、金融、公共秩序和文明都是高层玩法：玩家可以劳动、创业、
雇佣、经营、交易、投资、申请许可、申诉或参与制度演进；NPC 也可以在玩家不在场时由
调度器提交同类 intent。

“是玩法”不意味着“拥有 world truth”。每层的账户、库存、技能、设施、关系、政策或
事件仍由对应 authority 结算。完整 owner 边界见
[全域架构](../全域架构/00-系统边界与责任矩阵.md)。

## 玩法层级

| 层级 | 玩家面对的问题 | 系统 | 典型反馈周期 |
| --- | --- | --- | --- |
| L1 即时具身 | 我现在如何观察、移动、使用、躲避或对抗？ | 行动、感知、交互、潜行、冲突 | 秒至分钟 |
| L2 个体生活 | 我是谁、能做什么、携带什么、如何生存与推进目标？ | 技能、背包、装备、产权、生存、任务、关系/身份 | 分钟至游戏日 |
| L3 生产与交换 | 我如何把劳动、材料和设施转化为价值？ | 建造、生产、维护、物流、交易、市场 | 游戏日到周期 |
| L4 社会与制度 | 我如何与组织、规则、公共资源和其他主体协作或博弈？ | 组织经营、雇佣、预算、许可、税务、金融、政治与公共秩序 | 周期到长期 |
| L5 世界演进 | 世界的生态、人口、技术和制度如何改变可选玩法？ | 生态影响、文明能力、跨区传导、长期战略 | 长周期 |

L4/L5 的一部分会自主模拟，但自主推进只是时间调度策略，不会使其脱离玩法。反过来，
L1/L2 的选择也能逐层累积为组织利润、税基、声望、制度变化和文明能力。

## 跨层闭环

“经营面包店”不是一个经济后台任务，而是从 L2 到 L4 的可玩闭环：

```text
技能与体力（L2）
-> 原料、设施与生产（L3）
-> 库存、报价和居民消费（L3）
-> 雇员、工资、预算、许可证和税费（L4）
-> 声望、家庭、公共秩序与后续需求（L2/L4/L5）
```

同一闭环既可接受玩家命令，也可在 NPC/组织日程中推进；两条路径都必须经过相同的
authority、revision、事件与回放约束。Econ-1 是首个候选跨层样板，不是完整经济或
社会模拟完成声明。
