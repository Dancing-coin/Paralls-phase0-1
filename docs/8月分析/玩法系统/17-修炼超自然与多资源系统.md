# 修炼、超自然与多资源系统

状态：`planned cultivation extension; it must reuse existing resource/body/status and event authority boundaries`

## 1. 定位

修炼、魔法、信仰、科技异能等是同一玩法扩展类型：它们引入新的资源、能力、
效应和规则覆盖，但不能绕过物理、因果和 authority。基础自然规则仍然是基线；
超自然包只能通过显式优先级实施叠加、增强、覆盖、抑制、免疫或穿透。

## 2. 核心模型

```text
ResourceDefinition
  resource_ref, unit, maximum_policy, recovery_policy, reservation_policy

DisciplineDefinition
  discipline_ref, stages, prerequisites, training_evidence, breakthrough_policy

TechniqueDefinition
  technique_ref, action_ref, resource_costs, effect_templates, risk_policy

RuleOverride
  override_ref, base_rule_refs, mode(add|enhance|suppress|override)
  priority, scope, duration, counterplay_refs
```

生命、耐力、法力、灵力、信仰、专注等都使用同一资源 reservation 与事件投影
机制；它们的恢复和耗尽后果由各自 policy 定义。境界或突破必须有技能、资源、
证据、环境和风险闸门，不能由对话文本直接晋升。

## 3. 规则优先级

```text
自然/世界基线规则
  -> 已激活区域或文明规则
  -> 技术/功法/装备 effect
  -> 抵抗、免疫、反制和限制
  -> 状态变更与持续 effect
```

元规则引擎必须在 manifest 中验证优先级、互斥、循环、最大链深和可反制性。
例如火球可以提高热效应或穿透抗性，但仍通过目标材料、部位、护甲、环境和
规则覆盖层结算；不会直接写入“目标死亡”。

## 4. 与其他系统

技能成长提供修炼进度和 technique 资格；背包/装备提供法器、媒介和材料；
生存系统处理资源透支、伤势和环境要求；战斗消费 effect/resistance；任务和
组织记录传承、许可、禁术与声望；政府/文明能力可以限定可用体系。

## 5. 当前与新增

- `implemented`：resource/body reservation、skill path、effective stats、status tags、
  Patch Rule IR、声明式 capability 边界；
- `reusable`：action gate、effect/meta-rule 设计、revision、replay 和创作者权限；
- `planned`：multi-resource registry、discipline/technique schema、breakthrough evidence、
  RuleOverride contract、区域禁用/许可、反制规则和超自然内容包验证。

创作者可定义资源、功法、招式、法器和受限规则覆盖；规则解释器、优先级仲裁、
资源事实和状态写回必须留在闭源核心。
