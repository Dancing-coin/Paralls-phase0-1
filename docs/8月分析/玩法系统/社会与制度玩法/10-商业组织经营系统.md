# 商业组织经营系统

状态：`planned organization extension; current reusable primitives are economy, inventory, ownership, contract, skill, and event/replay`

## 1. 组织是独立经济主体

商店、工坊、农场、运输队和银行等组织都拥有独立 subject、账户、库存、设施、
成员、预算和经营周期。组织经营是 L4 的高层玩法：玩家可创建、加入、经营或影响
组织，NPC 经营者则是组织的决策代理，不是组织资产的替代品。

## 2. 核心模型

```text
Organization(organization_id, subject_id, type, jurisdiction_ref)
RoleAssignment(member_ref, role_ref, authority_scope, wage_policy)
Budget(period, account_refs, spending_limits, reserve_target)
OperatingPlan(target_stock, procurement, staffing, production, pricing)
BusinessPeriod(period_id, revenue, costs, payroll, tax, profit, closed_at)
```

## 3. 经营流程

```text
预测需求 -> 采购/生产 -> 排班与工资 -> 销售/服务
-> 维护/税费 -> 期末结账 -> 预算与信用更新
```

组织 AI 与玩家都只能提交采购、排班、报价、雇佣、借款或投资 proposal。Organization
Authority 检查成员权限、预算、授权范围、政策和 pinned revision，再调用经济、库存、
技能、生产 authority 进行原子结算。

## 4. 当前与新增

- `implemented`：account、inventory、ownership、debt、contract、skill 和 event/replay；
- `reusable`：idempotency、projection privacy 与跨域读取边界；
- `planned`：EconomicSubject、policy authority、组织注册、成员/职位/委托、预算、采购订单、排班、工资、营业日结、
  利润/现金流/信用和有限的停业/破产状态机。

创作者可编辑组织结构、岗位、经营目标、工资、采购优先级和风险偏好；不能
直接修改组织余额、库存或成员权限事件。
