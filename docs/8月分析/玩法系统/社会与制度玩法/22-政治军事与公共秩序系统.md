# 政治、军事与公共秩序系统

状态：`bounded public-obligation and conflict-boundary slices implemented; politics, military and full public-order remain planned`

## 1. 与政府监管的区别

政府监管处理许可、税费和检查；政治军事系统是进一步的 L4/L5 玩法，处理公共授权
如何产生、法律如何生效、预算如何分配、秩序如何执行、领土如何控制以及群体冲突
如何升级。任何政府组织都不是可任意改写世界的管理员账号。

## 2. 核心模型

```text
Polity
  polity_id, jurisdiction_ref, legitimacy_policy, offices, public_accounts

Mandate / OfficeAssignment
  holder_ref, scope, delegation, valid_from, valid_until, recall_policy

PublicPolicy
  policy_ref, proposal_ref, enactment_evidence, effective_tick, appeal_path

PublicBudget
  period, revenue_refs, allocation_rules, expenditure_limits, audit_refs

MilitaryUnit / CommandOrder
  unit_ref, member_refs, readiness, supply_refs, command_scope, objective_ref

PublicOrderCase
  case_ref, alleged_fact_refs, evidence_refs, due_process, outcome, appeal
```

法律、政策和命令都先是 proposal，经过规定的授权、证据、投票/任命或程序条件
后才获得有效 revision。军事 command 只能产生约束范围内的行动意图；真正移动、
交战、供给、伤害、征收和领土状态仍分别由行动、冲突、经济、产权和环境
authority 结算。

## 3. 公共秩序与跨域影响

```text
public policy / order -> permission, duty, budget or effect proposal
-> domain authority settlement -> public audit / reputation / social response
-> legitimacy and future policy constraints
```

执法与处罚必须有法规版本、证据、管辖、比例性、可申诉路径和审计记录；谣言或
司命叙事不能直接构成处罚依据。战争、征税、救济、戒严、征用和禁运都通过明确
capability 与预提交 `SettlementPlan` 表达，不能作为跨域直接写入。

## 4. 当前与新增

- `implemented`：经济/产权/合同原语、event/replay、受限 audit 与 Siming 边界；
- `reusable`：evidence、privacy projection、内部 Patch active-set lifecycle 与 replay
  脊柱；它们不是通用 policy activation、生产身份或公共审计运行时；
- `implemented bounded`：permit/tax/inspection/public-obligation、evidence/privacy、
  investigation conflict、event/replay and Siming boundary；
- `planned`：Jurisdiction 扩展、scheduled activation、polity/mandate/public policy/budget、lawful delegation、public order case、
  military unit/command/supply、legitimacy/territory projection 和 due-process rules。
