# 金融、信用与投资系统

状态：`late-phase social/institution gameplay extension; not Econ-1 scope`

## 1. 边界

金融是在账户、产权、合同、组织、信息和政府监管稳定之后的受治理 L4 玩法扩展。
它使玩家和 NPC 能在明确风险、信息与监管约束下进行借贷、担保或投资；不等于给
现有余额加利息，也不应把创作者收益、平台支付或现实货币清算混入游戏世界账本。

## 2. 核心模型

```text
CreditFacility
  facility_id, lender_ref, borrower_ref, limit, collateral_refs, policy_ref

LoanSchedule
  principal, interest_policy, due_ticks, delinquency_policy, status

FinancialRiskExposure
  holder_ref, counterparty_ref, instrument_ref, amount, maturity, source_refs

SecurityDefinition / Holding
  issuer_ref, rights, cashflow_policy, transfer_policy, holder_ref, quantity

ClearingBatch
  batch_id, obligations, netting_policy, settlement_receipt, failure_policy
```

抵押物必须引用 ownership/custody 中的真实资产；信用授予可读取经过授权的信息、
历史履约和政策，但不能读取角色原始记忆或其他项目数据。利息、违约、追加保证
金、清算和破产都通过 scheduled obligation 和原子 posting 提交。

## 3. 文明、信息与监管门槛

金融工具由 `CivilizationCapability`、辖区许可和监管 policy 解锁。证券、债券、
保险、银行准备金、内幕交易和市场操纵必须依赖知识/信息传播、商业组织、政府
监管和审计能力，不能在单一面包店阶段实现。宏观货币发行、跨区汇率和系统性
风险在更后期才接入六轴因果图。

## 4. 当前与新增

- `implemented`：账户、固定交易、simple debt、simple contract、产权与回放；
- `reusable`：信息可见性与 event/replay 脊柱；
- `planned`：posting/hold、Organization/Governance、调度与 policy revision、
  credit/collateral、interest schedule、risk graph、security/holding、
  clearing、insolvency、financial disclosure、反操纵与金融监管规则。
