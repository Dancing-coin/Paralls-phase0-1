# 文明能力与六轴传导

状态：`late-phase layered-gameplay guidance; CivilizationCapability and cross-axis causality are planned`

## 1. 领域位置

文明能力、金融/制造/教育等制度解锁，以及物质生态、人口社会、政治军事、文化信仰、
知识科技、司命气运之间的长期传导，构成 L5 世界演进玩法。它们读取已提交的世界、
角色、经济和治理事件；不属于 `world_runtime` 的 canonical owner，也不可直接改变环境、
账户、角色或规则真相。玩家可以通过研发、制度参与、公共行动和长期战略影响其中
有限的因果边；群体模拟则在玩家不在场时推进同一套已启用机制。

既有世界基础设施只提供时间 profile、事件/revision 脊柱和群体调度入口；如何解释“某种
制度已被社会采用”由未来的 Civilization/Society Authority 决定，并仍须映射到各领域
authority 的事件。基础经济的范围先以 [Econ-1](02-经济系统底座.md) 为界，金融和公共
秩序分别在 [21](21-金融信用与投资系统.md)、[22](22-政治军事与公共秩序系统.md) 后置。

## 2. 候选模型与约束

`CivilizationCapability` 是候选的版本化“允许机制集合”，不是单一科技树数值，也不是
世界基础设施的既有调度/配置入口。未来正式设计至少要定义其前置条件、辖区范围、启用的玩法包/规则、
生效 revision 和撤销/迁移行为。

六轴传导只能以有限、带方向的因果边逐步加入：每条边必须固定阈值、衰减、规则版本、
来源事件和影响的领域 projection。例子是技术突破影响生产率，再影响劳动需求、税基
和社会稳定；它不是让一个“文明总分”直接改写所有余额或角色性格。

## 3. 实施门槛

在正式建设前，以下能力都仍为 `planned`：

- 有效的 `CivilizationCapability` schema、authority 与事件；
- 组织、政府、知识传播和生态投影间的有限因果链；
- 文明/政策 revision 与游戏、模拟、推演 profile 的一致性；
- 跨轴回放、预算和循环截断的 Harness；
- 创作者在 Preview 中观察和验证制度效果的受限视图。

不得先实现宏观万能模拟器、默认股票市场、完整选举或战争全局模型。先证明一个具体
capability 能在可回放的事件链中门控一个明确玩法，再扩展第二条因果边。
