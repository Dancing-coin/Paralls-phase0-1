# 社会与制度玩法

状态：`bounded economy/organization/governance slices implemented; long-cycle social simulation remains planned`

当前实现映射：见 [../../12-实现收口与证据映射.md](../../12-实现收口与证据映射.md#社会与制度玩法)。经济、组织、监管和信用已有 P1/P2/P4 限定闭环；投资、政治军事和文明能力仍未实现。

本目录是玩法系统的第四层：玩家不只通过战斗或任务参与世界，也可以劳动、生产、交易、
创业、雇佣、经营组织、接受监管、参与公共秩序并推动制度演进。经济、组织、政府、金融、
政治和文明不是“玩法以外的后台模拟”，而是更长反馈周期、更大作用范围的玩法域。

它们同时具有两种运行方式：

- **玩家参与**：角色提交工作、交易、雇佣、投资、许可、申诉、政策或公共行动等 typed intent；
- **自主推进**：NPC/组织计划器在日级或长周期中提交同类 intent，调度器只改变何时推进，
  不改变谁拥有账户、库存、税务、关系或政策事实。

这不是让一个“社会模拟器”成为新的世界真相 owner。经济、组织、政府、金融和公共秩序
仍各自拥有明确的 authority；它们通过既有 event/replay 脊柱与技能、背包、设施、生存、
关系、生态和任务协作。完整 owner 矩阵见
[全域架构](../../全域架构/00-系统边界与责任矩阵.md)。

## 和其他玩法层的关系

以 Econ-1 面包店为例：技能和体力决定劳动资格；背包/产权管理原料与商品；设施决定
产能；生存需求创造消费；经济结算价格、工资与税；组织负责预算和岗位；监管验证许可。
这是一条完整的高层玩法循环，不是多个后台表之间的同步任务。员工、顾客、供应商和
监管人员在群体模拟实现后使用真实 CharacterRecord；在此之前只运行单玩家与聚合需求
配置，不伪造 NPC 状态。
