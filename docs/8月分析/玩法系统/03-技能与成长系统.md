# 技能与成长系统

状态：`incremental skill guidance; current action/ability gates are reusable and broader progression is planned`

## 1. 目标与边界

技能系统回答“角色是否会做、当前能做到什么质量、执行需要付出什么代价”。
它不直接决定剧情，也不直接写经济余额；工资、训练费和服务收入交给经济域。

## 2. 数据模型

```text
SkillDefinition
  skill_ref, version, level_range, prerequisites, tags

ActionDefinition
  action_ref, required_skills, resource_costs, risk_policy

LearningEvidence
  evidence_id, actor_ref, source_action, mentor_ref, quality, tick

SkillFact
  actor_ref, skill_ref, level, progress, source_event_ids

SkillResolution
  effective_level, efficiency, quality_band
  risk, resource_reservation, explanation_digest
```

技能事实只能由学习/训练/晋升事件投影得到。`SkillResolution` 还要组合身体、
状态、装备 modifier、环境和岗位条件；客户端或模型不能传入“我已经掌握”。

## 3. 成长闭环

```text
行动尝试 -> 资格/资源判定 -> 结果与证据
-> progress 累积 -> 晋升闸门 -> 新能力/新岗位
```

失败也可以产生受控证据、风险和关系后果，但不应随机跳级。高风险晋升可要求
导师、考试、任务证据或组织批准。

## 4. 当前与新增

- `implemented`：skill/action catalog、学习证据、资源/身体 gate、能力投影；
- `reusable`：revision pinning、原子事件批次、effective stats 和 status；
- `planned`：通用工作效率/质量曲线、训练场景、岗位资格、技能遗忘、跨职业迁移和
  创作者成长树编辑器。雇佣条款、工资合同、应付和支付由 Organization/Economy
  Authority 拥有；技能域只产生资格、质量和完成证据。

创作者可调技能定义、门槛、成长曲线、风险和训练内容；晋升判定器、证据校验、
隐藏技能 workspace 和状态写回仍属于闭源核心。
