# Superpowers 文档总入口

本目录分为两条并行但一一对应的文档链：

- [规格树](specs/README.md)：定义目标、边界、所有权、状态和验收口径。
- [计划树](plans/README.md)：定义执行顺序、文件范围、测试和交付步骤。

## 当前治理原则

1. `world-character-siming-authority-mainline` 是当前运行时主线真相。
2. `current-project-intelligence-upgrade` 是主线之外的增量专题，不重新定义主线。
3. 根目录平铺的旧文件默认视为历史规格；除非在对应 README 或治理清单中明确列为当前入口，否则不作为新工作的默认依据。
4. 规格、计划、审计/完成记录、冻结记录和执行提示词是不同文档类型，不应互相替代。
5. 近期保护清单中的规格在完成链接和索引迁移前不移动、不归档、不重命名。

## 整理阶段

- 阶段 1（当前）：建立入口、分类和保护清单，不移动文件。
- 阶段 2：补齐 spec ↔ plan ↔ evidence 关系和状态字段。
- 阶段 3：修复失效链接，建立历史/替代关系。
- 阶段 4：在链接验证通过后，才考虑物理归档或目录搬迁。

保护清单见 [近期 spec 保护清单](specs/_governance/protected-recent-2026-09.md)。
