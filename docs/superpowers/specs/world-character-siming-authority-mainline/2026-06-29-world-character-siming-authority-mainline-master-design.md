## Corrected Runtime Loop Model

### 1. Outer World Runtime Loop

```text
World State Change
-> World Sampling / Fact Production
-> Character-Private Percept Compilation
-> Character Mind Loop Wake-up
-> Execution Semantics
-> Realization / Settlement
-> World Writeback
-> New World State Change
```

### 2. Inner Character Mind Loop

```text
Perceived Facts
-> L1 Private Snapshot
-> L2 Cognitive Interpretation And State Update
-> Goal Ecology Activation / Maintenance / Reorganization / Repair
-> L3 Intent Planning And Selection
-> L4 Execution Contract
```

### 3. Downstream Execution Realization Segment

This is not a peer loop. It is a downstream realization segment inside the outer world runtime loop.

```text
L4 Execution Contract
-> Execution Semantics Layer
-> Asset / Kimodo Realization Layer
-> Local Presentation / Motion / Speech / Expression
-> Authority / Settlement / Runtime Result
-> Writeback To World And Character Inputs
```

## Why `L2` And `L3` Remain Split

`L2` answers:

- what this means for me
- what changed in my belief / social / higher-order / dynamic state
- whether a situation is risky, open, ambiguous, or pressurized

`L3` answers:

- given that interpreted reality and current goal ecology, what should I do next?

They remain separate because interpretation and planning are not the same runtime problem.
