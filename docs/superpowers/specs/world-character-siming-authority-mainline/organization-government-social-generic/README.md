# Organization / Government / Social Generic Subsystems

This subtree defines the approved federated Organization/Government/Social
generic platform.

The platform stays behind strict `v3/2.0` content, closed owner families,
precompiled recipes, and explicit population materialization. Population is
signal-only; no generic writer, router, coordinator, or second runtime is
introduced.
