# P1E Generalization Gate Design

Status: `implemented-and-verified; ownership-contract-debt sample and phase1e Harness evidence fresh on 2026-08-09`

Date: `2026-08-07`

## Purpose

定义第一阶段最后的泛化门禁。P1E 不提前选择或实现第二款完整游戏，而是规定怎样证明
P1A/P1B contract 没有被 V0 或 Econ-1 的字段和流程污染。

## Candidate Shapes

正式 plan 只能选择一个候选：

- evidence-driven investigation/permission interaction；
- contract/debt/ownership-heavy interaction；
- physical object action with material/effect resistance。

候选必须与面包店在主要 aggregate、时间尺度、失败类型或输入事实上存在结构差异。

## Required Comparison

P1E 必须比较 V0、Econ-1 和第二样板：

| Comparison | Required result |
| --- | --- |
| core schema | no sample-only field enters identity/semantic/settlement/time core |
| owner matrix | each domain adds its own authority, no duplicated canonical fact |
| command envelope | same principal/idempotency/revision/causation contract |
| action/fact | same PhysicalFact/LogicalFact boundary or justified no-physical path |
| reservation | same lifecycle where resources/rights are reserved |
| replay | full/checkpoint-tail and projection rebuild hashes match |
| permission | actor/creator/public/Godot filtering remains explicit |
| profile | game/simulation/inference changes granularity, not truth semantics |
| package | dependency/schema/capability/migration validation remains fail closed |

## Acceptance Evidence

- cross-sample report with schema diff and owner diff;
- same contract fixture suite run against at least two shapes;
- replay equivalence and revision pin evidence;
- focused rejection/zero-write evidence;
- report that records all sample-specific extensions outside core schema;
- no new store, bus, runtime, scheduler, shadow NPC or sample-local interpreter。

通过 P1E 后，只能宣称“第一阶段通用契约通过泛化门禁”。仍不能宣称动态市场、完整
商业社会、Population Simulation 或 Creator Control Plane 已完成。
