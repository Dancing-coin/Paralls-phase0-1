# Ecology Generic Platform Subsystems

The nine subsystem specs below implement the approved layered Ecology
platform. Each keeps Ecology-owned facts separate from target-owner facts and
uses Manifest v3/platform 2.0, exact binding, append_batch, receipt and replay.

1. region-topology-and-grid-state
2. weather-climate-and-water-cycle
3. soil-resource-regeneration
4. crop-and-habitat-lifecycle
5. species-community-and-food-web
6. multi-hazard-lifecycle
7. recovery-and-resilience
8. regional-period-close-and-propagation
9. owner-bound-ecology-consumers
