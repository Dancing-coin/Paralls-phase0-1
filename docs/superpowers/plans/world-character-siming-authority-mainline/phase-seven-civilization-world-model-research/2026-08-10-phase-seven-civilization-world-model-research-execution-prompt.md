# Phase Seven Civilization, World Model And Robotics Research Execution Prompt

仅在 P7 套件整体获得研究/沙箱授权、P6D fresh-green 且完成独立安全评审后使用。

```text
你负责 Paralls Phase Seven Civilization, World Model And Robotics Research 的完整执行套件。
P7 只扩展 read-only projections、branch reports、model proposals 和 simulation safety。它不宣称
文明模拟、世界模型、机器人或反事实 runtime 已实现，也不允许它们成为世界真相 authority。

开始前读取：
- AGENTS.md、docs/INDEX.md、docs/harness.md、docs/ai-engineering-workflow.md；
- P1-P6 specs/plans 与 fresh reports，尤其 P6D；
- phase-seven-civilization-world-model-research spec/plan README；
- P7A-P7D specs 与 matching plans；
- docs/8月分析/第七阶段推进全部文件；
- event/replay/checkpoint readers、permission/classification/audit、Patch/package governance、
  Character/Economy/Government/Organization authority 和 presentation/sandbox boundaries。

前置门禁：运行 P6D 及所有 predecessor profiles；确认研究数据分类、隐私、可复现性和安全责任人。

唯一顺序：
P7A civilization/cross-jurisdiction read projection
  -> P7B immutable branch replay/counterfactual calibration
  -> P7C world-model proposal boundary
  -> P7D robotics simulation safety slice

P7A：
- 先测 source provenance、jurisdiction scope、policy pin、redaction、deterministic aggregation、
  checkpoint-tail rebuild、zero world write；
- 只输出 derived projection/report，禁止写税、市场、组织、角色、领土事实。

P7B：
- branch descriptor pin parent checkpoint/tail、package/policy revision、perturbation manifest、
  seed、classification、expiry；
- 先测 isolation、no merge、seed determinism、stale dependency、private-data denial、calibration
  labels、retention；
- 只生成 audited CounterfactualReport，不创建平行 mutable event store，不生成可提交 settlement。

P7C：
- world model 只能读取 approved scope-filtered snapshots，输出带 model id/input digest/confidence/
  uncertainty/policy class/expiry/explanation 的 PredictionProposal；
- content candidate 进入 P6 package governance；action recommendation 重新走既有
  GameplayCommandEnvelope -> SettlementPlan -> GameplayEventStore.append_batch() authority；
- 模型不能读 private memory/keys、调用 writer、执行 arbitrary generated code 或控制 Godot/robot。

P7D：
- 先在 simulation-only 验证 sensor latency/dropout、malformed command、safety envelope、operator
  authorization、emergency stop、audit 和 sandbox isolation；
- experiment log 与 canonical replay 分离；robotics adapter 不调用 append_batch() 或直接
  SettlementPlan；
- 真实物理执行必须另有硬件 interlock、operator stop、独立安全审批和新的 spec/plan，不在此套件内。

每阶段必须先 failing/fault tests，再 research/security Harness、predecessor Harness、docs/
mainline；汇报 source/branch/model/experiment digests、redaction、calibration、fault matrix、
stop latency、audit 和 zero-write。任何模型、分支或机器人试图写世界事实，立即停止报告。
只有 P7A-P7D 全部符合研究门禁，才能形成下一轮产品决策。
```

## Usage Constraint

这份提示词对应整个 P7 plan set；P7 仍是长期研究路线，不是当前运行时实现授权。
