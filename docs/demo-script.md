# Phase 0 Demo Script

1. Launch backend.
2. Launch Godot scene.
3. Connect player to scene.
4. Character A greets player.
5. Player sends one dialogue line.
6. Character A replies with TTS or TTS-stub playback.
7. Player approaches and retreats to demonstrate audible distance change.
8. Player interacts with key object successfully.
9. Player repeats interaction from invalid range and sees constraint feedback.
10. Object or environment visibly changes.
11. Siming emits one observable attention or situation catalyst.
12. Character B reacts.
