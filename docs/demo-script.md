# Phase 0 Demo Script

1. Launch backend.
2. Launch Godot scene.
3. Connect player to scene.
4. Character A greets player.
5. Player sends one dialogue line.
6. Character A replies with TTS or TTS-stub playback.
7. Player presses `Z` to cycle `漫步 / 走路 / 快走`.
8. Player uses `Shift + WASD` to demonstrate a visibly faster run.
9. Player presses `C`, moves in crouch, then exits crouch.
10. Player compares `WASD + Space` and `Shift + WASD + Space`.
11. Player approaches and retreats to demonstrate audible distance change.
12. Player interacts with key object successfully.
13. Player repeats interaction from invalid range and sees constraint feedback.
14. Object or environment visibly changes.
15. Siming emits one observable attention or situation catalyst.
16. Character B reacts.
