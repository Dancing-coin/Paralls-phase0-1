# 群体模拟升级集成实施计划

状态：`analysis/planned/non-authorizing`

## 1. 最小纵切片

先实现一个不依赖新增模型的可回放夹具：

```text
一个登记角色
→ 一份 life/profile/memory seed
→ 一个 B0 背景窗口
→ 一个非玩家焦点事件
→ 一次 activation handoff
→ 一个 Laya typed decision fixture
→ 一个原子动作
→ 一个静物模型脚本
→ 一次 physics evidence
→ 一个 authority receipt
→ 三本账投影
→ close/reopen replay
```

## 2. 责任边界

| 工作面 | 责任文件/owner | 不应修改 |
|---|---|---|
| 角色连续性 | `backend/app/character_agent/`、Character Core | 世界真相 writer |
| 人口推进 | `backend/app/world_runtime/population_driver.py`、population continuity | Laya provider |
| 时间 | `simulation_clock.py`、planned mapping | Godot 本地 clock |
| 空间 | L1/occupancy/space model、Godot capture | 角色私有记忆 |
| 司命 | `backend/app/services/siming_*` | domain facts |
| 领域事实 | 既有 Gameplay/ESM/domain owners | WRK coordinator |
| 表现 | Godot actors/scripts/physics | Backend truth |
| 证据 | Harness profiles/replay | 产品运行时逻辑 |

## 3. 任务顺序

### Task 1：迁移和链接收口

- 修复十月中旬 README、既有规格和计划的相对链接；
- 标记原始讨论和静态设计来源；
- 生成覆盖矩阵。

### Task 2：角色 seed 和交接夹具

- 固定角色 roster、seed、cursor、activation lock 和 close receipt；
- 证明同一角色不会生成第二个身份；
- 证明关闭后记忆和生命连续性保留。

### Task 3：三本账和时间空间夹具

- 为一个事件记录 event_time、known_time、presented_time；
- 为一个角色记录 truth/body/perception/presentation position；
- 验证过期表现不会覆盖新 revision。

### Task 4：WRK 窗口和 owner receipt

- 固定窗口输入 revision；
- 执行 B0/B1 候选；
- 路由至 domain owner；
- 仅 receipt 后推进 cursor。

### Task 5：Laya 质量夹具

- 使用固定心智帧和结构化候选集合；
- 先跑本地 provider readiness，失败再 API；
- 独立留出集评估选择质量；
- 明确 slow/deep fallback 不计入 Laya 成功。

### Task 6：脚本和现场案例

- 原子动物动作；
- 静物状态机；
- 马、骑马者、孩子、包子笼和玩家二次碰撞；
- 记录物理 evidence、authority receipt、记忆和表现。

### Task 7：容量和恢复

- 多角色窗口、焦点公平、backlog、写入等待、模型超时；
- 断点恢复、失败窗口、重复请求和 replay tail。

## 4. 证据产物

每个任务至少产出：

- focused test；
- Harness profile；
- JSON/Markdown/NDJSON trace；
- 输入 revision 和 digest；
- owner receipt 或明确 denial；
- 回放 fixture；
- 静态/运行时证据分类。

## 5. 回滚和降级

- Laya 不可用：回到 continuity floor/B1 行为模块；
- 现场脚本失败：保留显式静态表现和真相状态；
- WRK 窗口失败：保留 backlog/cursor，不静默跳过；
- Godot 未验证：只能报告 backend/static，不宣称玩家现场完成；
- 领域 owner 拒绝：候选回到 requeue 或失败记忆，不伪造成功。

## 6. 实施门禁

没有以下证据不得推进下一阶段：

1. 没有角色 continuity receipt，不接完整群体 roster；
2. 没有三本账和时间空间映射，不接局部现场；
3. 没有 Laya 独立质量证据，不宣称角色智能体完成；
4. 没有物理和脚本 replay，不接复杂动物/静物交互；
5. 没有全批次覆盖审查，不进入大规模改码。
