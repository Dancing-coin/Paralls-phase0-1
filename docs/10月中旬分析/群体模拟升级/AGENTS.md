# 群体模拟升级文档规则

状态：`analysis/planned/non-authorizing`

本目录是 2026-10-12 十月中旬分析批次中“开放世界群体模拟、世界运行内核、司命与角色智能体协同”的主文档目录。世界模型相关内容单独保留在同级 `../世界模型与AI工作区/`，本目录不复制、不改写、不依赖其设计。

## 文档边界

- `规格/` 只写架构规格；必须包含架构图、主流程时序图、数据流图，并区分前架构、过渡架构、目标架构及 current/planned/deferred。
- `计划/` 只写实施计划；必须引用规格，不重新定义 owner 或领域对象。
- `讨论归档/` 保存继承线程原文、原文摘录、决策和案例，不把讨论内容伪装成实现证据。
- `审查/` 保存原始十月分析、线程、当前代码、测试、规格之间的覆盖和阻断映射。
- `回写/` 保存相对十月分析原文的补充、修正和范围变化。

## 核心设计不变量

- 世界真相由现有 authority/domain owner 结算；司命、角色模型、群体候选、图谱和 Godot 都不能直接写事实。
- 角色私有记忆由 Character Core/private memory owner 管理，不等于公共社会图谱。
- 世界运行内核（World Runtime Kernel，WRK）负责时间、调度、批量模拟、驱动交接、结算回执和恢复组织；不是万能事实写入器。
- 司命先处理事件、压力、义务和预算，再选择角色与精度；不替每个角色预写完整人生。
- B0/B1/B2/B3 是连续性和模拟精度层；Laya/Slow/Deep 是心智模型路由层，不能混用。
- “角色出现在画面里”和“角色运行完整智能体”是两个独立决定。
- 动物行为使用原子动作；静物行为使用原子模型脚本/状态机；最终由物理和领域 owner 确认结果。

## 证据规则

- `[current]` 只能由当前代码、测试、Harness 或正式运行时文档证明。
- `[planned]` 表示有来源依据但未完成实现或验收。
- `[deferred]` 表示暂缓，不是已经实现。
- `[blocked]` 表示有明确未解除条件。
- 继承讨论原文是设计来源，不是运行时证明。
