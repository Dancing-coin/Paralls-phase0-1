# 群体模拟升级

状态：`architecture analysis; proposed and non-authorizing`

日期：2026-10-12

## 目标

把线程中关于开放世界社会生命、司命、群体模拟、角色智能体、Laya、世界真相、三本账、时间空间、局部活化、行为脚本和玩家介入的讨论整理成一套可审查的设计文档。

核心目标是：

> 让城市在玩家不在时仍然持续运行，让每个登记角色保留独立生命、档案、记忆和影响；当玩家接近或事件重要时，提高局部模拟精度，让少数角色激活完整智能体，同时不让全体角色常驻高成本模型。

## 与世界模型目录的边界

同级的 `../世界模型与AI工作区/` 是独立主题。本目录忽略世界模型、latent space、World Pack 和 World Action Harness，不把它们作为群体模拟升级的前置依赖。未来如需接入，必须另行通过边界合同和回写审查。
