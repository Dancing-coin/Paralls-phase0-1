## 3. 与世界模型目录的边界

`../世界模型与AI工作区/` 保持独立。本索引不复制其规格，也不把 latent、视觉世界模型、World Pack 或 World Action Harness 作为群体模拟升级前置。未来如果需要接入，必须新增跨域合同和回写，不得把世界模型假设偷偷写入本批 runtime 设计。

## 4. 与旧文档的关系

- `既有中旬规格/`、`既有中旬计划/`、`既有中旬审查/` 是迁移前内容的保留副本，便于历史对照。
- 新规格编号从 `06` 开始，是因为 `00-05` 已有旧主题规格；新 `00` 是本批跨主题总架构入口，不覆盖旧 `00`。
- 修改旧主题的 owner、接口、时间语义或范围时，必须在[十月分析设计修正登记](00-十月分析设计修正登记.md)中增加记录，并更新对应旧文档的“本批回写”段落。
