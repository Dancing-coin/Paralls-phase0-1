# 已确认决策登记

状态：`analysis/decision-record/non-authorizing`

## 角色与 Laya

- 角色域优先于自走棋装备、玩法包、回合、羁绊和奖励。
- Laya 是激活角色智能体的通用快思考、低延迟、typed decision 模型，不只服务战斗。
- B0/B1/B2/B3 是模拟精度/连续性层；Laya/Slow/Deep 是心智路由层。
- 本地有 LLM 时优先本地，没有时使用 API。
- Laya 采用独立本地服务和 backend adapter，模型进程与角色 backend 隔离。
- multilingual checkpoint 作为第一阶段官方基线，typed-decisions 作为对照。
- 使用结构化可接受动作集合评估决策质量。
- 领域微调由实测触发；不能用慢模型回退掩盖 Laya 质量不足。

## 群体模拟与司命

- 一个世界可以有多个角色智能体和一个司命。
- 司命先处理事件、压力、义务和预算，再决定选择哪些角色和精度。
- 群体模拟持续推进；角色智能体激活或关闭不改变角色身份和记忆连续性。
- 图谱是派生社会生命索引，不是第二世界真相库，也不替代角色私有记忆。
- 每个登记角色应有稳定档案/生命状态/位置锚点/记忆种子和可恢复游标。
- 激活焦点不能只来自玩家；必须允许世界事件、关系传播、区域压力、due 和随机种子产生非玩家焦点。

## 表现和脚本

- 玩家能看到许多角色，不代表全部角色都运行完整智能体。
- 动物使用原子动作；动物是否有自我意志与是否受高级意志控制是两个维度。
- 静物使用原子模型脚本和状态机，最终由物理引擎与领域 owner 确认。
- 后台真相、角色记忆和现场表现必须分开记录和同步。
