# 十月中旬分析：全体角色社会生命、派生图谱与 Laya 混合运行时

状态：`architecture analysis; proposed and non-authorizing`

日期：2026-10-12

## 本批目的

本批把原十月分析中的角色心智、Laya、主动感知、能力包络、人口连续性、司命治理和知识图谱放到同一个开放世界目标下重新对齐：

> 让世界中的每个登记角色持续拥有独立生命线、关系、记忆来源和对社会的影响；用低成本群体推进和派生社会图谱承载全体角色，用角色智能体的 L1-L4 与 Laya 快循环处理被激活角色，用慢思考/Deep Model 处理重规划和复杂认知。

这不是让所有角色常驻完整 LLM，也不是让司命替每个人写人生剧本。

## 关键修正

1. **Laya 定义修正**：Laya 是已激活角色智能体的连续快思考/快决策回路，负责当前 typed intent、表达选择、取消和短期协同；不只服务战斗，也通过 `ThoughtMode` 适配经济、社交、探索和调查。
2. **维度拆分**：B0/B1/B2/B3 表示连续性和模拟精度；Laya/慢思考/Deep 表示心智模型路由。B3 不等于 Laya，B0/B1 也不能被写成完整角色智能体。
3. **图谱边界**：采用 MiroFish 式“每个角色是图谱节点、关系和事件可传播”的思路，但复用 HeavenlyGraph/authority projection 作为派生索引，不创建第二世界真相库或第二角色记忆库。
4. **司命定位**：司命先治理世界压力、事件、义务和预算，再选择需要何种角色推进；不是每轮为每个角色写故事线。
5. **玩家中心修正**：激活候选同时来自世界事件、角色 due、关系传播、区域压力、玩家交互和公平性随机焦点。

## 世界模型与 AI 工作区

面向“3D 世界成为 LLM、视觉模型、隐空间模型和世界动作模型共同工作区”的独立子域见[世界模型与 AI 工作区](世界模型与AI工作区/README.md)。它复用现有 world truth、L1、角色心智、Godot、ESM、物理和 Harness，不创建第二套 authority。HY World 2.0、WorldPlay2、LaWAM 及其他外部项目只作为研究输入，必须经过本目录定义的 WRC、World Pack、proposal admission 和 Harness 门禁后才能进入实现讨论。

## 当前范围

- 目标是开放世界运行时。
- 自走棋、棋盘回合、羁绊、奖励和单局玩法包继续保持 deferred，不进入本批 active gate。
- 通用编辑器控制面和 AD/Blender 动作工作流不进入本批执行，只在依赖和阻断中登记。
- 角色心智和 Laya 基础闭环优先于群体社会规模扩展。
