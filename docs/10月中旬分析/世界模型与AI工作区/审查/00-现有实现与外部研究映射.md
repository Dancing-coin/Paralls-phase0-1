# 现有实现与外部研究映射

状态：`analysis/planned/non-authorizing`

日期：2026-10-12

## 1. 结论摘要

当前仓库已经有“多模型工作区”的若干底座，但还没有一个统一的 World Runtime Contract：

- VLA 感知 advisory、L1 perception frame、空间模型、SimulationClock、population cadence、角色智能体和 ESM/authority 已有代码或正式运行时文档。
- P7C 已经规定 world model 只能消费 scope-filtered snapshot 并发出 proposal，不能直接写事实。
- `LAWAM.md` 已记录隐空间 world-action 路线，但仓库没有 LaWAM adapter 或 latent subgoal admission。
- HY World 2.0 能产生可导入引擎的 3DGS/mesh/点云等资产候选，但仓库没有 World Pack Compiler、entity binding、自动碰撞/导航/角色资产资格化闭环。
- World Action Model 公开项目主要面向机器人策略、未来视频/latent dynamics 和 action chunk；仓库没有统一 rollout/safety/action-model facade。

因此，本目录是架构补齐和研究登记，不是“世界模型已经接入”或“世界模型可以直接修改 3D 世界”的完成声明。

## 3. 外部世界模型研究

### 3.1 HY-World 2.0 / WorldMirror 2.0

- 项目：[Tencent-Hunyuan/HY-World-2.0](https://github.com/Tencent-Hunyuan/HY-World-2.0)
- 技术报告：[arXiv:2604.14268](https://arxiv.org/abs/2604.14268)
- 公开说明：文本、单图、多视图和视频输入；WorldMirror 2.0 输出 depth、normal、camera、point cloud、3DGS；World Generation 组合 HY-Pano 2.0、WorldNav、WorldStereo 2.0 和 3DGS composition。
- 公开文档列出的重建输出包括 `gaussians.ply`、`points.ply`、camera JSON、depth/normal 等。

**对本项目的判断：**

- 可作为 `WorldPackCompiler` 上游的重建/生成候选。
- 可作为场景视觉、相机、深度、法线和导航轨迹的来源。
- “可导入 Unity/Unreal/Isaac、可漫游、可碰撞”是产品/README 层能力描述；不能直接推导出本项目所需的稳定实体 ID、游戏事件、角色记忆、版本化 snapshot/restore、多人一致性和 affordance owner。
- 3DGS/点云默认是 visual/geometry asset；交互碰撞、物理材质、导航和可破坏状态必须由本项目重新绑定和资格化。

### 3.2 WorldPlay2

- 项目/论文：[WorldPlay2 arXiv:2609.35560](https://arxiv.org/abs/2609.35560)
- 方向：动作条件视觉世界模型，输入图像、低层动作、scene/character/event 语义和压缩视觉历史，输出连续视频帧。

**判断：**适合 NeuralVisualZone、表现预测和动作条件视觉 rollout；在没有稳定实体、空间、碰撞、事件和 snapshot/restore 适配前，不能承担 Explicit3DZone 的真相或交互 owner。

### 3.3 LaWAM

- 仓库：[RLinf/LaWAM](https://github.com/RLinf/LaWAM)
- 论文：[arXiv:2606.15768](https://arxiv.org/abs/2606.15768)
- 本仓库笔记：`docs/上下文不够用/LAWAM.md`

**判断：**隐空间子目标和 latent action 预测适合低延迟候选生成与 rollout ranking；输出要挂在 WRC 的 `LatentSubgoalRecord`，不能绕过动作候选、物理和 owner。

### 3.4 世界动作模型公开路线

| 项目 | 公共描述 | 可借鉴的接口 | 本项目不能直接假定 |
|---|---|---|---|
| [UnifoLM-WMA-0](https://github.com/unitreerobotics/unifolm-world-model-action) | 世界模型同时作为交互模拟器和 policy enhancement | future interaction prediction、action head、sim deployment | 游戏 entity/event/authority 兼容 |
| [GigaWorld-Policy](https://github.com/open-gigaai/giga-world-policy) | action-centered WAM，推理阶段 action-only，强调低延迟 | action proposal、action chunk、latency budget | 直接控制 Godot 或可替代物理 |
| [Motus](https://github.com/thu-ml/Motus) | unified latent action world model，融合 understanding/action/video experts | latent action、mode switching、video-action joint prediction | 稳定 3D world state 或游戏动作注册 |
| [FastWAM](https://github.com/yuantianyuan01/FastWAM) | 研究 test-time future imagination 与 action inference 的权衡 | prediction/acting mode、rollout benchmark | 生产权限、安全和事件提交 |
| [LingBot-VA](https://github.com/Robbyant/lingbot-va) | causal video-action world modeling for robot control | visual dynamics + action sequence、KV cache/异步执行 | 开放世界社会模拟和玩家输入 |
| [LongLive](https://github.com/NVlabs/LongLive) | long video / world model / world action model infrastructure | 长时视觉历史和 world/action pipeline | 本项目 world truth 和 editor binding |

这些项目说明“模型适配器 + rollout + action candidate”是可行路线，但其数据集、机器人 embodiment、控制周期和成功率不能直接作为本项目开放世界质量证据。

## 4. 缺口和阻断

1. **WRC 缺口**：当前没有统一的 snapshot/context/proposal/result schema。
2. **实体绑定阻断**：视觉/3D 模型输出还没有稳定 entity ID 与 pack revision 绑定。
3. **交互阻断**：没有证明视觉或 latent output 能进入 action registry、Godot physics 和 authority commit 的闭环。
4. **时间阻断**：没有证明模型输出在 simulation tick、physics tick 和 presentation tick 之间的 stale/replan 规则。
5. **窗口阻断**：已有 L1/PQF，但没有模型无关的 context slice budget、omission ledger 和 latent provenance contract。
6. **证据阻断**：已有 VLA/provider Harness，尚无 world model input digest、proposal zero-write、asset qualification 和 rollout replay profile。
7. **资源阻断**：HY World 2.0 与多数 WAM 需要大显存/CUDA/特定依赖；本地部署可行性必须单独测量，不能由论文或 GitHub README 推断。

## 5. 证据等级

| 等级 | 含义 |
|---|---|
| E0 | 论文/README/官网声明，只有研究参考价值 |
| E1 | 本地 adapter 能解析并校验结构化输出 |
| E2 | 本地 snapshot -> model -> proposal -> denial/preview 可回放 |
| E3 | proposal 经 authority/physics 后产生真实 commit 和 Godot 结果 |
| E4 | 多模型、延迟、stale、冲突、回滚和压力测试闭环 |

HY World 2.0 当前在本项目最多是 E0；LaWAM/WAM 项目是 E0；现有 VLA advisory 是 E1/E2 范围；不能互相替代。
