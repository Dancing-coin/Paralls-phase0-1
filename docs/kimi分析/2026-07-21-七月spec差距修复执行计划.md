## 2. P1 技能运行时一级 shadow 接线

### 完成线

`CharacterSkillService` 必须被运行时真实调用，但只做 shadow 观察：

- runtime 初始化持有技能 registry/service。
- 每次 L3 决策后，根据角色 authored profile 生成 `CharacterSkillState`。
- 生成 `SkillAffordanceSummary`。
- 将 affordance summary 写入 mind frame / `MindDeltaLedger` 或等价 observability surface。
- 不改变 L3 选择结果。
- 不改变 L4 命令输出。
- 不阻止任何动作。

### 建议实现位置

- `backend/app/character_agent/runtime/runtime_loop.py`
- `backend/app/character_agent/skills/service.py` 仅在必要时做小扩展
- `backend/app/character_agent/mind/frame_builder.py` 或现有 ledger 入口，优先复用已有 `skill_affordance_summary` 字段

### 验证

新增或更新测试，证明：

- runtime 调用 `CharacterSkillService.build_affordance_summary()`。
- `build_shadow_mind_frame()` 或相关 observability surface 中出现非空 `skill_affordance_summary`。
- 同一输入下 command output 不因 shadow 技能接线改变。

建议命令：

```powershell
python -m pytest -q backend/tests/test_character_skill_service.py backend/tests/test_character_skill_catalog.py backend/tests/test_character_mind_affordances.py backend/tests/test_character_mind_frame_builder.py backend/tests/test_character_runtime_shadow_mind_frame.py
```
