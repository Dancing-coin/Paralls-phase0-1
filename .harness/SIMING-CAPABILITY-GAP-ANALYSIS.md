## 一、设计文档中的司命完整能力

### 1.1 五大核心子系统

| 子系统 | 职责 | 孙系统 |
|--------|------|--------|
| **事实核心** | 维护事实锁定链、矛盾比对、证据一致性检查 | 事实索引器、矛盾检测器、锁定阶段协调器 |
| **天平系统** | 评估局势倾斜、节奏风险与可玩性风险 | 势能评估器、偏移监测器、回稳建议器 |
| **冲突与案件生成器** | 生成冲突机会与次生事件 | 机会枚举器、触发条件判定器、后果链预估器 |
| **高阶知识图谱引擎** | 维护"谁知道什么、谁知道别人知道什么" | 知识态更新器、高阶关系推断器、传播范围约束器 |
| **干预执行器** | 把司命决策编码为高层催化消息 | 消息组装器、通道选择器、回写审计器 |

### 1.2 公平状态模型（FairnessStateSnapshot）

设计文档要求显式维护五个维度：

1. `information_distribution`：信息分布公平性
2. `participation_distribution`：参与窗口公平性
3. `conversation_access_fairness`：会话接入公平性
4. `suspicion_heat_distribution`：怀疑热度分布
5. `evidence_visibility_distribution`：证据可见性分布

### 1.3 知识状态管理

**最小对象集**（v0.1）：
- `Actor`：会产生感知、知识和会话行为的主体
- `Conversation`：一段运行时会话实例
- `InformationItem`：可被传播、共享、偷听或误解的信息单元
- `PerceptionAccess`：某角色对会话或信息的接入记录
- `MembershipState`：角色与会话之间的成员关系判定结果
- `KnowledgeClaim`：某角色当前对某条信息持有的知识状态
- `AwarenessRelation`：谁知道谁在场、谁知道别人知道自己在场

**最小输出集**（v0.1）：
- `MembershipResolution`：成员资格结果
- `AccessResolution`：接入质量与接入起点
- `KnowledgeResolution`：知识状态与知识来源
- `AwarenessResolution`：互相知晓确认结果
- `PrivacyRiskResolution`：暴露风险与隐私破坏风险
- `ConversationBoundaryChange`：会话开放度变化

### 1.4 干预阶梯

1. `Lv1` 冲动注入（impulse）
2. `Lv2` 环境催化（opportunity）
3. `Lv3` NPC / 事实唤醒（fact_reveal）
4. `Lv4` 公共事件 / 节奏打断

### 1.5 协作协议

- **08-司命与角色智能体协作协议.md**：三重过滤器、高层催化消息
- **09-司命与 ESM 协作协议.md**：环境请求、约束状态
- **10-司命与事件总线契约.md**：事件订阅、回写契约
- **11-司命与视觉事实系统协作协议.md**：视觉事实接入

## 三、能力缺失的影响评估

### 3.1 核心能力缺失（致命）

| 缺失能力 | 设计优先级 | 当前影响 | 阻塞功能 |
|---------|-----------|---------|---------|
| **天平系统** | P0 | 无法评估公平性 | 叙事纠偏、节奏控制 |
| **冲突生成器** | P0 | 无法自动生成机会 | 次生事件、戏剧催化 |
| **高阶知识图谱** | P0 | 无法管理会话 | 信息博弈、成员资格 |

**结论**：当前司命只是一个"事实存储 + 简单干预执行器"，**不是一个完整的天道系统**。

### 3.2 辅助能力缺失（重要）

| 缺失能力 | 设计优先级 | 当前影响 | 阻塞功能 |

| **T0-T3 锁定协调器** | P1 | 无法管理事实阶段 | 时间线锁定 |
| **矛盾检测器** | P1 | 无法自动识别矛盾 | 事实一致性保障 |
| **检查点系统** | P2 | 无法 replay | 调试、回溯 |
| **只读叙事表面** | P2 | 无法展示叙事状态 | 工作台可视化 |

### 3.3 协议完整性缺失（重要）

| 协议 | 当前状态 | 缺失内容 |
|------|---------|---------|

| **Protocol 09（ESM）** | 桩函数 | 完整的环境请求、约束状态回写 |
