# External Character B Candidate Package

This package is a self-contained staged wrapper for the externally authored
`npc_animated.glb`; the archive source has not been moved or modified. Its
textures are co-located with the staged copy and manifest provenance records
the original source and SHA-256 digest.

It is intentionally not admitted to the shared actor action path. Import
inspection found only `anim_drink` and `anim_knock`, neither a truthful
Idle/Walk/Run/Jump/Turn suite nor a qualified upper-body coexistence profile.
The timing sheet is a source-traceable candidate mapping, not an approval.
