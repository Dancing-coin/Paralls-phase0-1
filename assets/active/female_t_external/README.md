This is a non-destructive working package exported from the externally supplied
authoring file:

`E:\下载\建模2 纹身腿黑卷发女T字版本  基础动作版.blend`

The source `.blend` remains unchanged. The source rig contains 344 bones and
68 deform bones. The runtime GLB contains the deform-skeleton boundary only;
controller/IK/FK/reference bones are not part of the runtime skeleton.

The reviewed Idle/Walk/Run/Jump/Turn clips are mapped and imported by Godot.
The package now contains build-time copies of `boxing`, `short punch`, and
`sword attack` from `female_jk_external`; the source package and source blend
remain unchanged. `short punch` is the qualified derived upper-body realization
and may coexist with Walk/Run. `boxing` and `sword attack` remain full-body
exclusive actions. The held-item anchor and sword slot/hit-volume nodes are
declared on the target GLB and manifest. Contact markers are evidence candidates,
not automatic hit results.
