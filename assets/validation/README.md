# Unified 3D Integration Validation Assets

This directory is reserved for small, runtime-safe validation fixtures. The
default validation scene must not depend on a production art pack. Candidate
environment, character, prop, animation, and audio packs are selected through
an explicit manifest and remain optional.

The default Godot entry point is
`res://scenes/integration/Unified3DIntegrationValidation.tscn`. It uses generic
primitive/procedural presentation and is intentionally independent from every
archived art pack.
